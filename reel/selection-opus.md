## 主要落选者及理由（按聚类）

- C1 2307.01928：共形澄清机制有价值，但 scoped，与 SayCan 同属规划层旧作。共形阈值在本名单的 2411.04549 之外、C2 的 2609.34356 和 C8 的 2506.09937 中也反复出现，本期不再给它单独位置。
- C2 2607.12220 / 2608.22657：两篇都是"运行时契约校验 LLM 输出"，机制同质；caveat 都指出契约是手写或定制、mock 不等于物理成功，证据范围比 2609.34412 窄。2608.29537：验证门控记忆写入，caveat 说强制推进使"每次写入均经验证"不能按字面成立，主张本身有缺口。2609.34356：共形部分只多 1 次安全，语义推理相对简单预测器的贡献没有隔离。
- C3 2609.22966 / 2610.01939 / 2609.35690：都是冻结模型接口设计。2610.01939 的收益是相对值，省 token 只统计共同成功样本；2609.35690 的验证消融同时改变候选数，DP 对照预算未配平；2609.22966 的 SOTA 比较未配平计算量。三篇都比组内两篇 supported 弱。
- C4 2207.04429：经典 LM-Nav，scoped，拓扑图依赖目标场景先验遍历，成功率文字与表格待核对。2608.30396 / 2609.12285：机制与 2606.10577 的"导航工具化"同属一线，2609.12285 的 caveat 明确限于自身开发栈，物体命中率仅 22%。
- C5 2609.23841：offline 级，导航是离散回放，真机链路故障后离线识别，不支持闭环。2609.28798：迁移只到模拟新视角，单次扰动只是展示。两篇证据范围都比 2602.15875 窄。
- C6 2305.16291（Voyager）/ 2607.00272 / 2610.18867：都是"成功经验压成技能库再复用"，与 2609.19906 同质。Voyager 是 2023 年旧作，成功门控缺独立审计；2607.00272 组件因果与等预算比较有限；2610.18867 单场景经验有回退。
- C7 2609.29394 / 2610.02204：与 2608.11350 同属自优化。前者跨本体是目标域再演化，13.2 倍延迟是未配对参照；后者离线修订成本与基线不等，未重复独立改进运行。
- C8 2506.09937 / 2609.34484：都是 offline 级。前者检测不等于在线安全收益；后者奖励器用了未来帧，只能离线筛选。
- C9 2609.21650 / 2609.24563 / 2610.15572 / 2610.21450 / 2609.23997：都是特权教师或合成数据训练学生，同质度高。各自限制：2609.21650 和 2609.24563 仍依赖人工数据或逐任务设定；2610.15572 需要预建地图和人工关键帧；2610.21450 迁移限于留出仿真城区，几何恢复标签未经安全可行性检验；2609.23997 是共享符号状态下的高层协调，峰值选择没有独立确认集。
- C10 2401.12963（AutoRT）：77k 是尝试次数而非成功演示，依赖人类视线监督；作为 2024 年系统，与 2607.13049 相比题材新意较低，列为本组替补。2609.33007：整体收益不等于校准单因素收益，学生任务按教师成功率筛选。
- C11 2604.25788：supported，但与 2410.07166 同为特权状态下的诊断基准，本组只留一篇；列为第一替补（若要提高 evaluation_resource 比例，优先换入）。2411.00081：8B 与 70B 相当的结论主要限于验证集。
- C12 2603.22435 / 2609.19554 / 2609.30233 / 2609.39507 / 2610.07594 / 2610.10409：都在测"通用模型能否直接闭环控制"，高度同质，都是 scoped。共同问题是 harness 差异使榜单不等于模型净效应。具体：2609.39507 主实测只有 30 个任务、固定初态；2610.10409 是单次初始化，参考控制器覆盖不全；2603.22435 的迁移计数只支持窄范围；2609.19554 的相机瞬移免除了物理代价。
- C13 2608.17386 / 2609.28236 / 2610.10388：分别是安全、记忆、探索专题，都可作替补。没入选是因为每组名额有限，2607.06256 的审计角度更独特。2610.10388 的主瓶颈归因限于所给接口与规则，2609.28236 只在仿真中验证。

替补顺序（核对中有篇被暂停或退回时依次补入）：2604.25788 → 2610.10388 → 2401.12963 → 2609.21650。
