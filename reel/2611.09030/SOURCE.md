补读附录后的展示取舍（不改判断）：
- 附录 D.4、E.1：各非参照条件只改报告渲染器一个轴，从参照运行的同一 π₀ 出发、先重渲染同一批训练回合，改进提示逐字相同——反馈研究的配对设计比 L2 所见更干净。
- 附录 E.5：世界坐标与物体坐标报告中位长度相同（16.9k 字符），只给状态的报告 18.2k 字符仅 11%，长度与成功的秩相关 0.24。这部分回答了 L2 “未证明等 token 成本”的缺口：至少在报告长度上，30 vs 40 不是多给文本所致。画报第 ② 区采用。
- 附录 E.5 原文有一句“per-motion report … reaches 90% against 45% on Tool Hanging”，与表 2（按动作 45、按技能 90）方向相反，判断为作者笔误；画报只用表 2 数字。
- 附录 B.5、表 10：反馈研究不给专家脚本，故初始程序总体 3%；画报元信息注明。
- 附录 F.2–F.3：70% 的三轮运行保留零样本程序，齿轮与线缆两列多半在测零样本；画报第 ④ 区注明。
