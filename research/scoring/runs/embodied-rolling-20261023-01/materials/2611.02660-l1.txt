# HeLM: Hierarchical Explicit Language Memory for Non-Markovian Manipulation

## Abstract
Recent advances in Vision-Language-Action (VLA) models have enabled fine manipulation capabilities, yet performing tasks that require working memory remains a key challenge. Most existing VLA architectures operate under a Markovian assumption, mapping only the current observation to an action, which leads to failure in non-Markovian environments. Inspired by the human 'inner monologue', we propose Hierarchical Explicit Language Memory (HeLM), a hierarchical VLA framework that maintains task-relevant history in explicit language through factorized event detection and event-triggered memory updates. We evaluate HeLM across 10 non-Markovian real-world tasks with 56 variants, including five newly formulated inter-episode tasks that require persistent context across task boundaries. HeLM improves intra-episode success by 12.8 percentage points over the strongest baseline and achieves 78% subtask success on compositional generalization tasks, while using up to 4.5x less memory and running 2.5x faster than the keyframe baseline at long horizons.

## 1 Introduction
The rise of Vision-Language-Action (VLA) models has revolutionized robotic control by enabling generalization across diverse language instructions and embodiments [ 1 , 2 ] . Built on large-scale pretrained vision-language models, VLA models generate robot actions based on visual observations and natural language instructions. This approach has led to widespread deployment, with variants focusing on visual grounding [ 3 , 4 ] , complex reasoning capabilities [ 5 , 6 , 7 ] , or subtask planning [ 8 ] . While recent advancements in robot policies have enhanced fine manipulation capabilities, tasks requiring working memory remain a key challenge for real-world deployment. When wiping the window, the robot cannot determine whether the surface has already been wiped and ends up wiping the same area repeatedly. Such tasks are fundamentally non-Markovian, meaning that the current observation alone is insufficient to determine the optimal action. Yet most existing VLA architectures operate under a Markovian assumption, treating manipulation as a sequence of independent decisions. These structural limitations cause failure in memory-intensive tasks (see Fig. 1 ). Recently, various approaches have been proposed to address such limitations [ 9 ] . One line of work extracts latent embeddings from historical observations [ 10 , 11 ] or compresses tokens into a memory module [ 12 ] . While these approaches are effective to some extent, relying on latent representations makes it difficult to identify causes of failure due to limited interpretability. Another line of work directly leverages visual history by stacking past frames [ 13 ] or using keyframe annotations [ 14 ] . A drawback of these approaches is computational overhead caused by accumulating image tokens, which limits long-horizon scalability. To overcome these limitations, we draw inspiration from how humans utilize an ‘inner monologue’. Just as humans manage complex tasks by internally keeping track of their progress (e.g., “I pressed the button twice; one more to go”) or spatial data (e.g., “The cup was originally on the left”), we suggest that natural language can serve as an efficient and interpretable representation for robotic memory. By nature, this compact form preserves critical information (e.g., counts, locations) across long-horizon tasks. More fundamentally, language is a natural memory representation for VLM-based policies: it is the native modality of vision-language reasoning, scales compactly across long horizons, and exposes inspectable memory states for analysis. Building on this insight, we propose Hierarchical Explicit Language Memory (HeLM), which incorporates language memory into robotic manipulation. HeLM separates high-level memory management from low-level action generation. Specifically, a VLM-based high-level policy (HLP) maintains the task relevant history in language form and generates action commands, while a VLA-based low-level policy (LLP) executes actions. Memory updates are event-triggered and occur only after task-relevant events or instruction changes. The language memory is organized into working and episodic fields according to whether information is needed within or across instructions. Together, these design choices support non-Markovian reasoning both within and across episodes. We evaluate HeLM on diverse non-Markovian tasks, including newly formulated inter-episode tasks. HeLM improves intra-episode subtask success by 12.8 percentage points over the strongest baseline and achieves 78% on compositional HLP generalization tasks. As task length grows, HeLM uses up to 4.5 \times less memory and runs 2.5 \times faster than the visual-memory baseline at long horizons. Contributions. Our main contributions are summarized as follows: • We propose HeLM, a hierarchical framework that maintains task-relevant history in explicit language through factorized event detection and event-triggered memory updates. • Across 10 real-world tasks, HeLM outperforms memory-augmented and visual memory baselines, supported by component-level failure analysis. • We formulate inter-episode persistence as an underexplored axis of robotic memory and introduce a task suite of 10 non-Markovian tasks (56 variants).

## 3 HeLM: Hierarchical Explicit Language Memory
HeLM’s design follows a single principle: language can serve as a memory representation for VLA-based manipulation. This section formalizes the non-Markovian problem (Sec. 3.1 ), hierarchical decomposition (Sec. 3.2 ), structured memory (Sec. 3.3 ), and event-triggered inference (Sec. 3.4 ). 3.1 Problem Formulation In non-Markovian manipulation tasks, the current observation o_{t} is insufficient to fully infer the true state s_{t} . Standard VLA policies model the action distribution as \Pi(a_{t}\mid o_{t},I) , implicitly assuming that o_{t} provides sufficient state information. However, identical observations can correspond to different underlying states depending on past events: P(s_{t}\mid o_{t},I)\neq P(s_{t}\mid o_{0:t},I). (1) A memoryless policy conditioned only on o_{t} cannot distinguish histories that yield the same current observation but require different actions (see Fig. 1 ). To address this gap, we introduce an explicit, structured textual memory M_{t} that captures task-relevant history, reformulating the policy as \Pi(a_{t}\mid o_{t},I,M_{t}) . 3.2 Framework Overview HeLM decouples semantic memory management from action generation through a two-level hierarchy. As shown in Fig. 2 , the HLP ( \pi_{HLP} ), built on a fine-tuned VLM, generates action commands z_{t} while maintaining the memory M_{t} based on o_{t} and I . On the other hand, the LLP ( \pi_{LLP} ), implemented with a VLA model, maps HLP-generated commands z_{t} and o_{t} to robot actions a_{t} . By design, language memory captures abstract task state, while the current observation provides immediate spatial grounding at execution time. 3.3 Structured Memory M_{t} Inspired by the distinction between working and episodic memory in human cognition, we organize textual memory into two fields based on how long information remains relevant (Fig 2 ): M_{t}=\langle m^{\text{work}}_{t},m^{\text{epi}}_{t}\rangle. (2) Here, working memory m^{\text{work}}_{t} tracks active progress within a single episode and is updated whenever a visual event is detected. Episodic context m^{\text{epi}}_{t} preserves summarized information across task boundaries, which is promoted from m^{\text{work}}_{t} at the end of each episode (see Fig. 3 for examples). 3.4 Two Stage HLP Inference HeLM employs a two-stage inference mechanism that updates memory only when semantic events are detected or the instruction changes. The LLP executes an action chunk of horizon H , and the HLP is synchronously invoked at each chunk boundary for event detection and updates memory when needed. This decoupling avoids unnecessary memory updates between detected events.
