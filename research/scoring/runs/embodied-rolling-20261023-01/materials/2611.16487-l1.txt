# HeMeR: Heterogeneous Memory Reconciliation for Embodied Agents via Structured KV Reuse

## Abstract
Embodied agents make decisions by combining information from heterogeneous memory modules, including declarative memory for explicit knowledge, procedural memory for learned routines, and working memory for current observations. During interaction, the memory contents required for decision making change with the agent's state, goal, and task progress, while many contents remain shared across consecutive decisions. However, existing memory modules are typically accessed through separate interfaces, so each updated memory context is often processed as a new input to the foundation model. This prevents selective key-value (KV) cache reuse for unchanged memory contents and forces full KV cache recomputation even when much of the memory context remains valid. We introduce HeMeR, an inference framework that performs KV reconciliation between dynamically updated memory contexts and reusable KV states. HeMeR tracks declarative, procedural, and working memory contents across action decisions, preserves KV states for unchanged contents, and reconciles only the KV states affected by memory-content updates. This enables efficient and stable inference as memory contents evolve during interaction. We evaluate HeMeR on ALFWorld, Habitat, and real-world robotic deployments requiring coordinated use of heterogeneous memory contents. In the real-world setting, HeMeR achieves 83.20% task success and reduces per-step inference time from 2.94 to 1.87 seconds compared with MemRL, while preserving compatible KV states as task progress updates the memory context.

## 1 Introduction
Embodied agents increasingly build on foundation models, using language or vision-language models to interpret observations, reason about goals, and select actions [ 1 , base:react , embodied:llmplanner , 13 , embodied:progprompt , embodied:voyager ] . However, embodied tasks often require information beyond immediate observations, including explicit environmental knowledge, learned behavioral routines, and ongoing task progress [ 13 , embodied:progprompt , embodied:voyager , embodied:reflexion ] . Accordingly, recent studies augment foundation models with memory modules that store, retrieve, and update task-relevant memory contents across interactions [ embodied:voyager , embodied:reflexion , method:genagent , serve:memgpt , mem:memorybank ] . These modules help agents preserve continuity over long-horizon tasks, but also make each action decision depend on memory contents that change with accumulated experience, current observations, and task progress. Recent memory-augmented agents use heterogeneous memory modules that maintain distinct forms of memory content for embodied decision making [ base:react , embodied:voyager , method:genagent , embodied:coala ] . A declarative memory module maintains explicit content about environmental objects, relations, and task conditions, often as structured representations such as symbolic facts [ method:genagent , serve:memgpt , mem:amem , 7 ] . A procedural memory module maintains learned behavioral routines that guide future actions [ embodied:progprompt , embodied:voyager , mem:procedural , 6 ] , including parametric representations such as neural adapters [ 11 ] . A working memory module maintains content about the current task state, including recent observations, intermediate decisions, and goal progress [ base:react , 13 , mem:working ] . Although these modules are often studied through separate storage, retrieval, and update mechanisms, action selection requires their contents to be composed into a memory context. The resulting memory context is processed by the foundation model to form transformer KV states during inference [ mem:kv , serve:vllm ] . As the agent receives new observations and progresses through the task, the memory context must be updated while many memory contents remain unchanged across consecutive decisions. This modular separation is well motivated, since each memory module serves a distinct role in embodied decision making [ embodied:coala , mem:procedural , mem:working , mem:episodic ] . However, after memory contents from multiple memory modules are composed into a single memory context, the foundation model must process this memory context to form the hidden representations and KV states used for action selection [ mem:kv , serve:vllm ] . As illustrated in Figure 1 , changes in the environment can trigger updates to declarative and working memory contents and procedural adapter switches, thereby changing the memory context across decision steps. Such changes can make some previously cached KV states incompatible with the updated memory context, while others may remain reusable [ serve:cacheblend , serve:kvlink , serve:cacheslide , pos:rope , 14 , 15 ] . Existing memory-augmented agents mainly focus on what to store, retrieve, and update, but do not explicitly address how to reconcile updated memory contexts with reusable KV states during foundation model inference [ serve:memgpt , mem:memorybank , mem:amem , 16 , mem:titans ] . Without such reconciliation, a naive implementation processes each updated memory context as a new input and recomputes the full KV cache, causing redundant computation during long-horizon embodied interaction [ serve:kvlink , 12 , 17 , 5 ] . To address this problem, we introduce HeMeR , a memory-serving framework for embodied agents that reconciles dynamically updated memory contexts with reusable KV states during foundation model inference. Although declarative, procedural, and working memory serve different roles, their effects on foundation model inference are ultimately reflected in the KV states used for action selection. Rather than treating each memory context as a flat token sequence, HeMeR represents it as a sequence of structured memory chunks associated with corresponding KV ranges, providing a common basis for reconciling heterogeneous memory updates with cached KV states. HeMeR realizes this reconciliation through two complementary mechanisms, Chunk-Level KV Reconciliation for content-level changes and rearrangements within the memory context, and Adapter-Stable KV Reconciliation for procedural changes that alter the active adapter. Specifically, Chunk-Level KV Reconciliation handles updates to declarative and working memory contents by mapping content-level changes and rearrangements to their corresponding KV ranges. ## 3 Problem formulation
We consider a foundation model-based embodied agent that acts over a sequence of decision steps. At step t , the agent receives an observation o_{t} , maintains a task goal g , and selects an action a_{t} using a foundation model F_{\theta} . The agent is augmented with heterogeneous memory modules \mathcal{M}=\{\mathcal{M}^{\mathrm{dec}},\mathcal{M}^{\mathrm{proc}},\mathcal{M}^{\mathrm{work}}\}, (1) corresponding to declarative, procedural, and working memory modules. A memory module stores and retrieves information, and each item it returns is a memory content. For each module \mathcal{M}^{m} , let R^{m} denote its retrieval function and \mathcal{R}_{t}^{m} the memory contents obtained at step t : \mathcal{R}_{t}^{m}=R^{m}(o_{t},g,h_{t}),\quad m\in\{\mathrm{dec},\mathrm{proc},\mathrm{work}\}. (2) Here, h_{t} denotes the interaction history available at step t . For readability, we denote the declarative, procedural, and working-memory contents as D_{t}=\mathcal{R}_{t}^{\mathrm{dec}},\quad P_{t}=\mathcal{R}_{t}^{\mathrm{proc}},\quad W_{t}=\mathcal{R}_{t}^{\mathrm{work}}. (3) A memory context is formed by composing multiple memory contents to support action selection. The function \Gamma defines the step-specific memory context X_{t} , which the foundation model uses together with the observation and task goal to generate an action a_{t} : X_{t}=\Gamma(D_{t},P_{t},W_{t}),\qquad a_{t}\sim F_{\theta}(\cdot\mid X_{t},o_{t},g). (4) Let \mathcal{D} denote the distribution of tasks encountered by the agent. Across decision steps, X_{t} may change as memory contents are inserted, evicted, reordered, or associated with different procedural adapters. Let \Pi denote a serving policy that reconciles the previous KV cache with the current memory context X_{t} . \Pi determines which KV states are reused or recomputed during action generation.
