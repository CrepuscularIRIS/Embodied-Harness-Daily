# SPARK: Self-Correcting Embodied Memory via Physical Re-Observation

## Abstract
Retrieval-augmented generation (RAG) systems have seen growing adoption in embodied settings as language-queryable memories of the environment. However, existing approaches often assume a reliable single-episode knowledge base (KB) or accumulate observations across episodes without correcting prior errors. Such errors can persist through incorrect semantic labels, inaccurate object positions, and inconsistent spatial relationships. To address this, we present SPARK, a corrective multi-episode framework for embodied RAG. After the first episode, a semantic critic flags regions of the KB, a targeted planner generates revisits, and a selective merge adds, removes, or replaces KB information based on the new observations. We evaluate SPARK on four outdoor AirSim maps under two degraded viewpoint conditions, using perception-built KBs, a visibility-constrained oracle used only for evaluation, and a fixed set of 158 embodied question answering (EQA) questions scored before and after correction. A single corrective episode improves downstream EQA on every map under both conditions while storing 13-41% fewer objects than append-only updating, with gains up to 2.7x on one map-condition pair. Extending correction through Episode 4 brings every map above the EQA performance of its undegraded reference. Ablations show that the critic's three signals each contribute to performance, that targeted revisits achieve a larger mean gain than untargeted ones under the same budget, and that selective merging achieves gains comparable to append-only updating with a smaller KB. Overall, SPARK demonstrates the value of correcting embodied memory through targeted re-observation, particularly as embodied systems scale and the risk of accumulated errors increases.

## 1 Introduction
Retrieval-augmented generation (RAG) originated in natural language processing research, where external knowledge bases (KBs) store information that can be semantically retrieved to augment a language model’s context ( Lewis et al., 2020 ) . This provides access to non-parametric knowledge beyond the model’s weights and has inspired extensions such as graph-based RAG ( Edge et al., 2024 ) . More recently, RAG has extended into robotics, where embodied memory systems organize multimodal observations into persistent representations, such as vector databases or hierarchical semantic structures, to support retrieval, reasoning, and long-horizon embodied question answering (EQA) ( Xie et al., 2024 ; Anwar et al., 2025 ) . Embodied memory, however, is built from inherently noisy and incomplete physical observations ( Gu et al., 2024 ) . Perception can introduce spurious or duplicated objects, wrong labels, and inaccurate positions ( Dengler et al., 2021 ; Matez-Bandera et al., 2022 ) , which persist in the KB and affect downstream tasks. As embodied systems scale, a central question emerges: how can a robot detect and correct errors in a memory that has already been built? In large language model (LLM) research, unreliable retrieved knowledge has motivated corrective mechanisms such as CRAG and Self-RAG ( Yan et al., 2024 ; Asai et al., 2024 ) . These approaches, however, focus on retrieval and generation rather than physical re-observation as a source of corrective evidence. Object-level semantic mapping maintains existence and class beliefs from later detections ( Dengler et al., 2021 ; Matez-Bandera et al., 2022 ) , but language-queryable embodied memories rarely correct an already-built KB, often treating stored knowledge as reliable or incorporating new observations without revising prior errors ( Xie et al., 2024 ; Anwar et al., 2025 ) . One line of work reuses what was already captured, through dense representations such as point clouds and 3D Gaussians or through stored keyframes, to reinterpret stored observations, retrieve previously captured frames, or synthesize views from reconstructed scenes ( Chang et al., 2026 ; Zhu et al., 2026 ; Ali et al., 2025 ) . These methods refine a KB by inference from existing observations and cannot add physical evidence about regions that were never adequately observed. Other approaches act physically in the environment, through exploration or corrective action, but serve different purposes. GSMem interleaves physical exploration with answering, exploring further whenever its map cannot answer the current query ( Lu et al., 2026 ) , and Mind Palace stores each episode as a separate scene-graph world instance and treats differences as environmental change ( Ginting et al., 2025 ) , while REFLECT summarizes the robot’s own execution history to explain and recover from immediate task failures ( Liu et al., 2023 ) . What remains missing is a system that can diagnose an existing KB independently of any particular query and resolve identified errors through targeted new observations across episodes. To address this gap, we present SPARK, Self-Corrective Process for Active Robotic Knowledge , a corrective multi-episode framework for embodied RAG. SPARK employs a VLM-powered critic that flags KB regions independently of any EQA query, followed by a targeted planner that generates revisit viewpoints for acquiring new evidence. A selective merge then adds, removes, or replaces KB information based on these observations, closing the loop between diagnosis, re-observation, and correction across episodes. We implement SPARK in AirSim ( Shah et al., 2018 ) using an RGB-D perception pipeline combining class-agnostic segmentation, depth backprojection, and open-vocabulary VLM labeling. We evaluate downstream EQA before and after correction and separately assess the critic against a visibility-constrained oracle graph, constructed using field-of-view restrictions and raycasting from the robot’s observation waypoints. This oracle is used only for evaluation. We validate SPARK across four outdoor scenes, two degraded viewpoint conditions, successive corrective episodes, and ablations of the critic, revisit policy, and merge policy. Our contributions are: • SPARK, to our knowledge the first framework where a robot repairs its own knowledge base without ground truth, using a semantic critic to diagnose memory, a planner to target revisits, and a selective merge that removes and supersedes stored content. Correction improves EQA on every map and viewpoint condition, and stores 13 – 41\% fewer objects than appending the same observations. • An evaluation setting for memory correction, pairing a perception pipeline with a visibility-constrained oracle used only for evaluation, and a fixed EQA set of 158 questions across four outdoor AirSim maps. ## 3 Method
3.1 Problem Formulation Current persistent memory systems generally assume a single collection pass suffices for downstream EQA, yet a KB built from a perception pipeline can accumulate errors, such as missing objects, incorrect labels, and misplaced geometry, that propagate to downstream tasks unless corrected. We study KB correction over repeated episodes in a static world, where cross-episode mismatches reflect memory errors as opposed to scene changes. An episode is a single traversal of a set of N_{e} waypoints, with one observation recorded per waypoint, so coverage is determined by the waypoints without continuous recording. During episode e , the robot records \mathcal{O}^{(e)}=\{\,o_{e,k}\,\}_{k=1}^{N_{e}}, where o_{e,k}=\big(I_{e,k},D_{e,k},\mathbf{p}_{e,k}\big) : I is the RGB image, D the depth map, and \mathbf{p} the robot pose. Pose is taken as ground truth because localization is not the subject of this work. The first episode builds the memory H^{(1)}=f_{\mathrm{build}}\big(\mathcal{O}^{(1)}\big), (1) by pooling and clustering observations, so visit order does not affect the result. Given H^{(e)} , a semantic critic \mathcal{C} inspects it together with the per-episode evidence Z^{(e)} retained alongside it, namely the waypoint images and their provenance, and returns regions flagged as unreliable, \mathcal{R}^{(e)}=\mathcal{C}\big(H^{(e)},Z^{(e)}\big). (2) A revisit planner converts these regions into waypoints, \mathcal{V}^{(e+1)}=f_{\mathrm{plan}}(\mathcal{R}^{(e)},H^{(e)}) , and visiting them yields targeted observations \mathcal{O}^{(e+1)} . The memory is then corrected as H^{(e+1)}=f_{\mathrm{correct}}\big(H^{(e)},\mathcal{O}^{(e+1)}\big). (3) The formulation assumes no particular memory representation and requires only a persistent KB, a critic, a planner, and a merge that can remove, replace, and add information (Figure 1 ).
