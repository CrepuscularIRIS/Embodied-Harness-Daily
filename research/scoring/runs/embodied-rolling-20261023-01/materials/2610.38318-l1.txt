# What Should a Navigator Remember? Spatiotemporal Memory for Zero-Shot Vision-Language Navigation

## Abstract
Zero-shot vision-and-language navigation (VLN) requires an agent to use past observations without navigation-specific training. We study what information an 8B-scale navigation system should retain and how it should be organized for subsequent decisions. Our agent combines instruction progress, hierarchically compressed observation history anchored to poses, and accumulated geometry in complementary task, temporal, and spatial memories. An 8B observer summarizes observations, and an 8B reasoner uses the memories to select waypoint intents or request additional views, a geometric controller executes the selected targets. A semantic information perspective motivates the distinction between retaining evidence, making it accessible to the reasoner, and acquiring further observations. On R2R-CE val-unseen, the complete system achieves the highest among the evaluated Qwen3-based zero-shot baselines. Removing temporal memory reduces SR and sharply increases average path length from 16.9 to 39.1m, removing the spatial-map and planning component reduces SR as well. Real-world experiments on a Unitree Go2 show that our zero-shot method achieves higher success rates than the post-trained baseline in both corridor and office environments, suggesting better transfer to the evaluated real-world settings. As a complementary evaluation, LAW2 uses paired instruction interventions to examine behavioral responses, instruction following ability beyond endpoint success. These results support preserving task progress, observation history, and geometry in structured memory for zero-shot navigation with smaller open models.

## 1 Introduction
Vision-and-Language Navigation (VLN) requires an embodied agent to follow a natural-language instruction through a previously unseen environment, providing a foundation for higher-level tasks such as object manipulation and human–robot interaction. Post-training methods ( Guo et al., 2026 ; Wei et al., 2026 ; Wang et al., 2026 ) fine-tune vision-language models on navigation trajectories and achieve strong success rates on R2R-CE ( Krantz et al., 2020 ) . Zero-shot methods ( Chen et al., 2025 ; Shi et al., 2025 ; Yuan et al., 2025 ; Li et al., 2026a ) instead reuse pretrained models without navigation-specific training. Despite their different training requirements and inference resources, both approaches must integrate visual observations, instruction progress, and execution history to make reliable navigation decisions. A central question is how navigation history should be represented for smaller open models. In our reproduced HSGM configuration ( Li et al., 2026a ) , replacing GPT-5 with Qwen3-VL-8B reduces SR from 0.463 to 0.049 on R2R-CE val-unseen (Table 1 ). This comparison motivates examining the demands placed on the navigation backbone. We focus on memory representation: the reasoner must connect current observations with instruction progress and earlier evidence, often across many actions. Our design preserves three complementary kinds of information: what the instruction requires and which subgoal is active, what the agent has observed and executed, and what geometry it has explored. We organize these as task memory, temporal memory with hierarchical summaries anchored to poses, and spatial memory containing an occupancy map and a committed target. The semantic communication perspective of Lastras et al. (2026) motivates retaining evidence useful for task-relevant judgments and organizing it for a computationally bounded receiver. In navigation, these judgments include whether a subgoal is complete and where to move next. We use this perspective as a design rationale. An 8B observer constructs observational summaries, while a Qwen3-VL-8B reasoner combines them with the instruction and spatial memory. Waypoint intents connect these decisions to geometric control, and a PREVIEW action allows the agent to acquire additional views. We evaluate this memory design through navigation results, component ablations, and deployment on a Unitree Go2 to experiment real world performance. We also introduce LAW2 as a complementary diagnostic benchmark: paired direction reversals, route-information removal, and paraphrases reveal how behavior responds to instruction changes with the same meaning. Our contributions are as follows. • We propose a spatiotemporal memory representation for zero-shot VLN that combines instruction progress, pose-anchored observation history, and accumulated geometry. • We evaluate the representation in a navigation system with an 8B observer and an 8B reasoner. Component ablations characterize the effects of temporal memory, spatial memory and active previewing with planning, an integration with CA-Nav and real-world deployment provide additional evidence of utility. • We introduce LAW2 to complement navigation metrics with paired tests of directional responsiveness, dependence on route information, and sensitivity to paraphrasing.

## 3 Methodology
3.1 Problem Formulation We consider vision-and-language navigation in a partially observable environment. An agent receives a natural-language instruction G at the beginning of an episode and subsequently acquires observations while executing actions. We model the interaction as a POMDP Kaelbling et al. (1998) , whose state s_{t} includes the environment layout and the agent’s physical configuration. The agent does not observe the complete state; instead, it receives observations v_{t}=(I_{t},D_{t},P_{t}) , comprising an RGB image, depth, and a measured or estimated pose. The environment evolves according to s_{t+1}\sim T(\cdot\mid s_{t},a_{t}),\qquad v_{t+1}\sim O(\cdot\mid s_{t+1},a_{t}), (1) where T and O are the transition and observation models. The executed action belongs to \mathcal{A}_{\mathrm{prim}}=\{\texttt{FORWARD},\texttt{LEFT},\texttt{RIGHT},\texttt{STOP}\}. (2) The agent maintains an internal memory that integrates the instruction with its interaction history: \displaystyle h_{0} \displaystyle=f_{\mathrm{init}}(G,v_{0}), (3) \displaystyle h_{t} \displaystyle=f_{\mathrm{update}}(h_{t-1},a_{t-1},v_{t}),\qquad t\geq 1, \displaystyle a_{t} \displaystyle\sim\pi(\cdot\mid h_{t}). Here, h_{t} is an internal memory representation, not necessarily an exact Bayesian belief state, and \pi denotes the complete decision-and-control policy. The instruction is supplied once, but its retained representation remains available throughout navigation. Let Q_{G} denote the task requirements associated with G . Successful execution requires the resulting trajectory to satisfy Q_{G} . Standard benchmark SR evaluates the narrower condition of stopping within a prescribed distance of the goal and does not by itself establish compliance with all route instructions. We therefore evaluate navigation performance together with instruction responsiveness. Appendix C develops the general receiver-based perspective underlying this formulation, distinguishing available information, realized computation, and task achievement through environment interaction. 3.2 Design Rationale Our memory design is motivated by the semantic information perspective of Lastras et al. (2026) , which studies communication that enables a receiver to derive required conclusions using its existing knowledge. For navigation, this motivates retaining evidence that supports task-relevant judgments rather than reproducing the entire observation stream. We adopt this perspective as a design rationale, without transferring its communication bounds directly to memory cost or navigation performance. We distinguish evidence availability from its effective use. A navigation decision may fail because the necessary evidence has not been observed, because it was discarded during memory compression, or because the reasoner cannot reliably interpret and combine the retained information. These possibilities motivate complementary mechanisms: acquiring additional observations, retaining relevant history, and organizing that history into accessible representations. The agent is not assumed to identify these failure sources perfectly. We instantiate this rationale through task, temporal, and spatial memory. Task memory retains the instruction and its execution stage; temporal memory organizes past observations and measured motion; spatial memory accumulates geometric evidence for navigation. Hierarchical summarization and pose anchoring organize historical information for the reasoner, while a preview mechanism allows the agent to request additional views. These mechanisms support memory-conditioned decisions without guaranteeing evidence sufficiency or correct reasoning.
