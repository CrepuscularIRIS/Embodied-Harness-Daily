# MOTIO: Agentic Skill Engineering for Reality-Grounded Humanoid Loco-Manipulation

## Abstract
We present MOTIO, an agentic skill-engineering system that turns ordinary human-action videos, reality-grounded 3D assets, motion references, and reusable robot skills into executable humanoid loco-manipulation programs. Through in-context task and contact reasoning, an agent constructs staged robot-native interactions and improves them using physics execution, multi-frame feedback, and human validation---without task-specific teleoperation or robot demonstration collection. Agentic 3D supplies metric product and environment assets, while existing whole-body, inverse-kinematics, and dexterous-hand interfaces realize the programs. Across 33 timestamped first approvals, the median recorded agent-turn time is 97.0 minutes and request-to-approval duration is 2.80 hours. Simulation-side layout and object variation prepare a long-horizon bottle-disposal skill for a continuous 101.75-second physical G1 execution in a scanned office; physical refinement reduces screw-tightening thread residual by 76.0%. Agent-generated skills additionally supervise BC/DAgger distillation into one shared reference policy, completing 18 simulated tasks under the same checkpoint without inference-time expert intervention. Project page: https://iiiiqiiii.github.io/motio/

## 1 Introduction
Humanoid foundation controllers increasingly provide reusable walking, balancing, and whole-body tracking. Developing a new contact-rich task in a real environment additionally requires metric object geometry, interaction stages, and execution under robot dynamics. Human demonstration videos reveal the sequence and intent of contact events—reaching, grasping, turning, regrasping, releasing, and checking the terminal state—which can be translated into robot-space programs. MOTIO provides an agentic task-acquisition interface. An Agentic AI harness receives a human-action video, a natural-language objective, metric scene or product assets, motion references, robot-specific skills, and prior executable cases. It reasons over task phases and contacts in context, constructs an editable robot-native program, and iterates on physical state and multi-frame visual feedback. Human review selects executable skill versions for reuse. MOTIO has two stages. Agentic 3D builds metric product and scene assets, primarily in Blender and with FreeCAD for parameterized or standards-oriented geometry. Agentic Skill Engineering translates human-action context into contacts, goals, phase transitions, and robot references; MuJoCo ( Todorov et al., 2012 ) provides execution feedback for program revision. Measured room layouts, RGB-D observations, LiDAR localization, and existing whole-body and hand control enable selected skills to run on physical G1. Simulated skill executions also serve as expert references for one shared BC/DAgger policy, without new task-specific reinforcement-learning rewards. Representative tasks show how the agent turns context into robot behavior. For a HEUER vise, human-action video and prior programs guide a 48-second right-hand grasp–turn–regrasp–clamp skill. For a Rapesco stapler, human feedback about palm pressing and withdrawal changes the contact and retreat phases. MOTIO spans locomotion, whole-body contact, articulated mechanisms, tool use, materials, and multi-humanoid tasks. In an office reconstructed with 3D Gaussian splatting ( Kerbl et al., 2023 ) , G1 completes bottle disposal and door/cart transport; agent-generated references also support a shared policy that executes 18 simulated tasks under one checkpoint. Our contributions are threefold. (1) We introduce demonstration-conditioned in-context skill engineering , constructing robot-native loco-manipulation programs from human-action video, reusable skills, and prior cases without collecting task-specific teleoperation or robot demonstrations. (2) We connect Agentic 3D assets, physics-grounded program revision, and human validation into a reusable task-development workflow. (3) We evaluate diverse humanoid tasks through development budgets, contact refinement, Real2Sim2Real execution, and distillation of agent-engineered skills into a shared multitask reference policy.

## 3 Agentic Skill Engineering
3.1 Reality-grounded assets and the executable task artifact Stage I takes a natural-language product or scene specification, gathers dimensions and reference material, and constructs a metric asset for human review. Stage II receives the task objective, a human-action demonstration, the reviewed asset, an interactive physical environment, and the robot embodiment and controllers. The agent then produces robot-frame targets and event-driven phase transitions. The asset catalogue contains 78 local families and 104 simulation-task families, with 59 shared families and 123 distinct families in their union; these units cover products, supporting objects, and scenes. Making an asset executable requires collision geometry, articulated bodies and joints, named contact sites, and task-event measurements. The 159 \times 41 \times 53 mm Rapesco stapler has lever, magazine, anvil, and press-cap representations; the robot uses stapler-frame palm targets and paper-frame stabilization targets while the event logic checks lever motion and sustained contact. The HEUER vise couples a translating jaw and rotating screw so the robot’s palm arc produces measurable clamping. Supplementary Section S1 specifies these physical interfaces. 3.2 Video-conditioned program synthesis The task agent brings human-action frames, the objective, metric assets, motion references, G1/Revo2 skill instructions, prior programs, and embodiment constraints into context. Video establishes the action sequence and contact intent; object and robot models provide scale, coordinate frames, reachable targets, and event thresholds. The agent writes body and hand references with phase transitions that respond to simulated state. In the HEUER vise task, human-video cues for stabilization, rotation, regrasping, and release become robot-specific phases: initial workpiece support, a right-hand palm arc around the handle, hand retreat and repositioning, and finally withdrawal followed by a retention check. The 48-second program completes four seven-second half-turn cycles, producing 2.052 handle turns and reducing jaw opening from 38.000 to 29.987 mm. The workpiece remains clamped after hand and support withdrawal. Figure 4 illustrates the phase-to-program correspondence and G1 execution; Supplementary Section S2 details the video context and program stages. 3.3 Physics-grounded revision and human approval For each candidate program, the agent runs MuJoCo, inspects robot and object states alongside a multi-frame contact sheet, and revises targets, phase timing, contact logic, or control references. Human feedback specifies task intent and motion quality; state-based checks determine whether the desired physical event occurred. For the Rapesco stapler, human feedback requests palm-driven pressing and a more natural hand withdrawal. The program is revised into palm press, unload, paper release, elbow retraction, and arm lowering. The resulting 31-second execution triggers the contact-gated staple event at 14.8125 s, leaves the paper joined, and withdraws both hands. The skill receives human approval. The screw-tightening task provides a second example: simulation feedback reduces maximum thread residual from 269.44 to 64.58 \mu m. Supplementary Section S3 provides the program phases and event checks. 3.4 Embodied deployment and optional policy reuse Frozen ScaleBFM whole-body tracking executes standing and locomotion references, with task-specific inverse kinematics, Revo2 finger schedules, and bounded hand/contact feedback. MuJoCo is the main validation engine; Isaac Sim/PhysX models deformable fruit peel in the mango-peeling task. For physical bottle disposal, Livox MID-360 localization, RGB-D and SAM3 observations, and a measured bin pose guide Thor’s staged planning. The resulting body and hand references are validated in MuJoCo before execution on G1. Skill programs and their simulated executions provide expert state/reference pairs for a task-conditioned BC/DAgger student. The student predicts six 59-dimensional references at 20-ms intervals, executed through frozen ScaleBFM and the existing contact/IK feedback stack. DAgger labels student-visited states with the skill-program expert and uses task-event gates for recovery. The final reference policy conditions on current task and phase state plus explicit geometry memory ( reference_history=False ); the observation channels and training interface are detailed in Supplementary Section S6.
