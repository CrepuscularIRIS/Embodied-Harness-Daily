# HGWM: Hierarchical Graph-Guided World Model for Zero-Shot Object Navigation via Graph Matching

## Abstract
Zero-shot object navigation requires an embodied agent to choose where to search while retaining evidence from previous observations. HGWM couples an LLM-generated room-anchor prior with persistent spatial-semantic memory. A coarse stage assigns visual-semantic scores to candidate headings on a 0-10 scale; a fine stage measures symbolic compatibility between observed objects, room context, and the goal prior. Phase-dependent fusion combines these scores with an LLM direction recommendation before local action selection. On HM3D v0.1, the reported HGWM configuration achieves 62.6% success rate (SR) and 31.5% success weighted by path length (SPL), compared with 58.1% and 31.2% for WMNav. On MP3D, the corresponding values are 46.8% and 17.9%, compared with 45.4% and 17.2%. The results indicate higher success point estimates and modest path-efficiency gains. On HM3D v0.2, the full model obtains 74.4% SR and 31.9% SPL. Additional component ablations reduce SR by 0.9-2.3 percentage points and SPL by 0.6-1.5 points. These are author-reported aggregate measurements. The accompanying implementation repairs pass offline tests; episode-level rerun records are not available. Evaluation is confined to simulation.

## 1 Introduction
Navigation in an unfamiliar environment benefits from both recognizing visible objects and anticipating where a target might be found. Foundation-model agents provide open-vocabulary semantic cues [ 26 , 17 ] , but ambiguous observations and incomplete spatial memory can still lead to unproductive search. A useful prior should guide exploration without being mistaken for a verified map of the environment. We study two design challenges: retaining observations across viewpoints and using prior room–object relations to assess candidate directions. VLM detections can be incorrect, while common indoor associations need not hold in every scene. Structural checks may therefore help reject some misleading interpretations but can also suppress valid, atypical observations. HGWM addresses these challenges through a predict-then-ground design. An LLM first generates a hierarchical goal graph describing plausible rooms, anchors, and connections. During navigation, RGB-D observations populate a persistent spatial-semantic graph. Coarse visual-semantic scoring and fine prior-conditioned matching then inform action selection. Here, grounding means relating a hypothesis to sensor-derived evidence, not proving that either graph is correct. A category such as bed specifies no room instance, route, or viewpoint. A room–anchor hypothesis supplies plausible search contexts before the target appears, while memory records encountered evidence. Their compatibility gives relational context a defined role in ranking where to look next. Our contributions are threefold: • A symbolic predictive navigation state coupling a hierarchical goal prior with persistent spatial-semantic graph memory. • A two-stage decision rule that separates prior-conditioned visual scoring from explicit, direction-specific matching of observed and hypothesized relations. • Evaluation on HM3D and MP3D, including four additional component ablations on HM3D v0.2, analysis of success and path efficiency, and qualitative navigation examples. Relative to the reported WMNav results, HGWM improves SR by 4.5 percentage points (pp) on HM3D v0.1 and 1.4 pp on MP3D; SPL improves by 0.3 pp and 0.7 pp, respectively. These are point-estimate comparisons, not evidence of statistical significance. The qualitative trajectories motivate studying repeated exploration, but no aggregate loop-frequency metric is reported.

## 3 The Proposed Method
HGWM maintains a symbolic predictive navigation state: a goal prior, an observation memory, and scores for candidate headings. The term world model denotes this state, not a learned dynamics simulator. Figure 1 shows the perception–memory–decision loop. Section 4.2 identifies the reported evaluation and available reproducibility records. 3.1 Task and Decision State The target is an object category c . At decision step t , the agent receives RGB-D observations O_{t}=(I_{t},D_{t}) and a planar pose P_{t}\in SE(2) . The panoramic scorer uses six relative headings \mathcal{A}=\{30,90,150,210,270,330\}^{\circ} . A high-level decision selects a search direction and a short-horizon subtask; the local navigator then selects a feasible displacement. The 40-step horizon counts agent decision iterations, not a uniform metric distance traveled. \mathcal{W}_{t}=(G_{goal},M_{t},\{(c_{t}^{\alpha},f_{t}^{\alpha})\}_{\alpha\in\mathcal{A}}). (1) Here c_{t}^{\alpha}\in[0,10] is a coarse score and f_{t}^{\alpha}\in[0,1] is a symbolic compatibility score. Neither is a posterior probability. Success requires the stopping condition within 1.0\,\mathrm{m} of a target instance under the evaluation protocol, rather than complete alignment of the graphs. 3.2 Goal Prior and Observation Memory Given c , an LLM returns a structured prior containing likely rooms, alternative rooms, anchor objects, and room connections: G_{goal}=\mathrm{LLM}_{prior}(c,\text{prompt}). (2) This graph is a category-conditioned hypothesis, not a map of the particular scene. In the supplied implementation, priors are cached by goal within an episode and the cache is cleared on reset. We do not assume identical priors across independently executed episodes. What is predicted. The prior describes object categories and plausible relations, rather than asserting coordinates for unseen objects. For example, a bed query can suggest a bedroom and nearby furniture as search context. A detected anchor contributes evidence for a direction even before the bed is visible; failure to observe that anchor is not proof that a bed is absent. Alternative rooms in the prior preserve multiple search hypotheses. Hypothetical nodes are kept separate from observation records so that an expected object is not counted as a detected object merely because the LLM mentioned it. Spatial-semantic memory stores object names, inferred rooms, observation counts, and estimated map positions. The revised implementation queues depth-based navigation rays before the VLM response arrives, then associates each directional description with the nearest available view-center ray within 30^{\circ} . Projection uses pose, a maximum ray distance of 3\,\mathrm{m} , and 100 map pixels per meter. These are coarse positional estimates for a view, not precise object bounding-box projections. The current local graph additionally uses textual spatial and depth cues. For each direction, current observations and retrieved memory are normalized into one graph contract before matching. It exposes consistent flat and typed views of room nodes, object nodes, adjacency, object relations, and containment. Field aliases are resolved once, objects retain stable identifiers, and observed room membership supplies containment edges. Current attributes take precedence for the same identifier. This boundary prevents a scorer from silently reading a different graph representation. Matching uses symbolic features, without a learned graph-embedding network. 3.3 Coarse Visual-Semantic Scoring The VLM receives the panorama, goal, and prior context and returns a JSON record per heading with a score, objects, room, path assessment, and explanation: c_{t}^{\alpha}=\mathrm{VLM}_{score}(I_{t}^{pano},c,G_{goal})_{\alpha}. (3) The requested score range is 0–10. A score of 10 is reserved for a visible target according to the model; 0 denotes a dead end with no visible target; 1–9 encodes intermediate opportunities. This is a model judgment, not a validated detector confidence. Because the same goal prior already enters this prompt, the fine stage adds an explicit computation rather than exclusive access to prior knowledge. The parser supplies 5 when a score is absent, and uses score 5 for all headings if the entire directional extraction fails. The fusion routine consumes this scale directly: it does not apply candidate-set min–max normalization or episode-level z-score normalization. Malformed or out-of-range responses remain an implementation concern, not an assumed probabilistic guarantee. 3.4 Fine Symbolic Compatibility The refinement prompt asks the LLM to review relations using scene descriptions and goal context. The application routine retains nodes, accepts proposed relations between known nodes, and preserves unmodified edges with confidence greater than 0.7. All typed edge views are rebuilt from the edited edge set, preventing discarded relations from surviving in a stale representation. This operation remains heuristic and can mishandle atypical arrangements; it is not a verified node-pruning procedure.
