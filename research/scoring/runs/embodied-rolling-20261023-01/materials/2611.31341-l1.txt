===ABSTRACT===
Social robots face diverse and changing tasks in companionship and education. LLM-based methods can generate task programs, but they still rely on manually developed control interfaces and predefined capabilities. They also lack a general mechanism to optimize completed tasks based on user-specified metrics and reuse performance improvements across tasks.We present EvoMisty, a plugin-based framework that enables coding agents to build and continually improve robot capabilities. EvoMisty builds a control program from official documentation and verifies candidate capabilities on a physical robot. Verified capabilities are stored in an atomic capability library and combined with existing skills to solve tasks. After task completion, EvoMisty can collect execution data, measure user-specified metrics, and iteratively improve task programs. It then distills reusable skills from final solutions into a skill library for future tasks.We evaluate EvoMisty on a physical Misty II robot using Claude Code and Codex. The two agents construct 109 and 107 verified atomic capabilities, respectively. Both complete all 28 AutoMisty benchmark tasks and seven additional tasks beyond AutoMisty's capabilities. Optimization improves all seven evaluated metrics across five tasks. For example, dialogue response latency decreases by 52% and 71%, respectively. Reusing skills from one optimized dialogue task reduces latency by 33% to 72% in three other dialogue tasks without further optimization. All code and experimental videos will be publicly released through the webpage: https://wangxiaoshawn.github.io/projects/evomisty/index.html

===INTRO===
Social robots face diverse and changing tasks in companionship and education. New tasks may require additional device functions, external hardware, or better execution performance. LLM-based methods can generate task programs, but they rely on predefined device capabilities and lack a general mechanism to improve performance. Existing methods, such as Code as Policies [ 20 ] , AutoMisty [ 35 ] , and MistyPilot [ 36 ] , use predefined interfaces or skills to complete tasks. Recent studies, including ASPIRE [ 23 ] and RoboFoundry [ 21 ] , further explore program improvement through execution feedback. However, two challenges remain. First, constructing and verifying basic device capabilities still largely requires manual development. Second, existing approaches mainly focus on task completion and failure correction. They lack a general mechanism to optimize completed tasks based on user-specified performance metrics and transfer these improvements to future tasks. We introduce EvoMisty, a plugin-based framework that enables coding agents to autonomously build and continually improve robot capabilities. As shown in Fig. 2 , EvoMisty consists of four stages. Build creates a control program from official documentation and stores verified capabilities in an atomic capability library. Solve combines atomic capabilities and existing skills to write and test task programs. Optimize collects execution data, measures user-specified metrics, and iteratively improves completed programs. Evolve distills reusable skills from final solutions into a skill library for future tasks. We evaluate EvoMisty on a physical Misty II robot using Claude Code and Codex. The two agents construct 109 and 107 verified atomic capabilities, respectively. Both complete all 28 AutoMisty benchmark tasks and seven additional tasks beyond AutoMisty’s capabilities. Optimization improves all seven evaluated metrics across five tasks. Reusing skills from one optimized dialogue task reduces latency by 33% to 72% in three other dialogue tasks without further optimization. Our main contributions are as follows: • We propose EvoMisty, a plugin-based framework that enables coding agents to autonomously construct and verify robot capabilities from official documentation. • We introduce a metric-driven optimization workflow that improves completed tasks and transfers performance improvements through reusable skills. • We demonstrate the effectiveness of EvoMisty on a physical social robot using two coding agents, 35 tasks, seven performance metrics, and cross-task reuse experiments.
