===ABSTRACT===
Tools with different shapes can have similar functions, but transferring manipulation skills across tools requires understanding how tool geometry relates to the specific task and adjusting the manipulation strategy accordingly. The key challenge is to discover the common affordances that contribute to task completion across different tools and verify whether they support new tools in performing similar work. We present A$^2$-VLA, a tool-adaptation framework that combines an embodied agent with a VLA policy. It treats tool affordances as hypotheses the agent can construct, test, and revise. Given teleoperated demonstrations with a few source tools, the agent reconstructs the scenes in simulation and autonomously determines task-relevant affordance features: functional regions and their key geometric properties. It develops affordance-extraction skills and refines both the features and skills through autonomous experiments in the reconstructed scenes. Validated extraction skills accumulate in a reusable skill library for unseen tools. Finally, A$^2$-VLA uses encoded functional-region features as conditioning inputs to a $π_{0.5}$ backbone during training and inference. Evaluation examines affordance reliability in reconstructed scenes and real-robot task success on unseen tools. Our method achieves 86.1% success in simulated cross-tool trajectory retargeting based on affordances. On three real-robot tool-use tasks, A$^2$-VLA improves task success by 30.7 percentage points over $π_{0.5}$.

===INTRO===

People can often reuse a familiar manipulation skill with an unfamiliar tool after inspecting it and attempting to interact with the environment using it. A differently shaped implement may still provide functional regions similar to those of a familiar tool, such as an edge for cutting or a tip for hooking, even though its appearance and required wrist motion differ substantially from those of the original tool. What transfers is therefore neither the tool’s identity nor a fixed end-effector trajectory, but an understanding of the properties that make the intended interaction possible. Enabling robots to acquire and reuse this understanding from limited tool experience would reduce the need to collect demonstrations for every new tool–grasp combination. Toward this goal, we study how to enable a robot system to adapt to new tools that can perform the same task, starting from teleoperated demonstrations using a small set of source tools. Vision-language-action (VLA) policies already possess some tool-manipulation capabilities [ 6 , 3 , 14 ] , but adapting them to entirely new tools still requires repeated rollout collection and fine-tuning to maintain performance. Predefined functional representations of tools have shown useful structure for transfer: MimicFunc establishes functional correspondences through keypoints and function frames [ 18 ] , and FuncBridge learns functional trajectories separately from their grounding into actions [ 23 ] . Meanwhile, improvements in the embodied manipulation capabilities of general-purpose large vision-language models (VLMs) make autonomous analysis of tool function possible. Our focus is how an agent system can autonomously identify task-relevant functional regions and determine their key geometric features, capturing functional commonality across tools to guide a VLA policy in adapting to new tools. We treat task-relevant affordance features as experimentally testable hypotheses. Although hierarchical robot systems already connect reasoning by general-purpose VLMs to low-level policy execution through language or spatial guidance [ 16 , 7 , 4 ] , language or keypoints alone cannot fully represent the geometric details of tools. Cross-tool adaptation additionally requires deciding which tool properties should be represented for a specific task and testing whether these properties can guide the policy to complete it correctly. We introduce A 2 -VLA, in which the agent starts from a few real-robot teleoperated demonstrations, reconstructs the demonstrated scenes and tools in simulation, and conducts experiments within them. The agent analyzes how different source tools accomplish the task, determines task-relevant affordance features, develops affordance-extraction skills, and applies them to other tools to attempt task execution. Based on experimental feedback, it analyzes unsuccessful interactions and refines the selected functional regions, geometric features, or extraction skills. Successful skills and their applicability conditions accumulate during this process in a reusable skill library. When faced with an unseen tool, the agent can therefore reuse previously validated skills to identify corresponding functional regions and extract the same features. We condition the low-level VLA execution policy on agent-encoded functional-region features through a low-dimensional affordance interface. While analyzing the source tools, the agent determines task-relevant affordance features, which are encoded under a unified protocol as conditioning inputs for VLA training. Unseen tools’ affordances are described through the same protocol: their specific affordance parameters are extracted while the coordinate representation and feature semantics remain unchanged. This gives the agent freedom to select functional regions and geometric features while maintaining a consistent policy input format. Encoded features serve as conditioning inputs when training a \pi_{0.5} policy with an auxiliary affordance prediction head. During deployment, the agent reconstructs the unseen tool in simulation, extracts and tests candidate affordances, and refines their parameters from simulation feedback before encoding them under the same protocol for the VLA policy. At execution time, the VLA conditions each action chunk on the updated affordance features and current observations. Our evaluation examines the reliability and reusability of autonomously discovered affordances and their effectiveness in cross-tool transfer. Simulation tests compare our affordance discovery and validation process with other tool-adaptation methods, including task success when using affordances to retarget trajectories in reconstructed scenes. Three real-robot tool-use tasks test the robustness of cross-tool transfer. ## 3 Problem Formulation
Given a task instruction \ell , we are provided a small set of source tools, each with real-robot teleoperated demonstrations. At time t , the observation \mathbf{o}_{t}=(I_{t},\mathbf{q}_{t}) contains camera images I_{t} and the robot configuration \mathbf{q}_{t} . The first command predicted from \mathbf{o}_{t} is \mathbf{a}_{t} . An action chunk \mathbf{A}_{t}=(\mathbf{a}_{t},\ldots,\mathbf{a}_{t+H-1}) contains H consecutive robot commands. The demonstrations provide the observations and trajectories needed to reconstruct tool interactions in simulation. We seek transfer to unseen tools, disjoint from source tools, without additional task demonstrations. The agent autonomously determines task-relevant affordance features by analyzing source-tool demonstrations, identifying functional regions and key geometric properties shared across tools. It develops skills to extract corresponding features from unseen tools. We denote the encoded functional-region feature vector at time t by \mathbf{f}_{t} . Feature values follow a unified task-level encoding protocol. For an unseen tool, the skills use inspection observations and its attachment to the robot. Different tools supply different values under the same feature definitions and encoding. The policy \pi_{\theta} uses \mathbf{f}_{t} together with \mathbf{o}_{t} and \ell to complete the task. We evaluate affordance reliability through simulated cross-tool retargeting and transfer performance through real-robot task success.

## 4 A 2 -VLA
A 2 -VLA connects an agent that analyzes tool function with a VLA that executes the task (Fig. 2 ). The agent reconstructs demonstrated interactions, develops affordance-extraction skills, and tests them through simulation. Validated affordances condition VLA training and deployment. 4.1 Reconstructing Demonstrated Interactions The agent performs real-to-sim reconstruction using observations and recorded robot trajectories from source-tool demonstrations, together with calibrated camera parameters and a robot model, to reconstruct the tools, target objects, and their spatial arrangement in simulation. Recorded motions anchor the reconstruction to the demonstrated interaction. The resulting environment enables the agent to replace a tool, change its functional parameters, adjust object positions, and execute candidate action sequences while observing contact and task outcomes. The reconstructed environment enables the agent to rapidly test candidate functional regions through simulated tool interactions. 4.2 Autonomous Affordance Discovery From examples to extraction skills. As shown in Fig. 2 (a), the agent compares source-tool demonstrations to identify the functional region and properties that enable the task, such as position, local orientation, and task-specific direction. It develops executable affordance-extraction skills for these task-relevant features. Each skill extracts and encodes features as \mathbf{f}_{t} at each demonstrated time step, with spatial features expressed in the robot-base frame through tool attachment and kinematics. Ordering these features in time yields the demonstrated affordance trajectory. Affordance validation in simulation. The agent validates each tool’s extracted affordance features in simulation. Specifically, it tests whether feature-based trajectory retargeting enables different tools to complete the task. Let \mathbf{Q}=(\mathbf{q}_{0},\ldots,\mathbf{q}_{T-1}) be a feasible T -step robot trajectory that completes the task with the source tool in simulation, yielding reference features \mathbf{f}_{t}^{\mathrm{src}} .
