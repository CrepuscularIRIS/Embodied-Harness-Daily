# PyRUA-REAL: Robot Exploration and Adaptive Learning through RSI in the Real World

## Abstract
Coding agents powered by models such as GPT-6-Astra connect spatial reasoning with executable robot behavior, raising the question of how such agents can produce lasting improvements in robot capabilities from physical interaction. In this work, we study embodied recursive self-improvement (RSI) through real-world exploration, code refinement, and deployment using PyRUA-REAL, a framework in which coding agents retain interaction experience as persistent memory and reusable executable skills that inform subsequent exploration and improvement. Our empirical study places physical manipulation at the center of the improvement process, examining how agents collaborate, what kinds of execution feedback support effective code refinement, and how task specifications and previously acquired skills influence robustness and task transfer. We further investigate the efficiency and capability of the resulting programs when deployed without involving an online agent for decision-making. Across eight real-world tasks, PyRUA-REAL achieves an average success rate of 91.1%. In complementary evaluation on 42 tasks from the RoboDojo benchmark, it achieves an average success rate of 84.4%. This study provides empirical guidance for turning physical exploration into reusable robot skills that support continued improvement and robust, efficient deployment.

## 1 Introduction
Large language models can translate task instructions into robot programs that combine perception, spatial reasoning, and feedback control [ 11 , 6 ] . Coding agents powered by models such as GPT-6-Astra extend this interaction by executing code, inspecting observations, and adapting subsequent actions through execution feedback [ 16 ] . These capabilities make code a practical interface between high-level reasoning and physical behavior. They also raise a question beyond completing an individual task: How can coding agents turn physical interaction experience into robot capabilities that persist and improve across successive attempts? Experience-based adaptation and iterative code modification offer ways to improve agents while keeping foundation model parameters fixed [ 15 , 24 ] . In robotics, recent work has explored skill and agent-harness evolution in simulation [ 18 ] , simulation-based practice followed by physical deployment [ 20 ] , and policy improvement through direct robot interaction [ 22 , 19 ] . Building on these developments, we study embodied recursive self-improvement (RSI) as a process in which execution experience informs code revisions and is retained as memory and reusable skills for subsequent exploration. Our focus is an empirical account of this process in real-world manipulation, tracing how capabilities are acquired, refined beyond first success, and converted into programs for deployment. Physical exploration presents challenges at several levels. Agents must decide which experiments to run, which implementation details to revise, and when to reconsider the underlying approach. Repeated local changes may leave an unsuitable perception or control strategy intact. Execution feedback is also ambiguous: an apparent task failure can originate in motion, perception, or the procedure used to verify success. Moreover, success under one configuration does not establish robustness to changes in object positions, orientations, or task requirements. Retaining a successful implementation therefore raises further questions about its reuse on new tasks and its ability to operate without repeated online agent decisions. Understanding embodied RSI requires examining these aspects of the improvement process alongside task success. We present PyRUA-REAL (Python-based Robot-Use Agent for Robot Exploration and Adaptive Learning) as an embodied RSI framework for this study (Figure 1 ). A researcher agent selects experimental objectives and technical approaches, while an engineer agent implements programs, executes robot trials, and diagnoses failures. Their interaction connects local code improvement with task-level reassessment. A persistent repository records environmental facts, attempted approaches, execution outcomes, and reusable implementations, allowing later experiments to build on earlier experience while model parameters remain fixed. For deployment, the resulting code can be frozen and executed without runtime language-model calls, while still responding to live observations through its perception, control, and recovery routines. This separation enables us to study both the process of developing robot capabilities and the behavior of the programs that retain them. Our experiments cover eight manipulation tasks on a dual-arm Franka platform, spanning reasoning, long-horizon execution, precise contact, deformable objects, and bimanual coordination. Recorded development success averages 91.1% across tasks. These rates aggregate attempts across code revisions; frozen-program performance is evaluated separately. Complementary evaluation on 42 RoboDojo tasks yields 84.82% success, averaged equally over five capability groups, compared with reported results of 50.35% for PyRUA-Lean and 22.48% for GPT-6-Astra. Our main contributions can be summarized as: • An empirical study of skill acquisition and continued improvement through real-world interaction. Across eight physical manipulation tasks, we trace how coding agents turn exploration experience into executable robot skills and improve them beyond first successful rollout, documenting gains and trade-offs in task completion, execution time, and placement precision across program revisions. • Case studies on the factors shaping embodied RSI. Through comparative experiments and diagnostic case studies, we examine how agent coordination, execution feedback, explicit task requirements, and previously acquired skills affect revision efficiency, robustness, and transfer to new tasks. • An evaluation of the resulting robot capabilities and their deployment costs. Real-world evaluations compare frozen programs with online agent execution, quantifying execution-time benefits and identifying situations that still require online assistance. Complementary evaluation on 42 RoboDojo tasks measures performance across five capability groups against reported baselines.

3.1 Problem Formulation We study how executable robot policies improve through environment interaction while foundation model parameters remain fixed. Improvements persist as reusable skills and experience. (1) The program may incorporate perception, planning and feedback control. A persistent experience repository \mathcal{M} stores previous programs, experimental results, failure analyses, and their applicability conditions to support subsequent improvement.
