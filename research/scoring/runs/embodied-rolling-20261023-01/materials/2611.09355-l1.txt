# HiMEM: Hippocampus-Inspired Memory Consolidation, Pruning, and Composition for Vision-Language-Action Models in 3D Scenes

## Abstract
Memory plays a crucial role in long-horizon task execution and cross-task generalization for Vision-Language-Action (VLA) models operating in complex 3D scenes. However, existing VLA memory mechanisms suffer from memory noise, particularly in complex 3D scenes, as stored episodic memories contain extensive redundant details about scene layouts, object configurations, and robot-specific states, which obscure generalizable manipulation principles and hinder cross-task transfer. To address this challenge, we first introduce a hippocampus-inspired memory consolidation mechanism that synthesizes extensive episodic experiences into a compact set of essential semantic memories, enabling VLA models to derive generalizable principles from practical experience. Second, we propose an episodic memory pruning mechanism that removes redundant episodic memories whose contents are captured by consolidated semantic memories, thereby increasing effective memory capacity and improving long-horizon task execution. Finally, to handle complex task scenarios, we develop a flexible memory composition mechanism that jointly leverages multiple episodic and semantic memories to enhance cross-scenario generalization. Experiments on LIBERO, LIBERO-Plus demonstrate the effectiveness of HiMEM across different VLA backbones, improving the average success rate of pi_0 from 91.88% to 98.20% on LIBERO.

## I Introduction
Vision-Language-Action (VLA) models have made substantial progress in robotic manipulation of 3D environments by unifying visual perception, language understanding, and action generation [ 1 , 2 , 3 ] . However, long-horizon robotic manipulation typically involve multiple interdependent manipulation steps, requiring robots to continuously track environmental states and retain historical interaction information [ 4 , 5 ] . Therefore, effective long-term memory mechanisms are crucial for improving the long-horizon robotic manipulation and cross-task generalization capabilities of VLA models. Most existing long-term memory mechanisms resemble episodic memory in the human brain, retaining extensive scene layouts, object states, and action outcomes from specific interactions, thereby providing rich information for robots to reuse historical experiences [ 7 , 8 , 9 , 10 , 11 ] . However, especially in complex 3D scenes, these episodic memory records also contain substantial details that are irrelevant to the current task or specific to particular scenarios (i.e., memory noise, as shown in Fig. 1 ) and lack explicit guidance of generalizable manipulation patterns, resulting in limited transferability of experience across tasks [ 6 ] . In contrast, humans possess an efficient memory system for interacting with 3D environments, which provides inspiration for addressing the aforementioned problem. Specifically, complementary learning systems (CLS) theory [ 12 ] suggests that the hippocampus rapidly encodes and retains specific experiences, whereas the neocortex gradually develops generalizable semantic knowledge by integrating information across experiences. This division of labor enables the memory system to preserve information about specific events while identifying shared patterns across different experiences. Inspired by above mechanism, we propose HiMEM, a long-term memory framework for VLA models in 3D scenes. ❶ First, HiMEM introduces a meta-semantic memory consolidation method inspired by the complementary mechanisms of the hippocampus and neocortex. The hippocampus-inspired module identifies recurring manipulation patterns and their applicable conditions across different experiences. The neocortex-inspired module then consolidates these patterns into compact meta-semantic memories that represent environmental and object conditions, reusable manipulation strategies, and their success probabilities, enabling VLA models to derive a compact set of abstract guiding principles from extensive concrete manipulation experiences. ❷ Second, we propose an episodic memory pruning mechanism that partially removes the corresponding episodic memories once relevant semantic memories have been established, thereby increasing the memory capacity limit. ❸ Finally, to address complex task scenarios, we introduce a mechanism for flexibly combining and utilizing multiple episodic and semantic memories. Specifically, meta-semantic memories provide manipulation patterns with conditional applicability, while episodic memories supplement information about specific manipulation procedures and state transitions. By incorporating visual observations of the current task, task instructions, and characteristics of the manipulated objects, the proposed mechanism flexibly combines memories at different levels of abstraction (i.e., episodic and semantic memories) to enable cross-scenario generalization in long-horizon tasks. Experimental results demonstrate that, across the four standard LIBERO suites, our method improves the average success rates of three mainstream memory-free VLA models, \pi_{0} , \pi_{0.5} , and OpenVLA-OFT, by 6.32, 3.65, and 2.15 percentage points, respectively. Compared with ECHO [ 6 ] , HiMEM further improves the average success rates by 0.90, 1.17, and 0.57 percentage points on \pi_{0} , \pi_{0.5} , and OpenVLA-OFT, respectively. ## III Methodology
HiMEM is a long-term memory framework for VLA policies that integrates continuous hierarchical episodic memory with cross-episode meta-semantic consolidation. It segments executions into subgoals, encodes them in hyperbolic space, and organizes verified experiences into a general-to-specific hierarchy. Episodic memory supplies task-relevant successful manipulation priors; meta-semantic memory summarizes success and failure evidence into condition–operation rules that modulate prior aggregation and residual injection. Together, they condition action generation through lightweight backbone-specific projections. The overall architecture is illustrated in Fig. 3 . III-A Episodic Memory Construction and Organization HiMEM builds upon ECHO’s subgoal-level episodic memory representation, partitioning continuous executions into reusable manipulation segments. Qwen2-VL-7B-Instruct proposes task decompositions and subgoal boundaries. Each segment is represented as M_{i}=(z_{i},g_{i}^{\mathrm{task}},s_{i},a_{i},c_{i},y_{i},e_{i}) , containing its hyperbolic embedding, global task, local subgoal, actions, scene conditions, execution outcome, and supporting evidence. Local outcomes are independently verified using simulator state predicates or human-verified real-robot records, avoiding incorrect attribution of whole-task failures to individual subgoals. To organize these experiences, a hyperbolic autoencoder maps backbone hidden states h_{i} into a Lorentz space with 512 spatial dimensions, yielding z_{i}=E_{\phi}(h_{i}) . Feature reconstruction and task–subgoal entailment constraints support hierarchical representations, organizing episodic memories into a general-to-specific tree. Successful segments provide retrievable manipulation priors, while both successful and failed experiences preserve contextual and outcome evidence. This episodic memory structure serves as the foundation for the subsequent semantic consolidation, redundancy pruning, and memory composition mechanisms.
