# AgenticJevNav: Agentic Object Search and Navigation via Event-Driven Verification

## Abstract
Agentic navigation must maintain goals and adapt actions from incomplete evidence despite execution failures and delayed inference. We present AgenticJevNav, which links goal-directed planning, evidence memory, event-triggered verification, and bounded execution. The Agent plans from RGB, odometry, memory, and feedback, retaining goal ownership while authorizing a bounded action set. Jev reviews structured evidence after blocked/failed execution or two consecutive low-progress segments. Version, freshness, and once-only checks govern decision application. A single executor and independent RGB reflex constrain motion. Goal revisions revoke obsolete requests and actions before replanning. Across six simulated task families, AgenticJevNav achieves 73.33% SR over 60 trials, 21.67 percentage points above the next-best Agent-only aggregate control under differing historical protocols. A real-world GENISOM L1 quadruped deployment achieves 70.0% success over 30 trials, including bounded search reporting. Together, the simulation and physical-robot results demonstrate the effectiveness of the proposed architecture, while remaining failures highlight opportunities to improve grounding, approach planning, and runtime.

## I Introduction
Research on embodied navigation spans instruction following and grounding [ 1 , 2 ] , semantic exploration [ 3 , 4 ] , language-model planning [ 5 , 6 , 7 ] , and learned navigation [ 8 , 9 ] . Vision-language models ground natural-language goals in visual observations, while large language models generate structured navigation plans from task descriptions. Learned policies integrate these capabilities into end-to-end systems that map observations to actions. However, these capabilities leave a coordination problem: how should a robot maintain its goal, respond to a lack of progress, and apply delayed decisions as execution and instructions change? When perception is uncertain, when should the system trigger additional verification rather than proceeding with the Agent’s initial judgment? How can the system ensure that decisions produced by remote inference remain valid and authorized when the goal has been revised or execution context has changed? We study when verification is warranted, whether responses remain valid, and how motion can stop before remote inference returns. AgenticJevNav addresses these questions through a versioned evidence interface . The Agent owns the goal and replans from feedback; Jev reviews only authorized actions. A shared consumer checks versions, authorization, freshness, and once-only consumption before execution. An independent RGB reflex can stop forward motion without remote inference. Here, agentic denotes this feedback-driven planning and delegation loop within one robot. Jev has no independent goal authority. We make three contributions to agentic navigation through coordinated planning, verification, and execution: 1. Feedback-driven planning with authorized verification. Feedback-driven planners use environmental feedback to correct actions [ 10 , 11 ] . We further specify when to trigger Jev and which authorized actions it may select. Jev reviews only after blocked or failed execution, or two consecutive low-progress segments, choosing from the Agent’s authorized set. This reduces review overhead while preserving goal ownership. 2. Versioned memory and decision-making for online goal revision. Interactive planning [ 10 , 6 ] and latency mitigation [ 12 ] address feedback and action continuity, respectively, while semantic-map reasoning [ 13 ] and instance-oriented navigation in dynamic environments [ 14 ] organize semantic information for acting. We address the complementary issue of temporal validity after online goal corrections. We bind evidence to mission, revision, skill, and snapshot, and revoke stale requests upon correction. This isolates obsolete responses and maintains authorization consistency with the current task context. 3. Execution that separates remote semantic decisions from local motion constraints. Inference latency affects action continuity [ 12 ] . We integrate RGB veto checks, skill leases, command time-to-live (TTL), and task versions within a single executor. This enables stop/veto actions without waiting for remote responses, and limits the application of invalid commands through revocation and expiry.

Figure 2 illustrates the system architecture. We formulate the task, define versioned evidence and Agent/Jev coordination, and describe local execution below. III-A Problem Formulation Task: Given a natural-language goal g , budget T , and operational boundaries, the robot searches for the instructed instance, reaches it, and stops. In a timed search-report task, it reports not found within scope and budget if no target is found. Inputs: The policy observes o_{t}=(I_{t},\hat{x}_{t},f_{t-1},z_{t}) : RGB, odometry, previous-segment feedback, and local veto status. Simulation uses ideal pose-derived odometry. Hardware uses onboard odometry (Sec. V ). Depth, LiDAR, semantic ground truth, target coordinates, and the navigation mesh are unavailable to the policy. A goal correction increments revision r . III-B Perception and Versioned Evidence The shared state is E_{t}=(g,r,\mathcal{C}_{t},\hat{x}_{t},\mathcal{H}_{t},f_{k},z_{t},q_{t}), (1) where \mathcal{C}_{t} is candidate memory, \mathcal{H}_{t} is bounded decision/execution history, f_{k} is execution feedback, z_{t} is local veto status, and q_{t} records provenance and freshness. Each candidate has the form c=(\mathrm{id},\mathrm{attrs},\mathrm{rels},\mathrm{frame},\tau_{\mathrm{seen}},\mathrm{vis},\mathrm{src},\delta). (2) Here, attributes, relations, and uncertainty \delta are uncalibrated RGB-model outputs. Provenance binds the source frame, timestamp, and request. Memory associates hypotheses only under small pose changes and unique box overlap. Larger viewpoint changes create unconfirmed candidates. History guides search but cannot authorize motion or arrival, which require fresh evidence. Pixel boxes are not converted to world coordinates. The Agent receives bounded memory summaries. Jev sees current semantics, proposal, odometry, and local history. III-C Agent Module: Search and Route Intent The Agent outputs current-image semantics, a primary skill, and an authorized set \mathcal{A}_{k} , including that skill, stop, and replan. Skills are forward motion ( \leq 2.4 m), in-place left/right turns ( \leq 90^{\circ} ), stop, and replan. Reverse/lateral motion is disabled. Before forward motion, the target or passage-reference box center must lie in normalized horizontal interval [0.38,0.62] ; otherwise the robot turns and observes again. Schema/numerical validation allows one same-observation correction before rejecting an invalid output. Each action is replanned from a fresh image. An arrival claim requires a visible, centered target, a primary stop skill, an authorized set \{\mathrm{stop},\mathrm{escalate}\} , and zero translation and yaw commands. It revokes motion and submits the claim directly, bypassing Jev. Independent scoring determines success. Simulator settings are frozen within each cohort. Hardware arrival-policy changes are disclosed in Sec. V . III-D Jev Module: Bounded Judgments After an anomaly, Jev receives structured local evidence, without raw images, and returns five typed judgments: skill routing, success verification, failure detection, recovery routing, and task progress. The program validates their fields and confidence scores and combines routing, failure, and required recovery judgments. Success/progress are retained but do not certify completion.
