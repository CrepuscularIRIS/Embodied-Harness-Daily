# Decide Before You Move: Diffusion-Generated Search Reference for Zero-Shot Open-Vocabulary Object Navigation in Semi-Static Environments

## Abstract
Open-world navigation requires a robot to locate a user-specified target in an indoor scene under open-vocabulary queries. Realistic indoor environments are semi-static: walls and furniture largely persist while smaller objects move, relocate, or vanish between visits. Prior-map systems answer queries from object poses recorded at reconstruction time, which expire as soon as objects move, whereas online methods re-derive where to look from current observations every few steps, often through expensive calls to a vision--language model. Assuming that walls and large furniture do not move, we keep their map to plan paths, but use a target--furniture co-occurrence prior to decide where to search. We present PreNav, an ObjectNav framework on semi-static environments. Rather than invoking a vision-language model at each step, PreNav generates a single global search reference before the robot moves: an LLM converts target--furniture co-occurrence into a spatial prior, a conditional diffusion model turns that prior and the persistent structure into an ordered centerline with a band around it, and the robot approaches the target once it is detected online. Experiments on a Gibson ObjectNav benchmark show that PreNav outperforms a strong online baseline under matched structural priors, using a generator trained only on room-level ScanNet++ scenes and applied to floor-level Gibson without fine-tuning. Real-world experiments under object relocation and open-vocabulary queries further validate the approach.

## I Introduction
Object navigation requires a robot to move through an indoor environment and find a target specified only by a user query [ 1 , 2 ] . Existing methods keep either too much of the building or too little. Prior-map systems answer queries from dense object-level maps [ 3 , 4 ] , whose object poses expire as soon as objects move. Map-free methods use no prior knowledge of the building and decide where to look online, re-deriving candidate regions from current observations every few steps, often through expensive calls to a vision–language model [ 5 , 6 ] . Real buildings are semi-static : walls and large furniture such as wardrobes and tables barely move, whereas objects such as keys and cups change position between visits. Between these extremes, two lines of work handle the semi-static building differently. One follows what changes: systems for changing scenes keep a semantic map of objects and update it online as they move, adding and removing voxels [ 7 ] or tracking whether each object instance is still in place [ 8 ] , yet their search still runs over the whole maintained map, movable objects included. The other builds on what persists: osmAG [ 9 ] , a lightweight, text-based hierarchical map of areas such as rooms and corridors, supports localization [ 10 ] and LLM-based map understanding and navigation [ 11 , 12 ] even when incomplete, and osmAG-LLM [ 13 ] uses it to reliably identify the room that holds a moved or never-mapped target. Within that room, however, the robot can only check candidate locations recorded during mapping, namely viewpoints along the mapping trajectory and past object positions, which need not cover where the target now lies. With the search already narrowed to a room, and tracking every object as it moves requiring continual map maintenance, we ask whether the part of the room that barely changes, its walls and large furniture, suffices to plan where to look, and in what order, before the robot moves. We argue that it does. Real buildings are semi-static: walls and large furniture persist across missions, while movable objects, including the target, may change location. Therefore, instead of continually updating object locations, or treating the environment as a completely unknown scene, we treat only the objects as unknown and rely on the layout of walls and furniture to infer where the target may be. Thus, even if the target has moved, we do not rely on previously recorded target locations. Instead, we use semantic scores between the target and furniture to guide the search: a cup may be near a dining table, whereas a television is unlikely to be near a toilet. We propose PreNav, which uses this prior knowledge of a scene to pre-plan an informed object search for a given query whenever a query arrives. An LLM scores target–furniture co-occurrence once, offline, and the scores are projected onto the mapped furniture as a spatial prior. A conditional diffusion model then turns this prior, the wall raster, and the start pose into what we call the search reference : a globally planned reference path that optimizes the order of where to search in a floor or room. The reference is thus both an order to follow and a region to sweep. Trained on references from a solver for the traveling salesman problem (TSP), the generator produces one in about a second rather than tens of seconds. The robot then follows the reference, detects the target online, and approaches it, without repeated foundation-model calls or query-conditioned global replanning. We evaluate PreNav on an expanded Gibson [ 14 ] ObjectNav benchmark, asking three questions: whether it outperforms online baselines under matched structural priors; how generation efficiency trades against navigation quality when compared with its TSP teacher; and whether it transfers to real-world robots under open-vocabulary queries. As a summary, our main contributions are: • We propose PreNav, an ObjectNav framework for semi-static environments: it guides online search through a search reference that is globally optimized with respect to the known room layout and semantic areas. • We introduce an open-vocabulary interface that projects any user query onto the persistent furniture through LLM-generated co-occurrence scores between the query and each furniture category. As the generator’s only query-dependent input, these scores let a conditional diffusion model plan a search reference for any query without retraining. • We demonstrate zero-shot transfer from room-level ScanNet++ training to floor-level Gibson scenes, without fine-tuning the generator on Gibson. On the six-category benchmark, our method outperforms SGM under matched structural priors and achieves navigation performance comparable to its TSP teacher with an order of magnitude less generation time. We further demonstrate deployment on a real mobile robot with open-vocabulary queries.

## III Methodology
PreNav separates search-reference generation from online perception. When a query comes, the search reference is generated in two steps. First, the furniture-conditioned search prior (Sec. III-A ) computes a spatial prior that encodes where the target is likely to be found relative to known furniture. Second, the diffusion-based global search generator (Sec. III-B ) takes this prior, the persistent wall raster, and the start pose as inputs and generates a single search reference. The robot follows this reference, detects the target online, and then approaches it; subsequent execution requires neither repeated high-level foundation-model calls nor query-conditioned global replanning. III-A Furniture-Conditioned Search Prior In a semi-static environment, the target’s current location is unknown, but its co-occurrence with persistent furniture provides a stable search prior. For example, a book is likely near a bookshelf, whereas an earphone is unlikely to appear near a refrigerator. We capture this through a two-step process: an LLM scores target–furniture co-occurrence, and the resulting weights are projected onto the spatial layout of the mapped furniture. LLM co-occurrence scoring. Let \mathcal{C} denote the vocabulary of the supplied furniture prior. A query q is free-form text that describes the target: an object category such as vase , a description such as tray with fruits , or a broader concept such as computer parts . For every persistent furniture category c\in\mathcal{C} , an LLM is asked how useful c is for finding the target under each of three spatial relations—the target resting on c , contained in c , or merely near c —and returns the three relation scores together with a single search-usefulness score r_{c}(q)\in[0,100] that summarizes them. Only r_{c}(q) enters the prior. We normalize it per query to obtain weights, \alpha_{c}(q)=\frac{\exp\!\big(r_{c}(q)/\tau_{q}\big)}{\sum_{c^{\prime}\in\mathcal{C}}\exp\!\big(r_{c^{\prime}}(q)/\tau_{q}\big)},\qquad\tau_{q}=0.65\,\sigma_{q}, (1) where \sigma_{q} is the standard deviation of \{r_{c}(q)\}_{c\in\mathcal{C}} .
