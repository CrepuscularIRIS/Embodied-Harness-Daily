# ReSight: Task-Driven Self-Improving Memory for Embodied Agents

## Abstract
Robots can use historical observations to answer spatiotemporal queries in familiar environments, but the presence of relevant evidence does not imply that existing tools support the operations a task requires. We introduce ReSight, a task-driven self-improving memory system for embodied agents that expands the capabilities for processing and accessing historical observations as task demands arise. ReSight retains keyframes and their spatiotemporal associations, separating observation evidence from extensible derived fields so that stored observations can be reprocessed for new needs. An execution agent and a coding agent share this memory through different interfaces: the former calls registered tools within a bounded online budget, while the latter uses a programmable workspace and a larger exploration budget to inspect evidence, write programs, and acquire models as needed. To realize capability expansion in ReSight, we develop Explore-Distill-Mount (EDM), which identifies capability gaps from execution and exploration records without task reference answers and converts exploration-derived solutions into reusable memory builders, query tools, and skills, extending memory representations and access capabilities as needed. Experiments on three public benchmarks demonstrate effective base memory access and capability expansion. With the execution model and online budget held fixed within each benchmark, EDM reduces mean position error on OC-NaVQA from 33.10 m to 24.72 m and improves high-level success on FindingDory from 38.3% to 63.8%. With the tools and skill frozen, success still improves by 28.3 percentage points on FindingDory episodes excluded from exploration and distillation. Experiments on real robot patrol memories further demonstrate reuse of these capabilities for subsequent queries and new memories, with fewer online tool calls on average.

## 1 Introduction
Long-horizon robot tasks such as fetching and delivery often begin with a decision about where to go to satisfy a request. In previously visited environments, past observations can inform this choice. Finding emergency equipment requires recalling where it was seen; finding an object that has moved also requires distinguishing observations from different times. Such place selection depends on spatiotemporal question answering over memory, whose outputs can guide subsequent navigation and manipulation. We study tasks whose relevant evidence is already present in retained observations: how can an agent find, interpret, and combine that evidence to answer the current query? Embodied memory takes several forms, including scene graphs for structured queries and visual memories associated with time and position ( Gorlo et al., 2026a ; Hu et al., 2026 ) . Retained keyframes also allow object localization and representation construction to be deferred until query time ( Zhou et al., 2026 ; Maggio et al., 2026 ) . These approaches provide a basis for finding relevant observations, but the computation required by a task may exceed the capabilities of the available tools. Semantic retrieval may return images of a corridor, while distinguishing similar doors requires reading their signs. After retrieving several observations of an object, determining where it stayed longest requires organizing events across time. A task exposes a capability gap when the execution agent cannot readily perform these operations with its existing tools and online budget. We introduce ReSight, which combines revisitable spatiotemporal evidence with extensible memory capabilities. Unlike a fixed memory interface, ReSight can later acquire operations such as text reading, interaction-history reasoning, and object localization by reprocessing observations that are already stored. Its spatiotemporal evidence memory retains selected keyframes and their temporal associations, together with available observations such as poses and depth. Scene and object descriptions, along with visual and text features, form initial semantic fields for retrieval. Subsequent needs can prompt new processing of stored images to derive text, event, or geometric fields while preserving their links to source observations. This late binding allows interpretation and computation to evolve after observations have been stored, and lets memory builders and query tools be developed together for a new task requirement. ReSight separates online response from capability development through two agents (Figure 2 ). The execution agent treats the evidence memory as a database accessed through registered tools, using skills to guide retrieval, inspection, and answering within a bounded online budget. The coding agent treats the same memory as a programmable workspace: it can inspect files and images, write and execute code, and download and install models and dependencies. A separate, larger exploration budget allows it to develop solutions for requirements that are difficult for the current executor. The two agents work with the same evidence, carrying out bounded execution and open-ended exploration, respectively, providing a basis for turning exploration-derived solutions into reusable capabilities for the executor. ReSight implements task-driven capability expansion through Explore–Distill–Mount (EDM). Prior work uses execution traces to improve programs, skills, and memory-management mechanisms ( Lu et al., 2026 ; Lee et al., 2026 ; Zhang et al., 2025b ) . EDM combines execution-side capability gaps with coding-agent exploration traces to extract reusable tools, skills, and memory builders for retained sensor evidence. Builders reprocess stored observations to produce persistent fields and indices; corresponding query tools and skills are mounted on the execution agent so it can use the new capabilities. Our contributions are as follows: • We introduce ReSight, which retains revisitable spatiotemporal observations and provides distinct access interfaces for execution and coding agents, allowing historical observations to be reprocessed for new task demands and memory representations and access capabilities to be extended as needed. • We propose Explore–Distill–Mount (EDM), which identifies capability gaps from execution and exploration records without task reference answers and converts the coding agent’s exploration-derived solutions into reusable tools, skills, and memory builders. • We evaluate ReSight’s base memory access, task-driven capability expansion, and frozen-capability reuse on three public benchmarks and real robot patrol memories. ## 3 Method
ReSight provides a shared spatiotemporal evidence memory with extensible derived fields, accessed through asymmetric interfaces for execution and coding agents. EDM implements capability expansion within this architecture (Figure 2 ). 3.1 Problem Setting Given the robot’s accumulated observation memory \mathcal{M} and a task query q , the system returns an answer y and supporting evidence E_{q} . Task-location queries additionally require a position or candidate place suitable for navigation. We consider tasks whose required information is present in retained observations. A task exposes a capability gap when the current tools, skills, or memory-access mechanisms cannot solve it reliably within the online budget. For example, a room sign may be visible in memory, yet searching images individually can exhaust the call budget, motivating dedicated text extraction and retrieval. 3.2 Spatiotemporal Evidence Memory ReSight anchors memory in retained RGB keyframes and their associated observations and acquisition context. Available data vary with the robot’s sensors and the benchmark, including temporal associations, depth, poses, calibration, and synchronization information. We preserve these records at ingestion, especially information that is difficult to recover reliably from images, for subsequent processing. Let \mathcal{O} denote the retained records, \mathcal{F}^{(0)} the initial fields, and \mathcal{X}^{(r)} the derived fields and indices accumulated after r extensions. The memory is \mathcal{M}^{(r)}=(\mathcal{O},\mathcal{F}^{(0)},\mathcal{X}^{(r)}). (1) Initial fields record or reference observation times and available poses, and include descriptions and features produced during memory construction.
