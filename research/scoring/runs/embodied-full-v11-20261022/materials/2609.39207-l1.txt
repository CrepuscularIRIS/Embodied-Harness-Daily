# ASENA: Self-evolving Agents for Embodied Navigation

## Abstract
We present ASENA, an embodied agent system that enables general-purpose coding agents to program humanoid navigation, manipulation, and interaction. Through a unified robot harness, agents read sensor data, write and execute programs, inspect recorded outcomes, repair failures, and reuse notes and executable skills while keeping their model weights fixed. We also introduce ASENA-VLN, a 4B monocular navigation policy that serves as an optional tool within this programmable system. ASENA-VLN predicts body-frame trajectories for both extended routes and short-horizon behaviors. Its shared vision-language decoder is trained on route instructions, visual question answering, and a newly curated dataset of geometry-derived atomic navigation tasks. As a standalone policy, ASENA-VLN achieves state-of-the-art success rates of 68.7% on R2R and 70.2% on RxR. When integrated with a coding agent, learned navigation improves ASENA's success rate by 11 percentage points on both agentic benchmarks and reduces execution time. Persistent workspace evolution uses simulator feedback to improve success over ten passes through recurring 100-task subsets. Success increases from 72% to 98% on R2R and from 65% to 89% on RxR. On embodied question answering, ASENA achieves state-of-the-art accuracy with fewer interaction steps. On a Unitree G1, we demonstrate search, visual inspection, spatial reasoning, synthesized gestures, and mobile manipulation combining object pickup, carrying, and handoff without a pre-built map. These demonstrations illustrate how online programming extends robot behavior beyond route following and predefined skills.

## 1 Introduction
A useful humanoid robot must do more than reach a destination. If asked to check whether a vending machine contains an item and return with an answer, it must decide where to search, recognize the item, remember the user’s location, and communicate what it found. Retrieving an object from a room also requires planning a grasp, picking it up, carrying it back, and handing it to the user. Navigation is therefore only one part of a larger task whose next step depends on what the robot observes. A learned navigation policy provides movement capabilities, but such requests also require deciding what to inspect, how to act on objects, and what to communicate. These procedures depend on new observations and may extend beyond predefined skills. Coding agents can construct and revise them during a mission through programmatic access to sensing, computation, simulation, and action. Physical deployment also requires feedback tied to outcomes and a persistent workspace for retaining useful procedures. We present ASENA, an embodied agent system that gives coding agents programmatic control of humanoid tasks through a unified robot harness (Fig. ASENA: Self-evolving Agents for Embodied Navigation ). The agent can read sensors, derive geometry, inspect visualizations, and write programs that combine navigation, grasp planning, whole-body motion, and user interaction. Linked execution records let the agent inspect outcomes and revise these programs. A persistent workspace stores notes and executable skills. The system can improve through program revision while keeping its model weights fixed. Learned policies can further expand this programmable toolset when suitable training data are available. Delegating motion to a specialized policy reduces repeated agent decisions and supports navigation behaviors that are difficult to specify geometrically. We develop ASENA-VLN, a 4B monocular navigation policy trained on route instructions and geometry-derived navigation atoms. Building on vision-and-language navigation (VLN) [ 2 ; 20 ; 55 ; 8 ; 42 ] , ASENA-VLN predicts body-frame trajectories for both extended routes and short-horizon goals, such as approaching an object or passing through a doorway. We curate a new atomic navigation dataset that directly supervises these reusable, fine-grained behaviors and complements conventional route-level training. The policy remains an optional tool: a program may call it directly, combine it with geometric navigation, or complete a task using other available operations. We make three contributions. First, we introduce a robot harness that lets coding agents program humanoid navigation, manipulation, and interaction while retaining executable skills and experience. Second, we develop a state-of-the-art monocular navigation policy that supports both route following and reusable atomic skills. Third, we show through evaluation that workspace evolution improves task performance while model weights remain fixed. We evaluate navigation and embodied question answering (EQA) in simulation and demonstrate navigation, mobile manipulation, and user interaction on a real-world Unitree G1 robot operating without a pre-built map.
