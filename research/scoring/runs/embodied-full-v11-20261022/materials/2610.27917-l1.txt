# EventSync: Event-Driven Memory Updates for History-Dependent Manipulation

## Abstract
History-dependent robotic manipulation requires task context and interaction history, as the current observation alone is insufficient to determine the next action. Hierarchical frameworks use task memory for high-level subgoal reasoning and low-level policies for execution. However, memory updates require accurate completion assessment: similar observations may correspond to different execution phases, and prematurely recording completion can mislead subsequent subgoal reasoning. We present EventSync, a hierarchical framework that coordinates task reasoning and action execution through event-driven memory updates. A vision-language model generates subgoals from task plans and interaction history, while a vision-language-action model executes them. A lightweight Event Monitor combines visual observations with end-effector trajectories to determine whether the current subgoal is complete. The framework records the current subgoal in its completed-subgoal history and triggers subsequent reasoning only after obtaining completion evidence. With visual history in the executor, EventSync achieves 64.5% overall success on RoboMME, exceeding the best baseline reported in the benchmark by 20.0 percentage points. Further analysis shows that this update mechanism helps build a reliable completed-subgoal history. Experiments on four real-robot tasks with different memory requirements validate the framework's effectiveness in real-world robotic manipulation.



## I Introduction
Real-world robotic manipulation often requires decisions based on previous interactions. In assembly, tidying, and everyday service tasks, earlier requirements and interaction outcomes can determine what the robot should do next [ 19 ] . History may also be needed to interpret the current phase of an ongoing operation. Such tasks are non-Markovian with respect to instantaneous observations: robots must retain task context and interpret execution history to select subsequent goals and actions [ 18 , 31 , 11 , 9 ] . Prior work introduces memory into vision-language-action (VLA) models to use historical information [ 23 , 31 , 39 , 38 ] , while other approaches assign task memory to a high-level reasoner that guides action execution through subgoals [ 36 , 7 ] . We argue that hierarchical frameworks are well suited to history-dependent manipulation. The limited performance of hierarchical methods reported in existing evaluations [ 9 ] motivates us to revisit memory updates within this framework. As illustrated in Fig. 1 , an instruction issued by the high-level reasoner does not imply that the corresponding operation has been completed, and similar current poses may correspond to different execution phases. If an unfinished operation is recorded as completed, subsequent reasoning may rely on an incorrect estimate of task progress and advance to the next subgoal prematurely. For task-memory updates, completion judgments must be accurate enough to avoid premature goal transitions and timely enough to keep subsequent reasoning and actions aligned with execution progress. Fig. 1: Execution-phase ambiguity and erroneous memory updates. The pump head occupies the same position during pressing (a) and release (c), but must move downward in (a) and upward in (c). From (a), continuing to the bottom and returning to the fully released position completes the first pump. Recording a return before reaching the bottom as completion incorrectly triggers the second pump, causing the progress recorded in memory to exceed actual execution progress. We propose EventSync , a hierarchical framework that coordinates task reasoning and action execution through event-driven memory updates. A Memory Reasoner built on a vision-language model (VLM) obtains a task plan and combines it with interaction history to generate subgoals, which a VLA-based Action Executor executes. EventSync maintains an event state for the current operation, and a lightweight Event Monitor with 87.39M total parameters estimates completion from visual observations and end-effector trajectories. The framework adds the current subgoal to the completed-subgoal history and triggers high-level reasoning for the next subgoal only after obtaining completion evidence. With visual history in the executor, EventSync achieves a 64.5% overall success rate on RoboMME, exceeding FrameSamp+Modul, the best baseline reported in the benchmark, by 20.0 percentage points [ 9 ] . Our variant without visual history in the executor achieves 94.0% on SwingXtimes, compared with the 7.3% reported for the hierarchical framework GroundSG + QwenVL [ 9 ] . Analysis of execution records further shows that updates guided by completion evidence help reduce premature progression and build a reliable completed-subgoal history. Experiments on four real-robot tasks further demonstrate the effectiveness of combining task-memory reasoning with event-driven memory updates. Our contributions are as follows: • A hierarchical memory framework for history-dependent manipulation. We introduce EventSync, in which a high-level reasoner manages task memory and generates subgoals, a low-level policy executes actions, and an independent lightweight monitor provides completion feedback. • Event-driven task-memory updates. We design a lightweight Event Monitor that combines visual observations with end-effector trajectories to assess operation completion, using the resulting evidence to trigger updates to the completed-subgoal history and subsequent high-level reasoning. • Empirical evaluation in simulation and on real robots. We evaluate EventSync on the RoboMME simulation benchmark and real-robot tasks to assess its effectiveness in history-dependent manipulation, with comparisons and ablations examining the role of event-driven memory updates.
