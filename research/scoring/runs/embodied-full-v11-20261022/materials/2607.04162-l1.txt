# ACE: Agentic Control for Embodied Manipulation via Zero-shot Workflow Reasoning

## Abstract
General-purpose manipulation requires both semantic reasoning over task constraints and reliable execution of contact-rich actions. We present ACE, an agentic manipulation harness that composes a high-level language agent with a reusable mask-conditioned visuomotor policy. Given an open-ended instruction, the agent solves semantic constraints, binds objects to destination roles, and decomposes the task into executable transfers represented by tracked pick-and-place masks. Execution feedback supports outcome assessment, re-grounding, and retry, while persistent object and task context preserves earlier associations when manipulation changes visible cues. We evaluate ACE on two physical multi-step tabletop tasks, Semantic Formula Assembly and Constraint Retrieval. The visuomotor policy is trained only on generic pick-and-place demonstrations and reused without complete demonstrations of either evaluation task, enabling task-level zero-shot composition. Across 20 randomized trials per task, ACE achieves 70% and 80% success, respectively, compared with 55% and 70% without persistent context. These results suggest that an agentic harness can extend a primitive-trained manipulation policy to semantically distinct tasks through explicit object-destination interfaces and closed-loop execution feedback.

## I Introduction
Fig. 1: Semantic task composition in ACE. Different task constraints produce object–destination assignments that share a tracked mask interface and a learned pick-and-place policy. Persistent context retains earlier object and task information for assessing outcomes when manipulation changes visible identifying cues. Masks and cubes are schematic; the full system is shown in Fig. 2 . Natural language provides an intuitive interface for robotic control, allowing users to specify goals at the task level. Executing these goals requires connecting semantic constraints to physical actions [ 1 , 2 , 3 ] . Instructions may define relationships that several objects must jointly satisfy, alongside the spatial roles those objects must occupy. The robot must resolve these relationships, execute the corresponding transfers, and assess the resulting arrangement. In Semantic Formula Assembly, the agent selects number and operator cubes that jointly satisfy a requested arithmetic relation, assigns them to operand and operator slots, and checks the expression realized by their placement. Constraint Retrieval maps selection conditions to eligible objects and their destinations. These tasks share a manipulation primitive while requiring different semantic decisions. Formula assembly specifically couples constraint solving, role-to-location binding, and verification of a relation expressed by several physical objects. Learned manipulation policies provide reusable physical skills [ 4 , 5 ] , and language-model agents can compose perception and control calls while incorporating execution feedback [ 6 , 7 ] . Each semantic decision must identify both an object and its destination, and their image regions must be updated as execution changes the scene. Manipulation can also alter the evidence available for checking completion: a cube may turn so that its identifying pattern is no longer visible. This motivates retaining both current spatial targets and earlier object context. We present ACE ( A gentic C ontrol for E mbodied manipulation), a framework that connects semantic workflows to learned pick-and-place execution through unified, tracked object-and-destination masks . Given an instruction, the agent generates semantic sub-goals and invokes two robot-facing skills: MaskInterface grounds the active sub-goal, and PickPlace executes the corresponding transfer. A single mask assigns distinct pixel values to the pick object and place region. Tracking updates these regions during execution, and the resulting mask conditions a reusable vision-action policy. The object–destination assignment connects these task requirements to execution: semantic roles specify the intended transfer, and the tracked mask supplies its current image regions. ACE targets task-level zero-shot composition . The same controller, trained on generic pick-and-place demonstrations, executes both tasks without full-task demonstrations of either evaluation task. The agent composes object selection, destination assignment, and sequencing at inference (Fig. 1 ). ACE separates live workflow and tracking state from persistent object and conversational context. Current masks specify where to act; retained context makes earlier object associations and task information available when assessing the resulting scene. After an attempt, the agent checks the observation and execution report against the active sub-goal, then advances or refreshes grounding. We evaluate this workflow on two tasks and ablate persistent context while keeping the DP controller and live state fixed. Our contributions are: • A framework connecting task-level constraint solving, object–destination role binding, and learned pick-and-place execution through a shared controller. • An execution interface combining tracked pick/place regions with persistent object and task context for grounding and outcome assessment as manipulation changes the scene. • A physical evaluation achieving 70% and 80% success on Semantic Formula Assembly and Constraint Retrieval, with matched visual-input and persistent-context ablations and qualitative analysis of completion uncertainty after cube rotation.
