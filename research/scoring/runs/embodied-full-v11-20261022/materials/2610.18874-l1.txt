# ChunkAct: Action Chunking for Agentic Robotics

## Abstract
Agentic robotics places a large language model (LLM) agent in the robot control loop, where it composes perception, motion, and vision-language-action (VLA) tools under the guidance of a memory and thereby generalizes to new tasks without retraining. This generality comes at a steep price in efficiency. Every primitive requires a round of LLM reasoning over the full interaction history, so the cost of an episode grows with the number of primitives. We find this reasoning largely redundant: once a sub-goal is chosen, its primitives follow a routine already prescribed by memory. We present ChunkAct, which introduces action chunking to agentic robotics. Online, a single call launches a chunk of chained primitives, which executes autonomously and returns control only upon failure. Offline, ChunkAct compiles the memory into these chunks, so execution is memory-free at test time and the planner is reserved for decisions that require reasoning. LLM computation therefore scales with the number of decisions rather than the number of primitives. On LIBERO-Pro, ChunkAct improves task success by 5.0 points over the state of the art in agentic robotics while requiring 2.9x fewer LLM calls, 4.4x fewer input tokens, and 2.3x fewer output tokens.

## 1 Introduction
Figure 1: ChunkAct introduces action chunking to agentic robotics, improving both task success and efficiency. Top: prior methods invoke the LLM planner once per primitive, so the number of LLM calls and the context length grow with every step. Bottom: ChunkAct invokes the planner once to launch an action chunk, which executes autonomously and returns a typed error only upon failure. Right: ChunkAct gains both task success and efficiency. Agentic robotics has emerged as a new paradigm for robot manipulation ( Liang et al., 2023 ; Kumar, 2026 ; Fu et al., 2026 ; Tsui et al., 2026 ; Zhang et al., 2026c ; Jia et al., 2026 ; Xu et al., 2026b ; Xu et al., 2026a ) . Rather than training a policy that maps pixels and language directly to motor commands ( Brohan et al., 2023a ; Kim et al., 2024 ; Black et al., 2024 ) , it places a large language model (LLM) agent in the control loop and equips it with perception, motion, and vision-language-action (VLA) tools, together with a memory of what has worked before. At each step, the agent observes the scene, consults the memory, reasons, and issues a single tool call ( Figure 1 , top). Because each task is composed by reasoning rather than learned from demonstrations, the agent handles new tasks without retraining and succeeds where end-to-end policies break down. For example, with no robot-specific training, GPT-6 Astra driven through a generic agent harness completes a real-arm pick-and-place task in 19 of 20 trials ( OpenAI, 2026 ; Menon et al., 2026 ) and ranks above every public policy on the RoboDojo benchmark ( Zhang et al., 2026b ) , which illustrates the generalization this paradigm affords. However, this generalization comes at a steep price in efficiency. The planner acts through primitives, i.e., robot skills invoked as tool calls, each of which requires a dedicated round of LLM reasoning. Every such round reprocesses the full interaction history, and reasoning models further consume output tokens before responding ( Sui et al., 2025 ) . Consequently, the number of calls and output tokens scales linearly with the number of primitives in an episode, while input tokens scale quadratically ( Kapoor et al., 2024 ; Kim et al., 2026a ) , as illustrated in Fig. 1 Top. For instance, a single pick-and-place task requires 24.2 LLM calls and 2.2M input tokens on average, costing about $22 per episode with GPT-6 Astra and still $11 even with the cheaper GPT-5.5. As tasks grow longer, this overhead quickly dominates the cost of execution, hindering the scalability of LLM-based agents. To address this inefficiency, we analyze the agent’s behavior and find that LLM reasoning is frequently redundant. Once a sub-goal is selected and its targets are localized, the subsequent primitives follow a fixed routine already encoded in memory, such that each additional call merely reproduces a decision that has already been made. Although a single read of memory suffices to capture this routine, the LLM tends to deliberate over each step and constantly returns to memory for guidance. Furthermore, the memory retrieval and LLM reasoning become less reliable as the context grows ( Liu et al., 2024 ; Laban et al., 2026 ) . This overhead could therefore be eliminated by compiling memory into generalizable action sequences that execute without the planner’s step-by-step involvement. This concept also echoes the action chunk Zhao et al. (2023) in robotics. Building on this observation, we propose ChunkAct (Action Chunking for Agentic Robotics), which consists of two complementary components: chunked execution at test time and memory internalization offline. At test time, ChunkAct introduces action chunking to agentic robotics. It composes the primitives that realize a sub-goal into an executable chunk, which the planner invokes with a single call and which then runs to completion autonomously. This design confines the LLM to where reasoning is genuinely required: understanding the physical scene, diagnosing failures, and redirecting the plan. To support this, a failed chunk returns a typed exit that specifies the failed primitive along with an error log, providing the planner with structured feedback for recovery. In this way, LLM computation scales with the number of decisions rather than the number of primitives (See Fig. 1 Bottom). Offline, ChunkAct builds these chunks as generalizable routines with memory compiled into them. The parameters and procedural knowledge that govern each chunk are compiled from memory before deployment, making its actions inherently memory-conditioned. As a result, chunks run memory-free at test time, eliminating frequent memory retrieval and further improving the efficiency of the LLM. Together, these two components improve both efficiency and performance. By substantially reducing the number of LLM calls and the length of the context, ChunkAct lowers the overall cost of each episode. Meanwhile, because the planner reasons over a concise context and memory is internalized throughout execution, ChunkAct also achieves higher task success rates (See Fig. 1 Right). To summarize, our contributions are threefold. • To our knowledge, ChunkAct is the first LLM agent for robot manipulation that commits to a chunk of chained perception and control primitives per call rather than to a single primitive. • ChunkAct compiles memory offline into generalizable action chunks, enabling memory-free execution at test time and reserving the LLM for decisions that genuinely require reasoning. • Compared with the previous SOTA agentic robotics approach, ChunkAct improves success by 5.0 points on LIBERO-Pro, while requiring 2.9 \times fewer LLM calls, 4.4 \times fewer input tokens, and 2.3 \times fewer output tokens. It also exhibits strong zero-shot transfer capability.
