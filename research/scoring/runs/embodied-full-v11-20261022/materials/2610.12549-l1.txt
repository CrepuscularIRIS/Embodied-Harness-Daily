# Fly-by-Code: Embodied Coding Agents for Aerial Manipulation with Active Visual and Physical Feedback

## Abstract
Embodied coding agents construct robot policies from natural-language instructions by generating executable programs and refining them from execution feedback. This refinement assumes that execution feedback reveals whether the task succeeded and, after a failure, provides sufficient evidence to guide program revision. Aerial manipulation violates this assumption in two ways. Payload constraints restrict onboard camera coverage and leave task-critical outcomes outside the robot's view (partial observability), while strong dynamic coupling and limited control margins make physical interactions fragile (limited interaction robustness) and leave failure causes unresolved. Re-examining the same feedback cannot recover observations that were never collected or separate failure causes that the available evidence does not distinguish. To acquire this missing evidence, we introduce Active Feedback (AF), an active "View and Probe" framework. When execution feedback leaves unresolved questions, the agent synthesizes a separate diagnostic program that runs in simulation to inspect unseen outcomes from informative viewpoints (View) or test hypotheses about failure causes through targeted physical interactions (Probe). Across six simulated aerial manipulation tasks with 60 trials per condition, AF reduces false completion declarations from 25 to 5 and raises final task success from 31.7% to 75% compared with terminal feedback under the same coding-agent configuration and task-execution limit. Using shared robot APIs, task programs refined with AF in simulation run on a physical aerial manipulator without task-program source-code modification and complete multi-stage manipulation tasks in the real world. These results show that executable diagnosis fills gaps in execution feedback for embodied coding agents, improving both completion assessment and program refinement in aerial manipulation.

## 1 Introduction
Embodied coding agents provide a promising approach to task-level coordination by translating natural-language instructions into executable programs that combine general control flow and computation with calls to robot perception and action APIs ( Liang et al., 2023 ; Chen et al., 2024 ; Fu et al., 2026 ) . In an iterative refinement loop, the agent executes a program, examines execution feedback, and revises it until it determines the task is complete. This refinement implicitly assumes that execution feedback provides sufficient evidence to assess the task outcome and, when execution fails, to identify how to revise the program. This assumption breaks down under two challenging conditions: partial observability and limited interaction robustness. Partial observability can leave task-critical outcomes outside the robot’s observations, while failures arising from physical interaction limitations can be difficult to distinguish from perception or manipulation errors. We refer to these two gaps in execution feedback as missing outcome observations and unresolved failure causes , respectively. Re-examining the same feedback cannot supply observations that were never collected or resolve failure causes that the available evidence does not distinguish. Effective refinement therefore requires the agent to identify what additional evidence is needed and how to acquire it. Aerial manipulation amplifies both limitations of execution feedback. An aerial robot equipped with a manipulator must physically interact with the environment while maintaining flight ( Ollero et al., 2022 ) . Spatially extended tasks can exceed the coverage of a fixed external camera, leaving the agent dependent on egocentric onboard sensing whose viewpoint changes with robot motion. At the same time, limited control margin and disturbances from manipulator motion and interaction wrenches can produce failures ( Yadav et al., 2025 ; Hwang et al., 2025 ) that are difficult to distinguish from perception or manipulation errors. For example, an empty gripper after a placement attempt does not reveal whether the object reached the target, while a failed door-opening attempt may not reveal whether the grasp failed, the commanded motion was inappropriate, or the platform lacked sufficient physical capability. Resolving these gaps requires new evidence: choosing a viewpoint that reveals an unseen outcome or performing a targeted physical interaction that tests a specific failure hypothesis. Motivated by this observation, we introduce Active Feedback ( AF ), an explicit post-execution diagnostic stage . Rather than immediately revising the task program based on existing execution feedback, AF first lets the agent generate and execute a separate diagnostic program to gather evidence for unresolved questions. Using the same robot APIs as the task program, the diagnostic program can move to informative viewpoints to acquire missing outcome observations ( View ) or perform targeted physical interactions in simulation to test hypotheses about unresolved failure causes related to interaction behavior or embodiment constraints ( Probe ). The resulting observations and measurements are returned to the same agent, providing additional evidence for both completion assessment and subsequent program revision. Existing coding-agent systems obtain evidence through multimodal execution feedback ( Fu et al., 2026 ) , per-primitive traces ( Lu et al., 2026 ) , task-specific verification procedures ( Xiao et al., 2026 ) , or information-gathering actions embedded within task execution ( Fu et al., 2026 ) . AF instead synthesizes an attempt-specific diagnostic procedure after execution, separately from task evaluation. AF uses the same prompt across tasks, while the agent generates a diagnostic program for each attempt to investigate unresolved questions. By decoupling diagnosis from task progress, AF gives the agent freedom to select actions for their information value rather than their immediate contribution to task completion. Task outcomes are evaluated before diagnosis, and the environment resets before the next task attempt, so diagnostic actions contribute evidence without earning task credit. Across six aerial manipulation tasks in two simulated environments, AF achieves 75% final task success, outperforming terminal (31.7%) and execution-trace (48.3%) feedback under the same agent configurations and execution limits. These results show that additional observations and interaction evidence improve program synthesis beyond existing execution-feedback baselines. We analyze task progress across refinement iterations, evaluate AF across models and interfaces, and examine how diagnostics inform program revisions. Finally, we investigate the real-world transferability of our approach by deploying the synthesized programs on a physical aerial manipulator. Because simulation and hardware share task-level APIs, these programs run on our custom hardware without source-code changes, even though the underlying sensing and control implementations differ. The resulting programs repeatedly complete two multi-stage tasks, 2-Objects Pick-and-place and Cabinet, despite differences between the simulated and physical scenes and variations in initial robot position and heading across trials (Figure 1 ). In summary, our work makes the following key contributions: • We characterize two limitations of execution feedback for embodied coding agents: missing outcome observations and unresolved failure causes , which hinder completion assessment and program revision. • We introduce Active Feedback (AF), a post-execution diagnostic stage within a simulation-based program-refinement loop. At this stage, the agent synthesizes an attempt-specific executable program to acquire evidence through informative viewpoints that supply missing outcome observations ( View ) and targeted physical interactions that test hypotheses about unresolved failure causes ( Probe ). • We evaluate AF in aerial manipulation. Across six simulated tasks, AF improves final task success to 75%, compared with 31.7% for terminal feedback and 48.3% for execution-trace feedback, while also improving completion assessment. We further demonstrate repeated physical execution of simulation-synthesized task programs through shared robot APIs without task-program source-code modification. To the best of our knowledge, this is the first study of embodied coding agents for aerial manipulation .
