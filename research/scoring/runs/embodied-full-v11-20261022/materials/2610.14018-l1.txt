# RoboHarness: A Simple Harness Outperforms VLA and World Action Models

## Abstract
The rise of large language models (LLMs) has opened a path toward generalist embodied AI, raising the question of how LLMs can act in the physical world. One straightforward approach is training the model to generate actions: collect robot-action data and video demonstration, refine LLM architecture with an action head, and train a vision-language-action (VLA) model at scale. However, we argue that coding agents have the potential to realize generalist embodied manipulation. All they need is a simple yet effective robot harness. We present RoboHarness: a robotic harness that gives LLM agents a visual-geometric control panel so that they can directly understand and invoke embodied tasks. With RoboHarness, Qwen3.8-Flash-Next outperforms state-of-the-art VLA models on BEHAVIOR Challenge 2025 tasks. The implementation is open source.

## 1 Introduction
The emergence of large language models (LLMs) opened a path towards generalist robot manipulation. The community has explored many ways to make use of LLM for planning, visual understanding, physical reasoning, and spatial reasoning to achieve generalizable robot manipulation. Yet an LLM’s world knowledge lives in a textual space. A bridge between the LLM and the physical world is therefore required: One straightforward approach is training the model to generate actions. VLA models try to make the model output end-effector actions directly. Actions may be encoded into the vocabulary for autoregressive generation, as in RT-2, OpenVLA, and FAST ( Brohan et al., 2023 ; Kim et al., 2025b ; Pertsch et al., 2025 ) , or grouped into flow-matching chunks, which are later produced by an action head appended to the LLM ( Black et al., 2025b ; Bjorck et al., 2025 ) . This representation can express arbitrary robot actions, but it requires substantial robot-action data and additional post-training. Such data are difficult to collect and scale to the diversity of real-world objects, scenes, and tasks. This difficulty has motivated world-action models (WAMs), which seek to improve generalization by learning action-conditioned models of how the world changes ( Zhao et al., 2026 ; Wang et al., 2026 ; Li et al., 2026 ) . We take a different view. An LLM already has strong capabilities for task decomposition, planning, spatial reasoning, and tool use. The main challenge is therefore not to train the LLM to generate a larger set of actions, but to provide a simple and sufficiently complete interface that connects these capabilities to the physical world. Existing work provides evidence for this view: Packaging embodied subtasks, such as picking, placing, and navigation, as callable functions allows an LLM to compose them into longer procedures ( Liang et al., 2023 ) . ASPIRE shows that an LLM agent can refine such programs and accumulate the repairs in a skill library ( Lu et al., 2026 ) . However, the available functions are not complete: their coverage is determined by predefined tasks, objects, and policies. Every new object or task may require another function, leaving the LLM confined to a predefined action space. This suggests that the main limitation lies in the action interface rather than in the LLM’s ability. In this paper, we propose RoboHarness . Without training models, RoboHarness combines visual clicks, keypoint tracking, and geometric constraints to provide an embodied control panel for an LLM agent. Concretely, our contributions are: An expressive, LLM-friendly robot harness that provides an embodied control panel for an LLM agent. A new paradigm for embodied AI. We show that a generalist LLM, equipped with the right tool harness can outperform VLA and World Action Models With RoboHarness, the open-source model Qwen3.8-Flash-Next can directly solve long-horizon household tasks in BEHAVIOR-1K ( Li et al., 2024 ) without any finetune, outperforming state-of-the-art models. It also substantially outperforms VLA and WAM baselines on fully out-of-distribution generalization tests.
