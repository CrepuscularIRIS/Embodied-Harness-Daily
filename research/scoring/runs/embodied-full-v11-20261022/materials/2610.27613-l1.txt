# Embodied Task Agents Can Perform Fine Manipulation through Tactile In-Context Learning

## Abstract
Can embodied task agents use tactile experience to perform fine manipulation without task-specific model training? We investigate this capability through Tactile-ETA, a system that incorporates tactile experience into an embodied task agent through in-context learning. Successful expert demonstrations show how contact changes during manipulation. We pair each recorded robot movement with its camera views and bilateral tactile observations. We keep tactile observations at the start and end of each movement and add two neighboring time points when the tactile images change markedly in between. The agent combines these demonstrations with current vision, tactile observations, and proprioception to select actions through general-purpose robot tools, without updating model parameters. Across four simulated manipulation tasks, adding tactile observations to the same two expert demonstrations increases average success from 15.75% to 24.00%, with current sensing and execution interfaces held fixed. Further experiments show that performance depends on the sensory content and representation of demonstrations, while comparing agent models on Lift Bottle reveals substantial differences under the same system configuration. On the real-robot tasks, demonstrations with aligned visual and tactile observations increase the task success rate from 0% to 60%. These findings demonstrate the feasibility of using tactile experience in context for fine manipulation and suggest a path toward extending embodied task agents to additional sensory inputs.



## 1 Introduction
Embodied task agents such as ETA ( Chen et al., 2026d ) , Show-Harness ( Chen et al., 2026c ) , and RoboDawn ( Guo et al., 2026 ) demonstrate that general-purpose models can execute robot tasks through observations, reasoning, and robot commands. However, fine manipulation remains challenging. Recent real-robot evaluation also shows a substantial performance gap between pick-and-place tasks and fine insertion tasks ( Menon et al., 2026 ) . Such manipulation requires adjusting actions to contact conditions, which can be difficult to infer reliably from vision alone. Tactile feedback provides complementary information for these adjustments ( Bi et al., 2025 ) . In-context learning further allows demonstrations to provide task guidance at deployment without additional parameter updates ( Palo and Johns, 2024b ; Yin et al., 2025 ; Cheng et al., 2026 ) . This creates an opportunity to extend the sensory information these agents can use: can embodied task agents similarly use tactile experience in context to perform fine manipulation that requires contact-sensitive adjustments? We investigate this question through Tactile-ETA (Figure 1 ), which incorporates expert tactile experience into an embodied task agent that acts through general-purpose robot tools, without task-specific fine-tuning. Current tactile observations describe ongoing contact, whereas expert demonstrations can provide a reference for how contact evolves during movement. For example, during rotation or insertion, a demonstration can show how an expert continues moving, adjusts its pose, or changes manipulation stages around a contact transition. Visual–motion records capture what the expert did, but not how contact evolved during the demonstrated actions. We organize expert demonstrations so that the agent can see each movement together with the visual and tactile changes that accompany it. Tactile-ETA divides successful expert demonstrations into action-aligned interaction segments, each containing robot motion, before-and-after camera observations, and bilateral tactile sequences from the same interval. Full tactile sequences can contain many observations within one movement, while the endpoints alone can miss changes during contact. We therefore retain tactile observations at motion boundaries and, when a change threshold is met, add an adjacent pair spanning the selected change. Complete demonstrations are provided in interaction order as references for execution. The agent combines them with current visual and tactile observations, proprioception, and execution feedback to select motion and gripper commands. Model parameters remain unchanged: task guidance is provided through context, while general-purpose tools and the underlying controller execute the selected actions. We evaluate the system on four UniVTAC simulation tasks ( Chen et al., 2026a ) , with 100 trials per task and condition. Adding tactile observations to the same two visual–motion demonstrations increases average success from 15.75% to 24.00%, with current sensing and execution interfaces held fixed. Content ablations reveal task-dependent contributions from demonstration vision and tactile observations, while representation ablations show that retaining more tactile frames does not automatically improve performance. A comparison of agent models on Lift Bottle also reveals substantial differences under the same system configuration. Execution statistics and cases illustrate behavioral differences in contact-guided corrections and stage transitions. On two real-robot tasks, a single multimodal demonstration enables three successful trials out of five per task, compared with zero without demonstrations. Together, these results demonstrate the feasibility of using tactile experience in context for embodied task agents and suggest a path toward extending them to additional sensory inputs. Our contributions are threefold: • We introduce Tactile-ETA, a system that incorporates expert tactile experience into embodied task agents through context for fine manipulation, without task-specific parameter updates. • We construct action-aligned visual–motion–tactile demonstrations that compactly retain motion boundaries and intermediate contact changes. • We show that tactile demonstration experience can improve manipulation performance, with outcomes depending on context organization and the underlying agent model. Execution records illustrate associated differences in contact adjustment and stage transitions.
