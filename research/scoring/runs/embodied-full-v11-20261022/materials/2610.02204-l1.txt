# Reconstruct, Practice, Go Real: Guided Self-Improvement for Embodied Agents

## Abstract
Building reliable robot capabilities across diverse tasks requires substantial human effort to develop and maintain skills, design rewards, and integrate perception with control. We present Reconstruct, Practice, Go Real (RPG), a framework for autonomous improvement of robot execution systems without updating model weights. RPG identifies manipulation capabilities in an offline dataset and constructs related practice tasks in simulation. During practice, RPG uses execution feedback, privileged simulator state, and available dataset videos to diagnose failures. It develops new reusable symbolic skills, refines existing skills, and revises the system prompt based on these diagnoses. Cross-task evaluation tests individual candidate changes and merged revisions before they are retained for reuse. At test time, a multimodal LLM uses the resulting system prompt and skill library to coordinate perception and robot control. On held-out initializations of 22 manipulation tasks, RPG improves task success from 28.6% after the first practice round to 95.0% after 15 rounds, outperforming all evaluated baselines, including ASPIRE (75.5%) and CaP-Agent0 powered by GPT-6 Astra Pro (60.0%). After a common calibration and hardware-adaptation procedure, the frozen system succeeds in all 30 physical trials, with ten trials on each of three tasks. ## I Introduction
Recent advances in multimodal large language models (MLLMs) have enabled agents to perceive environments and reason about tasks [ 1 ] . Language-model agents can also generate and execute code [ 2 ] and improve through feedback [ 3 ] . These capabilities offer a way to expand robot behavior with less task-specific human engineering. In particular, multimodal coding agents can use visual observations and execution feedback to construct, refine, and compose executable skills that robots can retain and reuse across tasks [ 4 , 5 , 6 ] . Language-model-based robot control involves a tradeoff between program execution and online reasoning. Code-as-Policy combines perception and control primitives into executable programs [ 7 , 8 , 9 ] . These programs can execute efficiently and incorporate feedback loops, but their responses depend on explicit program logic and perception interfaces. For example, a robust symbolic check for grasp success can be difficult to specify, while an MLLM can assess the outcome from images. In Agent-as-Policy , the MLLM remains in the control loop, providing flexible visual and semantic reasoning [ 1 , 5 ] . However, frequent model calls can make low-level decisions slow. A scalable system should combine these strengths by delegating repeatable execution to reusable code and reserving multimodal reasoning for decisions that benefit from visual or semantic judgment. We introduce Reconstruct, Practice, Go Real (RPG), a framework that develops and refines reusable robot skills through autonomous practice without updating model weights (Fig. ). RPG improves both the shared skill library and the system prompt that guides a multimodal agent in using it. Changes to these shared components persist across episodes and can benefit other tasks that reuse them. Given an offline dataset, Reconstruct selects source tasks that expose useful manipulation capabilities and constructs related practice tasks in simulation. The resulting practice suite can be expanded by processing additional tasks from the dataset. A practice task may cover part of a source task or an analogous manipulation. It need not reproduce the original trajectory or scene. We use ABC [ 10 ] in this work because it covers 193 diverse tasks. During Practice , RPG compares executions from the Runtime Agent and the Privileged Agent, which uses the same model and skill library but additionally receives simulator state. The Video Analyzer uses these execution records and available dataset videos to diagnose failures. RPG then develops new reusable symbolic skills, refines existing skills, and revises the system prompt. It evaluates candidate changes across the practice tasks and retests merged changes before retaining them. Finally, Go Real calibrates and freezes the resulting system for physical deployment, where the Runtime Agent coordinates perception and control through the shared skill library. On held-out initializations of 22 manipulation tasks, RPG improves task success from 28.6% after the first practice round to 95.0% after 15 rounds, outperforming ASPIRE (75.5%) and CaP-Agent0 powered by GPT-6 Astra Pro (60.0%). Through comprehensive ablation experiments, we demonstrate the benefits of the Privileged Agent, Video Analyzer, and skill revisions. After a hardware calibration procedure, the frozen RPG system successfully completes all 30 physical trials, with 10 trials for each of the three evaluated tasks. These results show that autonomous practice can develop and refine shared robot skills that support physical deployment. Our contributions are: • We introduce RPG, a framework that autonomously selects manipulation capabilities from an offline dataset and constructs an expandable suite of simulation practice tasks for developing reusable robot skills. • We develop an autonomous practice procedure that uses privileged execution and video-based failure diagnosis to revise shared skills and the system prompt, validating both individual and merged changes across tasks. • We demonstrate 95.0% success on held-out initializations of 22 simulated manipulation tasks and 100% success over 30 trials across three physical tasks.
