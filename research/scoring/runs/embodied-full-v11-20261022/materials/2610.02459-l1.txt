# OpenRUA: Robot-Use Agents Are Zero-Shot Visuomotor Policies

## Abstract
Coding agents are extending their reach into the physical world by writing and executing robot control programs. One might expect the agents to use the existing mature software stack that engineers have developed over decades to access sensors and control motion. Yet prior work primarily engineers complex custom harnesses to orchestrate agents for robot use, particularly by prescribing specialized workflows and providing bespoke interfaces. This raises the question: "Is such additional harness engineering necessary?" We introduce OpenRUA, a zero-abstraction harness that bypasses bespoke abstraction layers by providing off-the-shelf coding agents with only terminal access to the robot's native software interface ROS 2. OpenRUA employs a minimalist workspace-as-harness design, only offering ROS 2 documentation and basic tools while leaving the coding agent to organize its own work without orchestrating any agentic workflow. Within this workspace, OpenRUA recasts perception as file I/O and manipulation as coding. With Claude Code powered by Claude Opus 5, OpenRUA achieves success rates of 99.0% on CaP-Bench and 87.0% on LIBERO-PRO, demonstrating that an off-the-shelf coding agent can serve as a zero-shot visuomotor policy through the robot's native interface, without bespoke primitives or task-specific training. Under this minimalist design, further analysis reveals striking emergent behaviors of coding agents: (1) For perception, the agent spontaneously writes programs that process raw sensory inputs and derive metric measurements in 96.80% of episodes. (2) For manipulation, the agent spontaneously builds motion-control clients (e.g., gripper control) in 95.87% of episodes and closed-loop control programs (e.g., adjusting motion based on sensor feedback) in 50.13% of episodes. Our code is available at https://github.com/terminalworld/OpenRUA.

## 1 Introduction
Robot control has long been engineered by writing explicit programs that translate task specifications into physical motion ( Fikes and Nilsson, 1971 ; Li et al., 1994 ; Siciliano et al., 2009 ) . These programs execute on a multi-layered software stack, through which human engineers coordinate drivers, messaging, planning, and actuation to implement the required behavior ( Macenski et al., 2022 ; García et al., 2020 ) . However, this process requires substantial effort and human expertise, with further engineering often needed for new tasks or environments. One path is to learn end-to-end visuomotor policies , such as Vision-Language-Action (VLA) models ( Team, 2025 ; Kim et al., 2024 ; Intelligence et al., 2026 ; Bjorck et al., 2025 ) and World Action Models (WAMs) ( Agarwal et al., 2026 ; Ye et al., 2026 ; Li et al., 2026 ) , that map visual observations and language instructions directly to low-level actions. However, they require large-scale demonstration data, and their generalization remains limited beyond the training distribution ( Zhou et al., 2025 ; Fei et al., 2025 ; Kim et al., 2026 ) . For example, LIBERO-PRO ( Zhou et al., 2025 ) reports that OpenVLA ( Kim et al., 2024 ) and \pi_{0} ( Black et al., 2024 ) , despite average success rates above 90% on standard LIBERO, achieve 0.0% success under position and task perturbations. Another path is to revisit explicit programming for robot control ( Fu et al., 2026 ) , while replacing the human engineer with modern coding agents such as Claude Code ( Anthropic, 2025 ) or Codex ( OpenAI, 2025 ) . Such an approach is known as Code as Policies (CaP) ( Liang et al., 2023 ) , where the policy itself can be inspected, edited, and debugged by the coding agent without retraining ( Elmaaroufi et al., 2026 ; Lu et al., 2026 ) . As a result, the coding agent acts as a Robot-Use Agent (RUA) ( Isola, 2026 ) , operating the robot the way it operates a computer ( Team, 2025 ; Fu et al., 2026 ; Robocurve, 2026 ; Berman et al., 2026 ) . Figure 1: OpenRUA: a minimalist workspace-as-harness for robot-use agents. Given a task such as placing the block in the bowl, OpenRUA enables any off-the-shelf coding agent to operate a real or simulated robot through its native ROS 2 interface, bypassing bespoke abstraction layers. The workspace serves as the harness by only providing ROS 2 documentation and basic tools, making robot perception accessible through file I/O and manipulation through coding, without orchestrating any agentic workflow. Within this workspace, the agent exhibits emergent perception and control capabilities as it works to complete the task. It writes and executes ros2cli commands or rclpy programs that send control requests to the robot’s controllers, here grasping and lifting the wooden block. The agent saves new RGB-D observations as workspace files and uses images, computed measurements, and terminal feedback to autonomously verify progress and refine its actions until the block is placed in the bowl. Despite this progress, existing RUA systems devote significant effort to engineering custom harnesses for robot use, especially designing the tool interfaces and primitive libraries through which agents compose policies to operate robots in prescribed workflows. These systems either wrap learned visuomotor policies as callable tools ( Zhang et al., 2026b ; Galanti et al., 2026 ; Ding et al., 2026 ; Wang et al., 2026a ) or hand-craft custom libraries of perception and control primitives based on human expertise ( Fu et al., 2026 ; Lu et al., 2026 ; Elmaaroufi et al., 2026 ; Zhang et al., 2026a ) . However, it remains unclear whether such additional harness engineering is necessary for coding agents to operate robots effectively, given that robots have a mature ecosystem of software interfaces developed over decades for human engineers to access sensors and control motion ( Macenski et al., 2022 ; García et al., 2020 ) . This raises the question: “Can an off-the-shelf coding agent serve as a zero-shot visuomotor policy through the robot’s native software interface, without relying on bespoke primitives or learned policies?” In this work, we introduce OpenRUA, a zero-abstraction harness for robot-use agents that builds on the robot’s native interface, Robot Operating System 2 (ROS 2) ( Macenski et al., 2022 ) , the de facto standard of the robotics community. OpenRUA bypasses bespoke abstraction layers by offering off-the-shelf coding agents only terminal access to ROS 2, allowing them to operate the robot as a human engineer would. As illustrated in Figure 1 , OpenRUA frames robot use as a live, interactive software project and employs a minimalist workspace-as-harness design. This design rests on the observation that frontier coding agents already operate autonomously on unfamiliar repositories to complete tasks ( OpenAI, 2024 ; Merrill et al., 2026 ; Chu et al., 2026 ) . We hypothesize that the orchestration with bespoke interfaces in existing RUA systems compensates for limited agent capability rather than reflecting a requirement of robot control, and that a capable coding agent needs only a workspace directory. Specifically, the workspace serves as the harness by only offering ROS 2 documentation and basic tools, leaving the coding agent to organize its own work without a prescribed agentic workflow. Within this workspace, OpenRUA recasts perception as file I/O and manipulation as coding: task-specific perception and control strategies emerge as the agent acquires observations, interprets images, computes metric measurements, and writes control programs. As a result, the coding agent itself serves as a zero-shot visuomotor policy: it goes from raw observations to motor commands, reasoning explicitly about geometry and iteratively refining its actions from execution feedback. We conduct comprehensive experiments to evaluate OpenRUA on three widely used benchmarks, i.e. , CaP-Bench ( Fu et al., 2026 ) , LIBERO-PRO ( Zhou et al., 2025 ) , and RoboCasa365 ( Nasiriany et al., 2026 ) , in a zero-shot setting without access to privileged simulator state and the benchmark’s success predicates. With Claude Code powered by Claude Opus 5, OpenRUA achieves success rates of 99.0% on CaP-Bench and 87.0% on LIBERO-PRO, exceeding leading systems such as ASPIRE ( Lu et al., 2026 ) and Harness VLA ( Zhang et al., 2026b ) by 18.0 and 4.6 percentage points, respectively. On unseen composite tasks in RoboCasa365, OpenRUA achieves 28.1% success, exceeding Harness VLA by 13.1 percentage points. The results show that an off-the-shelf coding agent can serve as a zero-shot visuomotor policy through the robot’s native software interface, without bespoke primitives or learned policies. Further analysis reveals several findings about emergent agent capabilities: 1 For perception, the agent spontaneously writes programs that process raw sensory inputs ( e.g. , cropping images, adding grids, and reconstructing point clouds from depth) and derive metric measurements ( e.g. , computing coordinates for Cartesian motion targets) in 96.80% of episodes. 2 For manipulation, the agent spontaneously builds its own motion-control clients ( e.g. , trajectory execution and gripper control) in 95.87% of episodes and closed-loop control programs ( e.g. , adjusting motion or stopping based on sensor feedback) in 50.13% of episodes. 3 On RoboCasa365, OpenRUA maintains comparable success rates on seen and unseen composite tasks (26.3% and 28.1%, respectively), whereas RLDX-1 drops to 5.0% and Harness VLA, which orchestrates RLDX-1, drops to 13.8% on unseen tasks. This contrast highlights the generalization potential of OpenRUA without reliance on a learned robot policy. 4 Increasing test-time computation through more interaction or greater reasoning effort improves task success without additional robot training or bespoke primitives, while performance eventually saturates at levels that vary across models.
