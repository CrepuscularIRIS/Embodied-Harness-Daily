# AgenticRoboRL: Bringing Coding-Agent Post-Training to Agentic Robotics

## Abstract
Agentic robotics systems combine planners with robot harnesses to perform complex manipulation tasks. Recent work improves these systems through better harnesses and external memory, but relies on powerful closed-source models as planners and does not improve the planners' own capabilities. In contrast, coding agents have improved substantially by post-training the model itself. We therefore investigate whether post-training can also improve robot planners. However, applying it across robot harnesses requires accommodating different execution mechanisms, including VLA skill invocation and control-code generation. To this end, we introduce AgenticRoboRL, a framework for post-training robot planners across different harnesses. The training recipe combines supervised fine-tuning with multi-turn reinforcement learning. To accommodate different execution mechanisms, harness-specific adapters connect recorded planner interactions with task outcomes, enabling a common RL training pipeline while keeping execution components fixed. On LIBERO-PRO, AgenticRoboRL raises the success rate of a 9B-parameter planner from 18.1% to 71.0% without external memory, approaching the 72.1% achieved by Codex (GPT-5.5) with external memory. These results demonstrate post-training as an effective approach for improving robot planners. We will release the framework and trained planner checkpoints.

## 1 Introduction
Figure 1: Overview of AgenticRoboRL. (a) Agentic robotics systems combine planners with robot harnesses for multi-turn interaction with the environment. (b) We post-train planners through SFT on successful trajectories followed by multi-turn RL. (c) On LIBERO-PRO, post-training improves a 9B planner’s success rate from 18.1% to 71.0%, approaching the 72.1% achieved by Codex (GPT-5.5)with memory. Mem denotes external memory. Agentic robotics systems can perform complex manipulation tasks by combining a planner with a robot harness. The planner invokes VLA skills ( Zhang et al., 2026c ) or generates control code ( Liang et al., 2023 ; Fu et al., 2026 ) , observes the execution results, and decides what to do next over multiple rounds of interaction. Recent work has improved performance by refining robot harnesses and storing experience from task exploration in external memory ( Zhang et al., 2026c ; Xu et al., 2026b ) , with coding agents such as Codex and Claude Code ( OpenAI, 2025 ; Anthropic, 2025 ) serving as planners. However, these approaches primarily leverage existing planner capabilities and strengthen the support available to the planner. We explore a complementary direction: enhancing planners’ own capabilities to improve the performance of agentic robotics systems. For coding agents, enhancing the model’s own capabilities through post-training, including supervised fine-tuning and reinforcement learning, has proven highly effective ( Pan et al., 2024 ; Yang et al., 2026 ; Cao et al., 2025 ) . These advances raise a natural question: Can the post-training methods used for coding agents also improve the performance of agentic robotics systems? Applying these methods to robot planners is complicated by the fact that robot harnesses differ in how they carry out a planner’s response. In some harnesses the planner calls learned VLA skills, and a VLA policy executes each call. In others the planner writes control code over perception and control APIs, and a motion controller executes it. Harnesses also differ in what feedback they return to the planner and in how they decide whether the task has succeeded. Training planners across harnesses therefore requires a single pipeline that supports these different execution mechanisms. To realize such a pipeline, we introduce AgenticRoboRL, a framework for post-training robot planners across different harnesses (Figure 1 ). The training recipe combines supervised fine-tuning (SFT) with multi-turn reinforcement learning (RL). SFT trains the planner on successful demonstrations, providing a starting point for RL. During RL, we train on recorded planner requests and responses, while harness-specific adapters associate these interactions with episode outcomes. This allows the same RL pipeline to support VLA skill invocation and control-code generation without changing their execution interfaces. In both stages, only the planner is optimized, while the underlying execution components remain fixed (Figure 2 ). We evaluate the pipeline across these two execution mechanisms using a 9B planner. With RPent ( Zhang et al., 2026c ) , a harness that invokes VLA skills, SFT improves success on LIBERO-PRO from 18.1% to 65.1%, and RL further raises it to 71.0%, without external memory. The same checkpoint achieves 72.2% on LIBERO-Plus ( Fei et al., 2025a ) without additional training, compared with 19.2% for the original model. With the CaP-X harness ( Fu et al., 2026 ) , post-training improves success from 2.7% to 28.5%. These results establish post-training as an effective approach for improving agentic robotics systems. Our contributions are threefold: • To our knowledge, AgenticRoboRL is the first general post-training framework to agentic robotics systems. • AgenticRoboRL first fine-tunes the planner on successful demonstrations and then refines it with RL, updating only the planner while keeping execution components fixed. Lightweight harness-specific adapters link each recorded planner call to its episode outcome, so the harnesses do not need a shared low-level action representation. • Strong empirical results and an open release. With AgenticRoboRL , a 9B planner improves from 18.1% to 71.0% on LIBERO-PRO without external memory. This nearly matches Codex (GPT-5.5) with external memory (72.1%) ( Zhang et al., 2026c ) . With the CaP-X harness, it improves from 2.7% to 28.5%. We will release the AgenticRoboRL framework and trained planner checkpoints.
