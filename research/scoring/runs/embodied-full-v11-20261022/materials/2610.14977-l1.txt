# EnactOpt: Diagnosis-Guided Harness Evolution for Embodied Agents

## Abstract
Embodied agents built on foundation models rely on an execution harness to organize observations, guide actions, and incorporate execution feedback into subsequent decisions. Failures can arise not only from limited model capabilities, but also from how the harness presents evidence and guides its use. These model-external mechanisms provide an adaptation target without updating model parameters, but task-specific interaction experience can be costly to collect. Task-level outcomes alone do not reveal whether relevant evidence was missing from the model input or was available but inadequately used. Moreover, these two aspects are coupled: effective action guidance may require evidence that the current context omits, while exposing that evidence alone does not ensure an appropriate response. We introduce EnactOpt, which uses limited execution feedback to jointly evolve reusable textual skills and context-construction code while keeping the underlying models and runtime fixed. It diagnoses adjacent decisions by relating action feedback to the actual model input and subsequent action. Structured episode summaries guide joint revisions through prompt-level edit operators, and candidate harnesses undergo compatibility checks and validation-based retention. Across VLABench, ALFWorld, and Embodied Agent Interface (EAI), EnactOpt improves task success by approximately 10-27 percentage points over the initial harnesses and outperforms the evaluated GEPA, TextGrad, and Trace2Skill baselines. These gains extend to task conditions not used for harness evolution or candidate selection. The results support a complementary route to embodied adaptation: turning limited execution experience into reusable behavioral improvements by jointly refining how evidence is presented and acted upon.

## 1 Introduction
Foundation models provide embodied agents with multimodal reasoning ( Driess et al., 2023 ; Hurst et al., 2024 ; Bai et al., 2025 ; Comanici et al., 2025 ) and sensorimotor control ( Kim et al., 2024 ; Physical Intelligence et al., 2025b ; Li et al., 2025 ; Ye et al., 2026 ) . Effective execution, however, depends on how observations become model inputs, model outputs become actions, and execution feedback informs subsequent decisions ( Shi et al., 2025 ) . We call the reusable, model-external guidance and control logic supporting this interaction the execution harness. We focus on two editable components (Figure 1 ): reusable textual skills S that guide actions and context-construction code C that selects and presents observed evidence. Model parameters and the execution interface remain fixed during harness adaptation. Figure 1: Execution harness for embodied agents. The editable harness H=(S,C) comprises textual skills S for action guidance and context-construction code C for organizing observed evidence. The fixed runtime assembles the complete model input x_{t} from constructed context c_{t} and any additional runtime-provided inputs; model parameters and runtime interfaces remain unchanged during harness evolution. An initial harness encodes assumptions about how tasks are expressed and what evidence is available during execution. Changes in instructions or visual conditions can make its action guidance or evidence selection inadequate. Revising the harness still requires task-specific experience, which can be costly to collect in physical environments ( Kim et al., 2024 ; Tang et al., 2025 ) . Prior work on reflection and experience-guided learning shows that such experience can be retained as reusable guidance ( Shinn et al., 2023 ; Zhao et al., 2024 ) . The challenge is therefore to turn limited execution evidence into revisions that improve the harness on later tasks, rather than corrections confined to the episode that produced it. Feedback-driven adaptation already spans reusable skill optimization ( Yang et al., 2026 ; Ju et al., 2026 ) and executable harness evolution ( Lee et al., 2026 ; Lin et al., 2026 ) , including skill-and-context adaptation for embodied agents ( Wang et al., 2026b ) . Useful revisions, however, require more than a task-level success signal. A failure may reflect feedback omitted from the actual model input, an inadequate response to available feedback, or both. This motivates examining what evidence reached each decision and how the agent responded. At the same time, a proposed skill revision may depend on observed evidence not yet presented to the model. Evaluating that revision together with the corresponding change to context construction allows their combined effect to be assessed as one harness candidate, rather than treating the two edits as independent improvements. We introduce EnactOpt, a framework for diagnosis-guided joint revision of textual skills and context-construction code (Figure 2 ). It diagnoses adjacent decisions in training rollouts, relating action feedback to the actual model input and the agent’s response. Structured episode summaries consolidate the reported evidence, uncertainty, and repair and preservation suggestions into feedback for a single LLM optimizer. Given the source harness and this feedback, the optimizer uses prompt-guided edit operators to organize targeted changes to S , C , or both within one harness candidate. Interface and runtime compatibility checks screen candidates before validation-based pool retention. The retained versions supply subsequent iterations, and the final validation-selected harness is fixed for testing. We evaluate benchmark-specific EnactOpt harnesses on VLABench ( Zhang et al., 2025b ) , ALFWorld ( Shridhar et al., 2020 ) , and Embodied Agent Interface (EAI) ( Li et al., 2024 ) , spanning low-level policy execution and high-level action interfaces. Under the reported configurations, EnactOpt improves task success by approximately 10–27 percentage points over the initial harnesses and outperforms the evaluated GEPA ( Agrawal et al., 2026 ) , TextGrad ( Yuksekgonul et al., 2024 ) , and Trace2Skill ( Ni et al., 2026 ) baselines on all three benchmarks (Table 1 ). The gains extend to within-benchmark task conditions not used for evolution or candidate selection. On VLABench, the ablation comparisons show larger performance gaps under shifted conditions than in-distribution. Joint revision also achieves higher generalization success with fewer optimization passes than separate skill and code updates (Table 2 ). Our contributions are threefold: • We introduce EnactOpt, a framework that treats textual skills and context-construction code as a coupled adaptation target. A single proposal can revise either or both components, enabling their combined behavior to be evaluated while models and runtime remain fixed. • We develop a diagnosis-to-revision feedback interface that relates action feedback to actual model inputs and subsequent responses. Structured episode summaries convey reported evidence and uncertainty, while prompt-guided edit operators organize targeted changes and preservation requests. • We report gains over initial harnesses and evaluated baselines across three embodied benchmarks, including gains beyond the evolution conditions. VLABench ablations show that comparable in-distribution success can mask differences in generalization, and that joint revision attains higher generalization success with fewer optimization passes than separate updates.
