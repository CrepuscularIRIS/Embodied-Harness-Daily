# Scaling Online Exploration for Robot Agents

## Abstract
Robot learning has advanced by scaling demonstration datasets and model capacity; however, deploying a new robot embodiment or task typically necessitates a dedicated teleoperation corpus. The resulting policies remain bounded by their imitation distributions, limiting generalization and continual self-improvement. We introduce RAX (Robot Agent eXploration), an open-source framework for robot agents centered on scaling exploration: enabling agents to improve by acquiring online experience and synthesizing executable programs. In RAX, a general-purpose coding agent generates robot control code, operating without action demonstration data, hand-engineered action primitives, or value-function guidance. Through online exploration, the agent identifies decision sequences that achieve task goals and compiles them into modular programs encapsulating the full perception-planning-control loop. Using RAX, we present a systematic multi-embodiment study on scaling online exploration across precision and long-horizon manipulation tasks using single-arm, bimanual, dexterous, mobile, and humanoid systems in simulation and on real robots. Generalization performance on unseen environments improves consistently as exploration scales. In simulation, RAX outperforms top baseline models by +37.4% on average. On real robots, RAX autonomously learns memory-dependent, articulated, high-precision, deformable, and long-horizon mobile manipulation tasks without human demonstrations, continually improving performance by composing verified skills from prior exploration sessions. As exploration scales, we observe emergent capabilities including active perception, error recovery, safety guardrails, and human-robot collaboration. We open-source RAX as a generalist robot-agent platform in which new robot embodiments are integrated through their APIs alone, without teleoperated data collection or policy training.



## 1 Introduction
“We want AI agents that can discover like we can, not which contain what we have discovered. Building in our discoveries only makes it harder to see how the discovering process can be done.” — Richard S. Sutton, The Bitter Lesson ( 2019 ) Robot learning has made substantial progress by scaling demonstration data and model capacity with imitation learning, aiming to replicate the training recipe that transformed language modeling ( Kaplan et al., 2020 ) . Vision-language-action (VLA) models and World-Action models (WAMs) fine-tune pretrained VLMs and video generation models, respectively, using large teleoperation corpora ( Brohan et al., 2023 ; Kim et al., 2024 ; Black et al., 2024 ) . However, deploying a new robot or task still requires a dedicated teleoperation corpus of its own ( O’Neill et al., 2024 ; Team et al., 2024 ; Black et al., 2024 ; Intelligence et al., 2025 ; Bjorck et al., 2025 ; Liu et al., 2026 ; Wang et al., 2026e ; Yuan et al., 2026 ; Kim et al., 2026 ; Bi et al., 2026 ) . Furthermore, the knowledge of such policy models is inherently bounded by the demonstrations they imitate. Consider a mobile robot tasked with loading a car in an unfamiliar house: while opening doors, grasping bags, and placing objects may each be familiar skills, the robot must adapt to novel scenes, visual appearances, and task compositions while discovering new approaches. This adaptation and discovery process is absent during imitation learning on static teleoperation data. Consequently, these policies struggle to generalize and self-improve, even when provided with environment interactions and test-time compute. This limitation motivates a central question: can robots self-improve and learn to discover new skills through autonomous online experience and active exploration? Humans learn physical skills by attempting a task, observing the outcome, diagnosing failures, and practicing until their behavior becomes reliable. LLM agents exhibit a similar pattern in software domains: they explore unfamiliar systems by executing programs, inspecting outputs, and revising their work ( Yang et al., 2024 ) . Instead of training policies exclusively on teleoperated demonstration data, we let agents program robots directly ( Lozano-Perez, 1983 ) without hand-designed action primitives. The agent explores online to discover decisions that drive task success, then automates these decision-making principles into modular robot programs that integrate perception, planning, and control. It continuously debugs and tests these programs through online execution. These programs encode the agent’s underlying principles for how to generate successful actions based on environment perception, rather than merely mimicking the actions themselves, thereby enabling more robust generalization. Furthermore, the agent can compose, modify, and update these programs when confronting increasingly complex scenes and tasks, continually improving through online experience. We introduce RAX (Robot Agent eXploration) , a cognitive architecture for robot agents. Its core organizing principle is scaling exploration : robot agents should improve by gathering their own online experience and optimizing their programs. In RAX, a general-purpose coding agent receives a natural-language instruction, at most a few goal images or visual demonstrations, and a budget of exploration episodes. It interacts directly through the robot’s perception and control interfaces without requiring human teleoperation or value function guidance. The underlying language model parameters remain fixed and no policies are trained; instead, learning updates a persistent workspace of programs, notes, and verified skills. The agent converts successful interactions into autonomous code programs and stores reusable knowledge for subsequent episodes and tasks. As exploration scales, we observe several emergent system capabilities: the agent constructs task-relevant 3D perception models, plans actions via pose search in 3D joint space, generates fully automated programs with closed-loop visual and force feedback, and adapts its programs when encountering novel task conditions. Furthermore, we observe agentic behaviors on real robots, including active perception, error recovery, safety guardrails, and active human-robot interaction. For example, the robot executes end-effector contact probing for precise localization when depth measurements are inaccurate. In mobile manipulation experiments, following an initial collision with a cabinet, the agent automatically instantiates a safety check to verify workspace clearance before every base rotation. To test code robustness, the agent actively requests the human operator to vary object layouts, systematically testing the spatial generalization of the autonomous program. In RAX, we equip the agent with rich multimodal sensing by exposing metric depth and force signals through the robot interface. A unified architecture supports tabletop bimanual arms, dexterous hands, mobile household robots, and humanoids through interfaces to each robot’s sensors, controllers, and kinematic models ( Section 4 ). Unlike standard VLAs or WAMs operating on RGB images alone, the agent autonomously leverages these rich sensing signals to construct 3D point clouds and fit object models directly from perception. It then searches for actions to manipulate these 3D models while accounting for their unique shapes and affordances. Force feedback further enables the agent to resolve spatial uncertainty through contact and enable close-loop control on force signals in insertion tasks. Such multimodal world modeling have been largely absent from generalist policy models, yet naturally align with human cognitive processes. To enable high-frequency closed-loop control, the agent compiles its decision-making process into executable Python programs that generate actions directly from sensor signals. Unlike prior approaches that rely on human-designed action primitives or policies trained on demonstrations ( Lu et al., 2026 ; Xiao et al., 2026 ) , our approach directly generates robot control programs that encapsulate the full perception-planning-control loop, whereas standard policies discard the underlying decision-making process essential for generalization. In practice, we observe the agent writing programs that automatically segment and identify objects in 3D using point-cloud fitting and hue-based identification, then plan actions grounded in this 3D world model, with retry loops and exception handling naturally incorporated into the code. Because actions are planned directly on perceived 3D objects rather than learned through imitation, this approach generalizes to far more diverse object layouts and domain variations than standard VLAs or WAMs. For semantically rich perception in open-world environments, the agent can program direct API calls to LLMs (such as Gemini) within the code to assist with object identification, while incorporating checkpoints and exception handling to step in and verify progress. Over the course of exploration, both action inference latency and token counts decrease as an increasing fraction of decisions becomes automated through code. As experience scales with exploration, RAX maintains an intra-task memory file system across episodes to record failure lessons and successful strategies, allowing the agent to continually refine its programs. Across multiple tasks and sessions, we maintain a repository of modular programs as verified skills for various tasks and manipulation primitives. Each skill includes the executable code for a specific task, accompanied by execution logs from successful runs, clear preconditions, and verification checkpoints, allowing skills to be composed and reused for complex downstream tasks. In real-world mobile manipulation experiments in household settings, the agent practices individual tasks, each in its own exploration session, such as picking and placing boxes or tucking in office chairs, and commits them as verified skills. When subsequently evaluated on a composite, long-horizon task involving more than six sequential object manipulations, the agent achieves substantial automation and efficiency gains by reusing these stored skills. We envision agents practicing skills in a distributed, parallel fashion to build a rich repository of diverse capabilities, thereby enabling continual lifelong learning. Using RAX, we conduct the first large-scale, multi-embodiment, systematic study of scaling exploration for robot agents , spanning fine-grained precision and long-horizon tasks across LIBERO, LIBERO-Pro, RoboDojo, DexJoCo, BEHAVIOR-1K, and HumanoidArena in simulation and on two real robots. We evaluate the resulting policies on unseen scenes, separating exploration from evaluation. Performance grows steadily with exploration, and on fine-grained and long-horizon tasks on which state-of-the-art methods rarely succeed, RAX achieves high success rates, surpassing the strongest prior models by +37.4 on average over five benchmarks ( 1 , Section 13 ). Without any expert action trajectories, RAX sets a new state of the art on RoboDojo (+53.4), BEHAVIOR-1K (+38.3), DexJoCo (+31.4), and LIBERO-Pro (+21.2). On HumanoidArena, it sets a new state of the art (+7.9) with three teleoperated demonstrations per task, where every baseline uses 100. On real Franka and Rainbow RB-Y1 robots, RAX masters five complex tabletop manipulation tasks and a long-horizon mobile manipulation task with zero demonstrations, and verified skills accumulated across sessions let later sessions build on earlier ones. We summarize our contributions below: 1. We introduce RAX and establish scaling online exploration as a foundational principle for agentic robotics. In RAX, the agent operates directly through perception and robot control interfaces without policy training, compiling successful decision sequences into executable code programs that run autonomous execution loops. 2. Using RAX, we conduct the first systematic, multi-embodiment study of scaling online exploration across simulation and real robot environments. RAX acquires diverse manipulation capabilities solely through autonomous exploration, outperforming state-of-the-art baselines by +37.4 points on average across five simulation benchmarks, while solving high-precision, deformable, articulated, and long-horizon manipulation tasks on real robots without human demonstrations. 3. We demonstrate rapid adaptation and continual learning on real robots, showing that generated programs can be selectively updated in response to environmental and task shifts while retaining verified skills in a persistent repository for composition and reuse in complex tasks. We release the full architecture of RAX, together with its agent instructions, skills, benchmark integrations, and evaluation protocols, as a generalist robot-agent platform, on which a new robot can be brought up through an interface alone, without data collection or policy training.
