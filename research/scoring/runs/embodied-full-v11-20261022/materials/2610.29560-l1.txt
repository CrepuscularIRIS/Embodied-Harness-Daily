# From VLM Planners to Robotic Agents: Self-Evolving Harnesses for History-Dependent Manipulation

## Abstract
Vision-language-action (VLA) models achieve strong performance across embodied manipulation tasks by unifying visual understanding, language conditioning, and action generation. However, long-horizon tasks can involve non-Markovian dependencies: successful decisions may require retaining task progress and past interaction outcomes, while partial observability and execution errors compound over time. Existing work has begun to address these challenges by augmenting foundation-model policies with memory and by introducing hierarchical architectures that separate high-level planning from low-level execution. We organize the high-level VLM as a robotic agent through an editable harness to maintain task context and improve planning through execution experience. We instantiate this approach as SERA (Self-Evolving Robotic Agent), with a fixed VLA executor providing low-level control. The harness maintains and updates task context using observations and execution feedback to guide subsequent planning. Self-evolution uses environment rollouts to propose and evaluate harness revisions, with the selected configuration fixed before held-out testing. On RoboMME, SERA achieves 51.38% overall success with autonomous selection, compared with 44.38% without self-evolution. Our exploration suggests that agentic planning is a promising direction for history-dependent robotic manipulation.



## 1 Introduction
Vision-language-action (VLA) models connect visual observations and language instructions to robot actions, providing a foundation for general-purpose manipulation ( Brohan et al., 2023 ; Kim et al., 2024 ; Black et al., 2024 ) . Long-horizon tasks, however, can require information that the current observation does not reveal ( Koo et al., 2025 ; Dai et al., 2026 ) . For example, when a robot must repeat an operation a specified number of times, similar images may call for different decisions depending on how many repetitions have actually succeeded. An earlier observation may also contain a cue that is no longer visible. Such history-dependent decisions require preserving task-relevant information and tracking execution outcomes over successive interactions. Existing research provides several foundations for these capabilities. Memory-augmented policies equip VLA models with mechanisms for retaining and using historical information, including compact temporal representations ( Koo et al., 2025 ; Jang et al., 2025 ; Zhu et al., 2026 ) , memory retrieval, and recurrent state updates ( Shi et al., 2025a ; Hu et al., 2026 ; Li et al., 2026 ) . Hierarchical architectures introduce a high-level planning layer that issues intermediate decisions to low-level executors ( Ahn et al., 2022 ; Belkhale et al., 2024 ; Duan et al., 2025 ; Sridhar et al., 2025 ) and can incorporate environment feedback ( Huang et al., 2022 ) . Agentic systems further organize reasoning, actions, and feedback into iterative decision processes ( Yao et al., 2022 ; Shinn et al., 2023 ; Wang et al., 2023 ) . Recent embodied harnesses explore external task management ( Zhang et al., 2026b ; Gu et al., 2026 ) and experience-driven adaptation ( Chen et al., 2026 ; Wang et al., 2026 ; Ding et al., 2026 ) . Together, these developments motivate studying how the high-level planner in a hierarchical architecture can manage task context and make use of execution experience. Our focus is on two connected responsibilities of this planning process. Within an episode, issuing a command does not establish that the intended operation has succeeded. In the repetition example, updating progress requires interpreting subsequent observations and feedback, while retaining information needed for later decisions. Access to history therefore needs to be accompanied by an explicit process for maintaining decision-relevant task context. Across attempts, an execution record must be translated into a reusable change to influence future planning. This raises a question: how can we support both ongoing context management and improvements to the planning process from execution experience? We explore an editable harness around the high-level VLM as a common mechanism for these responsibilities. The harness organizes context and feedback during execution, while providing an explicit object for revision during self-evolution. This also offers a way to investigate experience reuse when additional demonstrations and manual annotations are costly. Figure 1 illustrates this design direction. We present SERA (Self-Evolving Robotic Agent), which organizes a VLM as an agent within an editable harness around a fixed VLA executor. During task execution, the harness supports sustained context management over long horizons, guiding the extraction, retention, and updating of task progress and execution outcomes from observations and feedback. This context supports the VLM’s subsequent planning. However, a predefined harness may not anticipate all task requirements, motivating execution-driven self-evolution to identify and repair its limitations. Analysis and revision agents autonomously diagnose failures from execution traces and propose candidate repairs to planning guidance, assessment criteria, and control rules. A verifier evaluates these candidates through environment rollouts, providing feedback for further revision and harness selection. This process revises the harness without manually constructing additional demonstration datasets for supervised fine-tuning of the high-level VLM planner. The selected harness is fixed before held-out testing, while task context continues to be updated within each episode. We evaluate SERA on RoboMME, a benchmark for history-dependent robotic manipulation ( Dai et al., 2026 ) . Autonomous SERA achieves 51.38% overall success, compared with 44.38% without self-evolution. These results support an empirical exploration of agentic planning and the aggregate effect of execution-driven harness revisions. Our contributions are: • An agentic planning framework that organizes a high-level VLM within an editable harness for sustained task-context management over long horizons, tracking task progress and execution feedback to guide a fixed VLA executor. • An execution-driven self-evolution procedure that autonomously proposes and evaluates revisions to planning guidance, assessment criteria, and control rules from rollout feedback, without constructing an SFT dataset. • We evaluate SERA on RoboMME and achieve 51.38% overall success.
