# Cracking Mobile Manipulation: From Failure Diagnosis to Agentic Robot System

## Abstract
Recent vision-language-action (VLA) models have shown strong performance on local robot manipulation, yet their success does not readily translate to long-horizon mobile manipulation. In our experiments, a pretrained subtask VLA achieves 80% success rate on atomic manipulation tasks but only 19% when these skills are composed into mobile manipulation. We argue that this gap stems from failures across the execution process rather than from local manipulation capability alone. To uncover these bottlenecks, we systematically diagnose failures in long-horizon mobile manipulation and identify three dominant regimes: task planning, navigation and base positioning, and local manipulation. Based on this diagnosis, we develop failure-guided agentic intervention that augments a fixed subtask VLA with demonstration-based planning guidance, adaptive visual memory, accessibility-aware base adjustment, and local end-effector adjustment. On RoboCasa365, these interventions progressively improve task success from 19% to 47%, with the finalized system reaching 49% on held-out episode seeds, compared with 18% for the baseline. The same design improves performance from 14% to 37% on BEHAVIOR-1K and from 5/20 to 13/20 on real-robot tasks. These results suggest that reliable mobile manipulation can be advanced by diagnosing and intervening on the current bottleneck, rather than uniformly scaling the underlying policy. Our code will be released at https://github.com/PKU-VaLuE-Lab/Cracking-Mobile-Manipulation.git.

## 2 Introduction
Recent vision-language-action (VLA) models have achieved strong performance on robot manipulation, particularly for the tasks that can be completed within a local tabletop ( Zitkovich et al., 2023 ; Black et al., 2025b ; Black et al., 2025a ; Wen et al., 2025 ) . Agentic systems further extend these capabilities to long-horizon mobile manipulation, through high-level planning, execution feedback, and tool use ( Ichter et al., 2023 ; Zhang et al., 2026b ; Fu et al., 2026 ) . Yet mobile manipulation exposes a striking gap between solving individual subtasks and reliably composing them over time. Unlike tabletop manipulation, a mobile robot is required to move across workspaces while maintaining task progress, and every movement changes the viewpoint and base configuration from which the next manipulation is executed ( Yenamandra et al., 2023 ; Fu et al., 2025 ; Liu et al., 2024a ; Wu et al., 2025 ) . As a result, strong local manipulation do not necessarily translate into reliable long-horizon mobile manipulation. Figure 1: From the mobile manipulation gap to failure-guided intervention. (a) Strong subtask VLA does not translate to reliable long-horizon mobile manipulation. (b) Failure analysis identifies the dominant failures: task planning, navigation and base positioning, and manipulation. These observations motivate our agentic intervention, including: in-context guidance from video demonstrations, adaptive visual memory, accessibility checking and base adjustment, and end-effector adjustment. The gap is surprisingly large. As shown in Figure 1 , a pretrained subtask VLA achieves 80% success rate on atomic manipulation tasks, yet the corresponding agentic baseline achieves only 19% on long-horizon mobile manipulation tasks. This discrepancy suggests that the central challenge is not simply whether the robot knows how to manipulate, but whether it can reliably carry a manipulation skill through the sequence of decisions and physical states required by mobile manipulation tasks. Specifically, a long-horizon task can fail even before manipulation begins: the planner may select the wrong target or lose track of task progress; navigation may reach the correct workspace but leave the robot in an unusable base pose; and even from a seemingly appropriate configuration, small errors in localization or end-effector alignment can derail the final interaction ( Yenamandra et al., 2023 ; Liu et al., 2024a ; Huang et al., 2023b ) . In this sense, what reliable mobile manipulation requires is not simply making a local skill stronger, but identifying where the execution pipeline breaks down. This leads to a fundamental question: Where does mobile manipulation actually fail over long-horizon tasks, and how can an agent intervene at the bottleneck? We answer this question by cracking the failure structure of mobile manipulation. Starting from a pretrained VLA that already performs individual tabletop subtasks well, we systematically analyze its failures when these subtasks are composed together. Our analysis reveals three dominant failure regimes that form a natural progression through the execution: task planning, navigation and base positioning, and local manipulation. Planning errors prevent the robot from pursuing the correct subtask, while navigation errors prevent it from reaching an executable configuration. And manipulation errors remain after the robot has successfully reached the intended workspace. This diagnosis motivates a simple but powerful principle: intervene where the current system breaks, rather than uniformly increasing the capability of the underlying policy. Guided by this principle, we develop a failure-guided agentic framework that progressively adds targeted interventions around a fixed subtask VLA. For planning, in-context guidance from video demonstrations provides explicit task procedures ( Zhong et al., 2023 ; Wang et al., 2023 ) , while adaptive visual memory retains what has already been accomplished and what remains to complete ( Yoneda et al., 2024 ; Sridhar et al., 2026 ) . For navigation, an accessibility check evaluates whether the current robot configuration is suitable for the upcoming manipulation, followed by base adjustment when the approach is geometrically inadequate. Finally, for local execution, end-effector adjustment refines the interaction pose to compensate for residual spatial misalignment. These components are not independent add-ons: each is directly motivated by a diagnosed failure mode, transforming failure analysis into targeted agentic intervention. We evaluate the resulting agentic system on all mobile manipulation composite tasks in RoboCasa365 ( Nasiriany et al., 2026 ) . Despite 80% success rates on atomic tasks, the agentic baseline achieves only 19% task success in the long-horizon tasks. Progressively introducing the proposed interventions raises success rate to 47% . This remarkable gain generalizes to held-out episode seeds, improving baseline from 18% to 49% success rate. The same design also improves performance beyond RoboCasa365, raising the task success rate from 14% to 37% on five BEHAVIOR-1K tasks ( Li et al., 2023 ) and from 5/20 to 13/20 on two real-robot tasks. Taken together, these results suggest a different way to approach long-horizon mobile manipulation. Rather than treating the robot as a monolithic policy whose capability must be scaled uniformly, we view it as an agentic system whose reliability can be improved by diagnosing bottleneck and intervening it precisely. Our contributions are summarized as follows: • A systematic failure diagnosis of mobile manipulation. We analyze the gap between strong subtask-level manipulation and long-horizon mobile manipulation, identifying three dominant failure regimes: task planning, navigation and base positioning, and local manipulation. The analysis turns overall success gap into a concrete, stage-wise failure structure. • A failure-guided agentic intervention framework. Based on the diagnosed bottlenecks, we introduce targeted interventions around a fixed subtask VLA, including demonstration-based planning guidance, adaptive visual memory, accessibility-aware base adjustment, and local end-effector adjustment. • Agentic intervention consistently improves the performance of mobile manipulation. The proposed interventions improve the success rate from 19.0% to 47.0% on RoboCasa365. Our experiments further demonstrate consistent gains on held-out RoboCasa365 episodes, BEHAVIOR-1K tasks, and a real dual-arm mobile manipulator. \FloatBarrier
