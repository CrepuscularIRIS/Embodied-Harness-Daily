# Wave-1 weak fits — group-3 reading notes (full text, 2026-10-21)

New clusters proposed here: **i** = teacher-SFT then GRPO with an *offline* reference-matching reward (no simulator in the RL loop); **j** = bandit selection over reusable LLM-written task annotations, scored by rollout success, to mass-produce demos for an IL student.

### 2505.22050 v2 — Reinforced Reasoning for Embodied Planning
- OPERATION: SFT a VLM on Gemini-2.0-flash responses, then GRPO on ALFRED step-decomposed samples with a format reward plus a prefix-match reward against the gold remaining-action list.
- INFO ACCESS: Teacher Gemini (frozen) sees the prompt and history. The student Qwen2.5-VL-7B is fully trained and sees the image, goal and action history. The reward uses the gold ALFRED trajectory, and no environment interaction happens during RL (§5).
- CLUSTER: new **i**. Not K708, because the reward is not outcome-based.
- WORKS: EB-ALFRED 35.6 vs base 1.7 and GPT-4o-mini 22.0 (Table 1). EB-Habitat 20 vs base 12.7 (Table 2). SFT→RFT 35.6/20 vs SFT-only 21/12.3 (Table 3).
- FAILS: Long-horizon only 6 (Table 1). On Habitat it stays below Llama-11B (23.3) and GPT-4o (54.0) (Table 2). Single runs. The ~4000 teacher samples are not said to be success-filtered (§3.2).
- COUNTER: SFT-only drops OOD performance below base (12.3 vs 12.67). RFT-only beats SFT-only on Habitat (15.6) (Table 3).

### 2506.07509 v1 — Taking Flight with Dialogue (PX4 drone agent)
- OPERATION: A local LLM emits only `Turn(θ∈±90°)` / `Move(d∈±3 m)` from the context plus the last 5 commands. A separate VLM answers yes/no on whether the target is present, and PX4 executes.
- INFO ACCESS: All Ollama models are frozen, with CoT suppressed and temperature 0.2. The LLM sees the text goal coordinates and history. Only the VLM sees the image.
- CLUSTER: K104 (the UAV "—" row). The mechanism matches, but the paper is a model benchmark rather than an interface study.
- WORKS: Best success is 40% for Gemma3 LLM + Gemma3 VLM. DeepSeek-LLM has 38% valid commands and 0–5% success (Table I). Each pair ran 20 episodes with at most 20 steps (§IV).
- FAILS: The authors say the differences "may reflect random variation". There is no latency or token data and no ablation of history or few-shot (§IV). The real-robot result is qualitative only (Fig. 4).
- COUNTER: Even with 100% valid commands and 100% valid detections, success is only 30–40%. Command values overshoot or undershoot, so the restricted vocabulary is not the bottleneck (§IV).

### 2506.17811 v2 — RoboMonkey
- OPERATION: Sample N actions from a VLA, fix the gripper by majority vote, fit a Gaussian to the pose deltas, draw K candidates, score each with a learned VLM verifier and execute the argmax.
- INFO ACCESS: OpenVLA is frozen. The LLaVA-7B reward model is trained (LoRA) on 20M synthetic pairs ranked by RMSE to the Bridge demo action (§4.2, §5.1). It sees the image, instruction and action.
- CLUSTER: **f**.
- WORKS: SIMPLER 47.5%, +9 points over OpenVLA (Fig. 3). Real OOD 60% vs 35% (OpenVLA) and 30% (V-GPS) (§5.3). LIBERO-Long 56.5 vs 49.8 (Table 1). Growing the verifier data takes SIMPLER from 37.5 to 46.3 (§5.5). 16 candidates take 650 ms (§5.4).
- FAILS: The scaling law assumes an oracle verifier against ground-truth RMSE (§3). The verifier's target is demo-RMSE, a proxy for success. Real tests use 10 trials per task. Runs at 1.5 Hz.
- COUNTER: Pairing OpenVLA with V-GPS (another verifier) scores below OpenVLA alone (§5.2). LIBERO tasks with no gain: Stove 58/58, Moka 26/26 (Table 1).

### 2506.23127 v1 — Embodied Planner-R1
- OPERATION: Run grouped parallel ReAct rollouts inside the environment. The reward is 0/1 task completion with no format reward, and there is a "done" action. Update with a GRPO-style policy gradient (IPO) whose ratio covers each step's thought and action tokens.
- INFO ACCESS: Qwen2.5-7B-Instruct is fully trained and sees only the text observations and history. No teacher, no demos.
- CLUSTER: K704. The operation fits once "code harness" is relaxed to a text-action interface. The setting is text-only.
- WORKS: ALFWorld 97.78 (seen 99.29 / unseen 96.27) vs ETO 82.07 and base 31.05. ScienceWorld 79.92 vs SFT 62.26 (Table 1). Generalization gap −3.33 vs −7.34 for ETO (Table 2).
- FAILS: Each task is evaluated once. The base model already scores 31%, so success is nonzero without a teacher (inferred). ScienceWorld uses the simplified "Easy" mode (§4.3). The abstract says −3.66, the table −3.33. Baselines are re-implemented.
- COUNTER: None. The Look task still drops 12.5 points on unseen (Table 2).

### 2507.01378 v2 — RALLY (UAV swarm)
- OPERATION: Each UAV's LLM proposes a target. An RMIX-trained MLP picks a role (Commander, Coordinator or Executor). A second LLM call refines the target into a consensus using neighbours' intents and roles. Illegal outputs fall back by role hierarchy.
- INFO ACCESS: Local numeric observations are turned into text. Qwen2.5 (0.5–7B) is LoRA-tuned on 8,231 filtered GPT-4o samples. RMIX is trained semi-offline. The mid-level MARL and PID controllers are pre-trained and frozen (§2.1, §4.1).
- CLUSTER: **c**, with a K501-like distillation step.
- WORKS: Highest mean reward over 30 test episodes (Fig. 6; values shown only in the figure). Holds up at swarm sizes 9–11 where CIHRL drops (Fig. 9). The three-role setup beats one role (≈−3,000) (Fig. 12).
- FAILS: The text reports almost no numeric results. The task and benchmark are the authors' own. SITL validation is qualitative (Fig. 16). Inference takes ~15 s per call (Table 3). The GPT-4o online baseline is confounded by API latency (§4.3.3).
- COUNTER: Adding a fourth role (Decoy) lowers the reward (§4.3.2).

### 2507.01485 v1 — BioMARS (wet-lab)
- OPERATION: A Biologist agent writes a protocol with RAG, then knowledge-checker and workflow-checker LLMs edit it. A CodeGenerator maps it to 11 primitives and a rule-based CodeChecker corrects the code. At runtime a ViT keyframe gate triggers a VLM check, which aborts on error.
- INFO ACCESS: GPT-4o/DeepSeek-R1 frozen. InternViT is used through a reference embedding library. VLM bounding boxes are manually refined (§2.4).
- CLUSTER: **c** as listed; really generator→checker stages plus runtime abort, overlapping K201.
- WORKS: Code instruction-matching 96.4% vs 92.4% for the single module, on 300 steps (Fig. 3d). The VLM stage reaches precision 95.7% and cuts FPR from 8.7% to 1.4% (Fig. 4).
- FAILS: Protocol quality uses the authors' own 5-point scale with no inter-rater check. Replanning keeps a human in the loop (Alg. 1). Humans still oversee volumes and centrifugation (§3). The RPE optimization numbers contradict each other (final 0.5913 < 0.6252 at iteration 7; GPT-4o 0.4344 vs "plateaued at 0.606") (§2.6).
- COUNTER: The VLM stage F1 is 80.7%, below the ViT-only F1 of 88.7% (Fig. 4c) (inferred trade-off).

### 2508.02629 v2 — HyCodePolicy
- OPERATION: A frozen LLM writes subgoal code over geometric primitives. Each program runs 10 times. A VLM judges checkpoint images from the most informative failed trial, and the fused symbolic and visual diagnosis drives a code edit, in a loop.
- INFO ACCESS: DeepSeek-V3 (code) and moonshot-v1-vision (monitor) are frozen. The monitor sees RGB-D checkpoints and the sim symbolic logs.
- CLUSTER: **e**. No agent-written probe program, so not K203.
- WORKS: ASR 47.4 (CaP) → 60.4 (CodeAct) → 63.9 on RoboTwin1.0, and 62.1 → 66.7 → 71.3 on Bi2Code (Table 1).
- FAILS: Only 10 tasks. Bi2Code and RT1.0 use different planners and are not comparable (§4.4), yet the headline 2.42 → 1.76 iterations compares them. The 40 extra tasks have 0% success where a skill is missing (§4.5). No real robot.
- COUNTER: Most of the gain comes from symbolic feedback (+13.0) rather than the VLM (+3.5). Under HyCodePolicy, Handover drops 50 → 27, Place Container 84 → 82 and Stack Two 68 → 64 (Table 3). CR-Iter goes 2.46 → 2.42 on RT1.0.

- OPERATION: A single VLM acts as the high-level layer. It emits chain-of-thought, atomic commands for a low-level controller, and spoken replies. Training runs continued pretraining, then SFT, then RL.
- INFO ACCESS: Abstract only. The VLM is trained; the low-level controller's status and the teacher data are unknown.
- CLUSTER: **b** (tentative).
- WORKS: Unclear (abstract claims it beats GPT-4o and Gemini 2.5 Pro; no numbers).
- FAILS: Unclear; no full text.

### 2509.20070 v2 — LLM Trainer
- OPERATION: GPT-4o annotates one demo (keyframes, salient objects, retargeting rules). A second call retargets the key poses for a new scene, the demo trajectory is warped and executed, and successes are kept. Thompson sampling picks which reusable annotation to use next.
- INFO ACCESS: Frozen LLM sees the start/end images plus robot and object poses (sim ground truth; SAM + GroundingDINO on hardware) (§III-A). The IL student is trained on the successes.
- CLUSTER: new **j**. Closest is K503, but a bandit selects among sampled annotations; nothing is revised from failure logs.
- WORKS: Best annotation 44/60/89/92/89/58% vs no optimization 12/20/39/65/34/14% (Table II). Hardware: 75.8% generation, 45% without optimization. IL/FF/ensemble 60/80/85% over 20 trials (§IV-A).
- FAILS: The IL student only matches MimicGen (Table III). Real rollouts need supervision; LLM cost is ignored (§V). The feedforward plan scores 14% on walking-stack.
- COUNTER: Total generation rate trails the baseline on Stack (79.1 vs 80.0). Ensembling hurts at high data: Kitchen 63.6 vs 100.0 at 1000 demos (Table III), Stack-Walking 400: 59.6 vs 76.8 for IL (Table IV).

### 2509.24230 v2 — ELHPlan
- OPERATION: A centralized LLM writes intention-bound multi-step Action Chains with `replan` placeholders. A rule validator checks each next action's preconditions against the shared state and flags same-object conflicts between agents. LLM refinement, conflict resolution or chain insertion repairs any flagged chain.
- INFO ACCESS: GPT-4o, 4o-mini and Llama3.1 are frozen. The simulator supplies ground-truth object and agent states (§IV-A).
- CLUSTER: **c**, with a K201-style precondition gate as a component.
- WORKS: TDW-MAT token cost 29.64K vs 70.18K for CoELA with a similar TR (78.54 vs 77.50) (Table I). C-WAH 22.22K tokens / 78.62 s vs REVECA's 72.51K / 411.25 s (Table II). Removing Action Chains raises SS by 62.9% (Fig. 7).
- FAILS: Success stays below REVECA (TR 79.17 vs 87.00; SS 54.10 vs 49.68). Move distance is worse (Tables I–II). Only 24 and 10 test tasks. The validator is never ablated on its own. Constraint violations and hallucinations are still observed (§IV-E).
- COUNTER: Dropping chain-level refinement lowers both TC and MD (§IV-D), so the refinement step is not free.
