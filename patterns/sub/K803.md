# K803 — Swap the model under a fixed embodied harness and the harness under a fixed model on the same episodes
_parent: **Separate the Harness Effect from the Model Effect** ([`harness_effect_evaluation`](../main/harness_effect_evaluation.md)) · status: candidate_pattern · source card: `K803-embodied-model-harness-swap.md` (frozen domain `embodied-agent-harness/v1`)_

## Operation
hold the harness fixed and swap the model, and hold the model fixed and swap the harness or loop director, on fixed embodied episodes

- Information access: Frozen models; same episodes; baselines rerun with the same backbone where stated.
- Transfer: Same-subset reruns are feasible in simulators; repeats are the missing piece.
- Status: candidate_pattern (4 full-text paper(s))

## When it works
- Fixed 100-episode subsets with baselines rerun on the same backbone (2606.10577#s4, 2609.15195#s4)
- One-factor-at-a-time over model families (2606.10267#s4)

## When it fails
- Harness gain varies 6-22 SR with backbone; no cost reported (2606.10577#s4)
- Single runs without variance (2609.15195#s4)
- Serving and context handling differ across harnesses, so complete systems are compared; workflow vs agent confounded with action interface (2607.26148#s3)
- Hierarchy components swing success from ~95% to ~0% even with a near-perfect VLA proxy (2606.10267#s4)

## Counterexamples
- none found in the readings
