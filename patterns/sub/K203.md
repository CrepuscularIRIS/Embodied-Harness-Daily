# K203 — After a scored attempt, let the agent write and run a diagnostic program before resetting
_parent: **Gate, Monitor and Diagnose Actions Outside the Model** ([`external_verification_control`](../main/external_verification_control.md)) · status: case · source card: `K203-post-attempt-diagnostic-program.md` (frozen domain `embodied-agent-harness/v1`)_

## Operation
after each attempt, have the coding agent synthesize a separate View/Probe program to gather evidence on unresolved outcomes, then decide FINISH or REGENERATE

- Information access: Frozen coding agent; evaluator ground truth, scores and success labels excluded from agent output; Diagnostic runs after scoring and before reset, so risky actions carry no credit or penalty. Aerial manipulator domain.
- Contrasts: Contrasts with K204 (backtracking tools that read privileged full state).
- Transfer: Only for resettable simulation, i.e. teacher-data generation rather than deployment.
- Status: case (1 full-text paper(s))

## When it works
- A simulator where diagnostics run after scoring and the state resets before the next attempt; revised programs rerun from the initial state (2610.12549#s1)

## When it fails
- Adds inference and interaction overhead; bounded by onboard perception errors and unreachable viewpoints; probing gives no hardware safety; Cabinet still 40%; not applicable to single-shot real episodes (2610.12549#s1)

## Counterexamples
- none found in the readings
