# K804 — Decompose outcomes into failure categories, endpoints and per-task repeat patterns
_parent: **Separate the Harness Effect from the Model Effect** ([`harness_effect_evaluation`](../main/harness_effect_evaluation.md)) · status: candidate_pattern · source card: `K804-failure-endpoint-decomposition.md` (frozen domain `embodied-agent-harness/v1`)_

## Operation
classify failed runs by cause or terminal state and tasks by repeated-run outcome pattern, and report these with pass rate

- Information access: Logged trajectories and terminal metadata only; no model internals.
- Transfer: Embodied endpoints (wrong stop vs never reached) are the natural categories.
- Status: candidate_pattern (5 full-text paper(s))

## When it works
- Logged turn-level tool trajectories (2605.23950#s2, 2607.22585#s2)
- Multiple runs per setting (2609.29861#s2)

## When it fails
- Metrics not estimated on any grid; attribution is co-movement (2605.23950#s2)
- No-action turns are a proxy; 20% manually reviewed (2607.22585#s2)
- Category assignment procedure unspecified (2606.14674#s3)
- Does not identify causes or test interventions (2609.29861#s2)
- Cannot tell when a correct patch first existed (2609.11987#s2)

## Counterexamples
- none found in the readings
