# K603 — Query the teacher only at learner states flagged by a gate
_parent: **Correct, Review or Relabel at Learner-Induced States** ([`learner_state_teacher_correction`](../main/learner_state_teacher_correction.md)) · status: candidate_pattern · source card: `K603-gated-selective-teacher-query.md` (frozen domain `embodied-agent-harness/v1`)_

## Operation
during learner rollouts, query the teacher only at states flagged by a gate and train on those teacher actions

- Information access: Gate: discriminator flags student states the teacher never visited (2505.09546#s1); learner normalized entropy above threshold (2609.01567#s1); Teacher: privileged on hidden context, labels aggregated DAgger-style (2505.09546#s1); frozen VLM seeing the same RGB, returns one action, action executed, absent at eval (2609.01567#s1, s2); Loss: imitation + discriminator term (2505.09546#s1); PPO on learner transitions, BC on teacher transitions (2609.01567#s2).
- Contrasts: Information contrast: privileged teacher (2505.09546#s1) vs same-observation black-box teacher (2609.01567#s1).
- Transfer: Reduces teacher-query cost, the binding constraint for a slow frontier teacher.
- Status: candidate_pattern (2 full-text paper(s))

## When it works
- Teacher near-optimal and queryable at student states; hidden context irrecoverable (2505.09546#s1)
- Discrete actions; teacher retains some competence; sparse-reward exploration bottleneck (2609.01567#s1)

## When it fails
- Early discriminator errors misclassify; too strong a discriminator increases aliasing; only small 3-4 goal tasks (2505.09546#s1)
- Entropy conflates uncertainty with multimodality; continuous VLM actions poor; a random teacher degrades (2609.01567#s1)
- AWBC no consistent benefit; direct VLM performance does not predict teacher usefulness (2609.01567#s2)

## Counterexamples
- The entropy-gated learner loses to VLM-as-policy on Fetch (0.122 vs 0.310) and to PPO on LavaGap (2609.01567#s2)
