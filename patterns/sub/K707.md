# K707 — Inject teacher-written skill hints into RL rollouts only, removed at evaluation
_parent: **Make Sparse-Success Embodied RL Learnable** ([`teacher_seeded_sparse_rl`](../main/teacher_seeded_sparse_rl.md)) · status: case · source card: `K707-rollout-only-teacher-guidance.md` (frozen domain `embodied-agent-harness/v1`)_

## Operation
have a frozen teacher contrast a success and a failure rollout to write a short screened skill, inject it during GRPO rollouts for assisted tasks, and remove it at evaluation

- Information access: Teacher sees issue text and two current-policy trajectories, no hidden tests; policy sees the skill only in training.
- Transfer: A privileged-during-training channel; same identifiability caution as F6.
- Status: case (1 full-text paper(s))

## When it works
- Binary verifiable reward; group RL with zero-variance groups; guidance must not reveal the answer (2610.28069#s1)

## When it fails
- General skill bank does not help; single seed; software repair only (2610.28069#s1)

## Counterexamples
- Near-answer hints raise training success but hurt no-hint evaluation (-2.6 pp vs GRPO) (2610.28069#s1)
