# K506 — Instead of cloning a privileged expert, estimate its missing state inputs and run it frozen
_parent: **Generate Supervision with a Privileged Teacher the Student Cannot See** ([`privileged_teacher_supervision`](../main/privileged_teacher_supervision.md)) · status: case · source card: `K506-estimate-inputs-of-frozen-privileged-expert.md` (frozen domain `embodied-agent-harness/v1`)_

## Operation
train a perception module to predict the privileged expert's missing state inputs from cameras, feed them with proprioception to the frozen expert, and ramp from state-MSE to action-MSE through the expert's Jacobian

- Information access: Expert frozen and differentiable, defined over fixed physical state variables; trained on 10,000 rollouts including failures; Deployment estimator sees 4 multi-view frames, proprioception and goal, no simulator state.
- Transfer: Applies only when the privileged channel is a state vector; a tool-using frontier teacher has no such input vector.
- Status: case (1 full-text paper(s))

## When it works
- Privileged expert exists over fixed state variables that are inferable from cameras (2609.34018#s1)
- State supervision first, then action loss through a deterministic differentiable expert (2609.34018#s2)

## When it fails
- Real failures from contact mismatch; with 3x budget a full-state flow clone closes much of the gap; most pixel-BC cells single-seed (2609.34018#s1)
- Weighting task-dependent; abrupt switch or flat action weight collapses; action-only converges 1/3 seeds (2609.34018#s2)
