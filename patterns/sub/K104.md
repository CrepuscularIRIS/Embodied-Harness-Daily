# K104 — Restrict the model to a discrete semantic action vocabulary executed by a deterministic or frozen low-level executor
_parent: **Design the Frozen Model's Observation and Action Interface** ([`observe_act_interface`](../main/observe_act_interface.md)) · status: candidate_pattern · source card: `K104-semantic-action-calls-delegated-executor.md` (frozen domain `embodied-agent-harness/v1`)_

## Operation
restrict model output to a fixed vocabulary of semantic actions and map each one deterministically to a lower-level executor

- Information access: Sub-condition (a) motion units: one token of incremental view-relative motion/rotation/gripper, mapped by an embodiment interpreter that holds setpoint, step size, frame mapping and safety limits (2609.10522#s1); Sub-condition (b) entity calls: four tool calls over online scene-graph entities and frontiers, executed by a frozen PointGoal navigator; model sees SG text plus set-of-marks RGB, no raw depth or metric map (2606.27871#s1); Frozen frontier teacher in both; the same interface is later piloted by a student (see K501, K502).
- Contrasts: (a) vs (b) differ in what the model must ground: relative motion vs map entities. Contrasts with K105 (code instead of a fixed vocabulary).
- Transfer: Assumes a reliable executor below the vocabulary (interpreter or point-goal policy); the semantic level (motion unit vs entity goal) must match what the executor can do.
- Status: candidate_pattern (2 full-text paper(s))

## When it works
- Parallel-jaw tabletop manipulation, 50-step cap; units must follow conventions (arbitrary symbols succeed 1/20) (2609.10522#s1)
- Static indoor scenes where a scene graph can be built online; simulation uses ground-truth semantic labels (2606.27871#s1)

## When it fails
- Errors concentrate on fine-grained grasping and placement; agentic baselines may not be model-fixed (2609.10522#s1)
- Scene graph cannot bind transient or compositional semantics; sparse VLM verification misses cues; no harness-component ablation (2606.27871#s1)
