# K204 — Give the coding-agent solver checkpoint/backtrack and parameter-search tools over full simulator state
_parent: **Gate, Monitor and Diagnose Actions Outside the Model** ([`external_verification_control`](../main/external_verification_control.md)) · status: case · source card: `K204-privileged-checkpoint-search-tools.md` (frozen domain `embodied-agent-harness/v1`)_

## Operation
add a checkpoint tree over simulator states, CMA-ES parameter search, parallel program sweeps and an assessment log to the agent's native harness

- Information access: Teacher-side only: tools read and restore full simulator state and optimize agent-specified privileged objectives; uses a second GPU; Downstream VLA student never sees these (see K503, K504).
- Transfer: A way to raise teacher success under privileged access; transfer requires state save/restore in the target simulator.
- Status: case (1 full-text paper(s))

## When it works
- Model fixed; tools added as a bundle; resettable batched simulation (2609.27308#s2)

## When it fails
- Bundle-level ablation only; compute not matched (extra GPU); single run per task (2609.27308#s2)

## Counterexamples
- Success rate for Opus 5 drops with the tools (2609.27308#s2)
