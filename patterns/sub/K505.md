# K505 — A privileged rule teacher acts step by step in the student's skill vocabulary, with templated state reasoning
_parent: **Generate Supervision with a Privileged Teacher the Student Cannot See** ([`privileged_teacher_supervision`](../main/privileged_teacher_supervision.md)) · status: case · source card: `K505-interface-aligned-privileged-rule-teacher.md` (frozen domain `embodied-agent-harness/v1`)_

## Operation
let a privileged rule teacher choose each next skill from the student's vocabulary after observing the result, annotate each step with templated state-estimation reasoning from sim ground truth, and train the student to output reasoning then action

- Information access: Teacher: rule-based, uses masks, goal poses, paths, bearings; student: head RGB, instruction, skill definitions, prior calls, key frames; Reasoning labels derived from privileged data, but the student must produce them from its own observations.
- Contrasts: Contrasts with K503 (teacher in a different action space from the student).
- Transfer: Close analogue of a privileged-planner teacher for navigation; the identifiability check is the missing step.
- Status: case (1 full-text paper(s))

## When it works
- Pre-mapped environment with known localization; simplified grasping; short horizons (2610.15572#s1)
- Labels derivable from simulator ground truth (2610.15572#s2)

## When it fails
- Generalization bounded by teacher data diversity; real robot 38%; only short single-room navigation; no on-policy correction (2610.15572#s1)
- No check whether templated privileged descriptions (e.g. out-of-view direction) are identifiable from student observations (2610.15572#s2)

## Counterexamples
- none found in the readings
