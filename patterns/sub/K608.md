# K608 — Sample target actions from a model copy given privileged context, then verify or match
_parent: **Distil On-Policy with Logit, Privileged-Self, Agreement or Harness-Contrast Signals** ([`on_policy_distillation_objectives`](../main/on_policy_distillation_objectives.md)) · status: candidate_pattern · source card: `K608-privileged-self-action-targets.md` (frozen domain `embodied-agent-harness/v1`)_

## Operation
sample target actions from a copy of the model given privileged context and use them as student targets after verification or as an agreement reward

- Information access: Privilege: harness-internal runtime state compiled into a control document, frozen base model as teacher, harness verifier + nearest-to-reference (2610.20261#s1); Privilege: private user goals, reference actions and outcomes, current weights as teacher (2610.19820#s3); Student sees public/native context only at train and eval.
- Contrasts: Contrasts with K606 (dense logit signal) and K609 (external teacher, no privilege).
- Transfer: Applicable when harness state is inspectable at each model call; embodied harness state (maps, depth receipts) would be the privileged document.
- Status: candidate_pattern (2 full-text paper(s))

## When it works
- Recorded actions executable and deterministically replayable under the target harness; inspectable runtime state (2610.20261#s1)
- Privileged information available at training time (2610.19820#s3)

## When it fails
- Only successful reference prefixes supervised; exact-match verifier needs a reference action, unavailable in open-ended embodied control (2610.20261#s1)
- Gains smaller than with external teachers; identifiability of privileged-guided actions not analysed (2610.19820#s3)
