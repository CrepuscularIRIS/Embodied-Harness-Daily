# K602 — A frontier harnessing agent reviews every student proposal and replaces unsound ones with corrections valid in the minimal harness
_parent: **Correct, Review or Relabel at Learner-Induced States** ([`learner_state_teacher_correction`](../main/learner_state_teacher_correction.md)) · status: case · source card: `K602-online-proposal-review-replace.md` (frozen domain `embodied-agent-harness/v1`)_

## Operation
intercept each student proposal before execution, pass or replace it with the smallest correction valid under the minimal target harness, and SFT the student on accepted responses for minimal-harness deployment

- Information access: Reviewer: frozen frontier model reading adapted reference-harness components (evolved tools/middleware/skills retargeted as review criteria); cannot see sandbox, hidden solutions or verifier; Review reasoning and rejected proposals stay out of the student trajectory; Student does not keep the harness: it deploys under the minimal harness alone.
- Transfer: Per-step frontier review at embodied latency and with irreversible actions is untested.
- Status: case (1 full-text paper(s))

## When it works
- Capable reviewer; deterministic verifiable sandbox tasks; expressive student action space (2609.24974#s1)
- Evolved components expressible as student actions or review criteria (2609.24974#s2)

## When it fails
- Weaker reviewers net harmful (-12.0 pp Qwen3.6-35B-A3B replacing 66% of steps); latency roughly doubles; context management not expressible (2609.24974#s1)
- Deep domain knowledge internalized less (30.0 vs 38.0) (2609.24974#s2)
- Ablation only on USPTO; single seed; text/tool domains, fully observable (2609.24974#s3)

## Counterexamples
- none found in the readings
