# K802 — Hold the model fixed and toggle one harness component or layer at a time
_parent: **Separate the Harness Effect from the Model Effect** ([`harness_effect_evaluation`](../main/harness_effect_evaluation.md)) · status: candidate_pattern · source card: `K802-model-fixed-component-ablation.md` (frozen domain `embodied-agent-harness/v1`)_

## Operation
hold the backbone (or distilled student) fixed and add, remove or swap one harness component or layer at a time

- Information access: Frozen VLM/LLM backbones (2606.18363#s1, 2606.14674#s1, 2609.20822#s3, 2610.12549#s2); distilled student with harness categories hidden or enforced at evaluation (2610.02858#s3).
- Transfer: The ablation that the harness-vs-model confound calls for; members are still mostly cumulative or single-run.
- Status: candidate_pattern (5 full-text paper(s))

## When it works
- Fixed typed interfaces so variants differ only in the chosen module (2606.14674#s1)
- Scenes, seeds and backbone fixed (2609.20822#s3)

## When it fails
- Ablations on base models only, not the student (2606.18363#s1)
- Best module environment-dependent; small suites, missing cells (2606.14674#s1)
- Single benchmark, no seed variance (2609.20822#s3)
- Magnitude varies across model-interface pairs; two tasks (2610.12549#s2)
- Internalization interpretation suggestive; ALFWorld only (2610.02858#s3)

## Counterexamples
- Unstructured evidence access occasionally helps (Payload with Claude Code Opus 5.5) (2610.12549#s2)
- Qwen3.5-2B in the same harness makes frequent invalid tool calls (2.2%) (2606.18363#s1)
