# K606 — Score the student's own tokens with a privileged-context copy of itself and add the divergence to RL
_parent: **Distil On-Policy with Logit, Privileged-Self, Agreement or Harness-Contrast Signals** ([`on_policy_distillation_objectives`](../main/on_policy_distillation_objectives.md)) · status: candidate_pattern · source card: `K606-privileged-self-teacher-dense-kl.md` (frozen domain `embodied-agent-harness/v1`)_

## Operation
let the student sample without privileged info, score its tokens with the same weights conditioned on privileged context, and add a per-token divergence to GRPO, optionally gating which responses are distilled

- Information access: Teacher = same parameters + privileged context, stop-gradient; needs own logits, no frontier logits; Privilege: information derived from frontier action traces (2602.04942#s2); the realized next screenshot from a demonstration (2608.06065#s1); Gate on low student step reward and teacher top-1 matching the demo (2608.06065#s2).
- Contrasts: Contrasts with K608 (privileged self samples actions, no logits used) and K607 (privileged view trained jointly).
- Transfer: Requires a white-box student and privilege the student-sized model can interpret.
- Status: candidate_pattern (2 full-text paper(s))

## When it works
- Information-rich privilege; teacher-student KL not excessive; larger student (2602.04942#s2)
- Next observation reveals the action's effect; SFT start; hard subset (2608.06065#s1)
- A verifiable step-level action match for the gate (2608.06065#s2)

## When it fails
- Excessive KL overrides utility; OOD degradation on Qwen3-4B (2602.04942#s2)
- Gains not uniform per app; untested on long-horizon or partially observed physical tasks (2608.06065#s1)
- If all resamples fail the gate, no hindsight signal (2608.06065#s2)

## Counterexamples
- Reference action alone as privilege does not beat SFT (2608.06065#s1)
