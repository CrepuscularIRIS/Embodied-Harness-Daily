# K805 — Re-price runs from raw per-turn usage and reconcile against billed spend
_parent: **Separate the Harness Effect from the Model Effect** ([`harness_effect_evaluation`](../main/harness_effect_evaluation.md)) · status: case · source card: `K805-cost-reconciliation.md` (frozen domain `embodied-agent-harness/v1`)_

## Operation
re-price every run from raw per-turn usage with explicit cache terms, reconcile against the ledger and billed spend

- Information access: Raw usage events, SDK-specific token semantics, list prices.
- Transfer: Teacher cost per trajectory is a key unknown for harness distillation; this is the accounting method.
- Status: case (1 full-text paper(s))

## When it works
- Raw per-turn events retained; caching dominates cost (2609.11987#s3)

## When it fails
- 58 runs without usage records; cache-write pricing uncertain ~2x; truncation probe inconclusive (2609.11987#s3)

## Counterexamples
- none found in the readings
