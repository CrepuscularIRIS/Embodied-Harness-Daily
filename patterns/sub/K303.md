# K303 — Mine, consolidate and review a reusable skill library from successful executions or demonstrations
_parent: **Build Context, Notes and Skills with the Weights Frozen** ([`harness_memory_skill_reuse`](../main/harness_memory_skill_reuse.md)) · status: candidate_pattern · source card: `K303-curated-skill-library.md` (frozen domain `embodied-agent-harness/v1`)_

## Operation
extract reusable skills from successes or demos, have a frontier model consolidate/edit/review them, and expose the frozen library at run time

- Information access: Frozen agent; library frozen before evaluation; 2603.22435#s2: pooled successful programs across 12 models; success labels from the simulator; 2609.29964#s2: expert videos and human corrections; Editor and Reviewer models; Skill Agent compares reference images in a separate context.
- Transfer: If the student keeps the harness, it inherits the library for free; whether a small student can use it is untested.
- Status: candidate_pattern (2 full-text paper(s))

## When it works
- Success-filtered low-level rollouts exist (2603.22435#s2)
- Model fixed across skill settings; demo source scenes disjoint from evaluation (2609.29964#s2)

## When it fails
- Single synthesis pass mined from the evaluation tasks; transfer to unseen tasks not ablated (2603.22435#s2)
- No ablation of the Reviewer or human-teaching component; single evaluation per setting (2609.29964#s2)

## Counterexamples
- Seed skills can hurt (Goal Pos. 30.0 -> 26.7) (2609.29964#s2)
