# K110 — Replace raw shell interaction with compact LM-oriented commands (agent-computer interface)
_parent: **Design the Frozen Model's Observation and Action Interface** ([`observe_act_interface`](../main/observe_act_interface.md)) · status: case · source card: `K110-compact-lm-command-interface.md` (frozen domain `embodied-agent-harness/v1`)_

## Operation
replace low-level shell interaction with a small set of LM-oriented commands with summarized, windowed returns, tuned by trajectory inspection

- Information access: Frozen LM; sees windowed file contents, summarized search hits, linter errors, older observations collapsed; no test oracle.
- Transfer: Cross-domain (SWE). Transfers only if the embodied bottleneck is how the model reads observations and emits actions, not physical execution.
- Status: case (1 full-text paper(s))

## When it works
- Large-context model, digital resettable environment with execution feedback, per-instance cost budget (2405.15793#s1)

## When it fails
- Iterative search makes agents page exhaustively; too small or too large windows hurt; ablations single-run on one model; authors leave transfer beyond programmatic tasks open (2405.15793#s1)

## Counterexamples
- none found in the readings
