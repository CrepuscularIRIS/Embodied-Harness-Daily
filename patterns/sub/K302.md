# K302 — Summarize repeated-task experience into notes injected into later episodes
_parent: **Build Context, Notes and Skills with the Weights Frozen** ([`harness_memory_skill_reuse`](../main/harness_memory_skill_reuse.md)) · status: candidate_pattern · source card: `K302-cross-episode-experience-notes.md` (frozen domain `embodied-agent-harness/v1`)_

## Operation
run the system on a task, have a model summarize what worked and failed into notes or parameterized traces, and inject them into later episodes' planner context

- Information access: Frozen models; memory from the system's own experience; 2607.08448#s2 bootstraps with a RESET primitive, generous budget and the benchmark success predicate on one reference seed; RESET disabled at deployment.
- Contrasts: Contrasts with K303 (generalized skills) and K304 (planner-free replay).
- Transfer: Requires task recurrence; the novel-task regime is untested.
- Status: candidate_pattern (2 full-text paper(s))

## When it works
- Same task repeated across episodes, or evaluation tasks sharing subgoal structure with a reference seed (2606.10267#s3, 2607.08448#s2)
- Fully observable tabletop tasks (2606.10267#s3)

## When it fails
- Not shown for partially observable or novel tasks (2606.10267#s3)
- Memory ablation on one suite with one planner; task vs global memory not separated; Composite-Unseen stays low; bootstrapping needs resets per task (2607.08448#s2)

## Counterexamples
- In-episode memory gave no benefit (attributed to full observability); window-3 numbers inconsistent across tables (2606.10267#s3)
