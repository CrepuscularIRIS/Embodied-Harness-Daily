# K708 — Initialize from teacher-derived data so every task has nonzero success before sparse-reward RL
_parent: **Make Sparse-Success Embodied RL Learnable** ([`teacher_seeded_sparse_rl`](../main/teacher_seeded_sparse_rl.md)) · status: candidate_pattern · source card: `K708-teacher-coverage-before-sparse-rl.md` (frozen domain `embodied-agent-harness/v1`)_

## Operation
initialize the student from teacher-derived data so target tasks have nonzero success, then run sparse or outcome-based RL

- Information access: SFT on privileged-teacher demos, teacher discarded, PPO on binary success (2609.21650#s2); Recovery-DAgger init from privileged geometric labels, then Flow-GRPO with STOP-override rollouts (2610.21450#s2).
- Transfer: The zero-reward barrier is the reason to raise teacher success before sparse RL.
- Status: candidate_pattern (2 full-text paper(s))

## When it works
- Target-domain simulator for RL; binary success checker; matched RL compute (2609.21650#s2)
- Initialized from Recovery DAgger, dense shaped reward, cheap rollouts (2610.21450#s2)

## When it fails
- Coverage correlation not isolated; SFT forgetting; below teacher on two tasks; real closed-loop failed (2609.21650#s2)
- Late termination increases; stop timing remains the main residual failure; no real aircraft (2610.21450#s2)

## Counterexamples
- BC-initialized Flow-GRPO fails (2610.21450#s2)
