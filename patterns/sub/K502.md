# K502 — Train the student on teacher data while the student's interface lacks part of the teacher's harness
_parent: **Distil Success-Filtered Teacher Harness Trajectories into a Compact Student** ([`offline_harness_distillation`](../main/offline_harness_distillation.md)) · status: candidate_pattern · source card: `K502-student-on-reduced-interface.md` (frozen domain `embodied-agent-harness/v1`)_

## Operation
train the student on teacher data while dropping harness components from the student's context, either by giving it a minimal context or by deleting and rewriting teacher turns that depend on removed components

- Information access: Teacher harness is richer than the student's at train and test: plugins/planner (2609.10522#s3) or external memory files (2610.28589#s1); Student weights trained; tool-call arguments derived from the removed component are kept, so that knowledge must be memorized (2610.28589#s1); 2609.10522#s3 data mix human keyboard control and frontier rollouts in the same unit space; split not reported.
- Contrasts: Contrasts with K501 (identical interface) and K602 (internalization through online review instead of offline deletion).
- Transfer: This is the 'internalize' branch of harness distillation; neither member checks whether the removed information is identifiable from student observations.
- Status: candidate_pattern (2 full-text paper(s))

## When it works
- Teacher and student share the remaining tools and frozen executor; memory dependence detectable by surface heuristics (2610.28589#s1)
- Demonstrations in the same semantic unit space as the student's output (2609.10522#s3)

## When it fails
- Without the frontier planner the student fails reasoning-intensive tasks (10%); 1B students over-adjust; distillation of plugin context not studied (2609.10522#s3)
- Recipes differ in content and coverage, so rewriting is not isolated; evaluation on the same tasks with new initial states (2610.28589#s1)

- none found in the readings
