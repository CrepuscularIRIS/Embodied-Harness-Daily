# K501 — SFT a compact VLM on success-filtered frontier-teacher turns so it pilots the identical harness
_parent: **Distil Success-Filtered Teacher Harness Trajectories into a Compact Student** ([`offline_harness_distillation`](../main/offline_harness_distillation.md)) · status: candidate_pattern · source card: `K501-sft-student-pilots-identical-harness.md` (frozen domain `embodied-agent-harness/v1`)_

## Operation
log the frontier teacher's per-turn reasoning and tool call while it runs the harness, keep successful episodes, and SFT a compact VLM on next-response prediction from the identical context

- Information access: Teacher: frozen frontier API (GPT-5.4, Gemini 3.1 Pro, Claude Sonnet 4.6, Gemini 3.7 Flash). Student: Qwen3.5-4B/9B, LoRA or LLM-only training, vision encoder frozen; Student sees exactly the teacher's harness observations and keeps the harness (tools do perception, geometry, control); no logits used; Targets: reasoning + call (2606.18363#s3, 2606.27871#s2), call + decision note (2609.29389#s2), call only with teacher reasoning excluded (2609.29964#s3); 2609.29964#s3 keeps frontier sub-agents at evaluation; 2606.27871#s2 data collected under privileged teleport execution.
- Contrasts: Contrasts with K502 (student lacks part of the teacher's harness) and K601/K602 (teacher corrections at student states).
- Transfer: Requires teacher success high enough that success filtering leaves data, and a student that can afford the harness context at deployment.
- Status: candidate_pattern (4 full-text paper(s))

## When it works
- The student retains the full harness rather than internalizing it (2606.18363#s3, 2609.29389#s2, 2609.29964#s3)
- A few hundred success-filtered decision samples (~500) or ~110 episodes are the data scale used (2606.27871#s2, 2609.29389#s2, 2609.29964#s3)
- Optional GRPO afterwards with sparse simulator success through the same harness (2606.18363#s3)

## When it fails
- RL shown on two tasks only; sequential observe-reason-act loop limits responsiveness to fast scenes (2606.18363#s3)
- Mixing teachers hurt; privileged execution during collection leaves real-executor states uncovered; no on-policy correction (2606.27871#s2)
- Held-out-task accuracy modest (13.9%); simulation only; success-filtered teacher data only (2609.29389#s2)
- Sub-agents remain frontier calls, so the student does not run standalone; OOD only new seeds (2609.29964#s3)

## Counterexamples
- OpenVLA beats the harness student on Object new-state (62.5 vs 43.8) (2609.29389#s2)
