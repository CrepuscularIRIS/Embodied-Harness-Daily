# K609 — Reward student candidates by semantic agreement with black-box teacher actions at the same state
_parent: **Distil On-Policy with Logit, Privileged-Self, Agreement or Harness-Contrast Signals** ([`on_policy_distillation_objectives`](../main/on_policy_distillation_objectives.md)) · status: case · source card: `K609-blackbox-action-agreement-opd.md` (frozen domain `embodied-agent-harness/v1`)_

## Operation
at each learner state, sample several teacher actions and student candidates, reward candidates by semantic match, optimize PPO-clipped, and advance the environment with the best candidate

- Information access: Teacher frozen black-box (generation only); same public context; hidden state excluded; Matcher LLM judges agreement, not correctness; no task reward.
- Contrasts: Same verb as K605 with black-box access.
- Transfer: Continuous or multi-unit embodied actions need an equivalence judge; holding state for N candidates needs simulator cloning.
- Status: case (1 full-text paper(s))

## When it works
- Cheap teacher queries at arbitrary student states; discrete judgeable actions; state can be held for multiple candidates (2610.19820#s1, 2610.19820#s2)

## When it fails
- Agreement is not correctness; matcher errors; few matches when decisions are dispersed; students far below teachers (37.7 vs 71.2) (2610.19820#s1)
- State-group rollout makes visitation off-policy (2610.19820#s2)

## Counterexamples
- none found in the readings
