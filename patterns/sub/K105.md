# K105 — Have the frozen planner write code cells that compose perception, geometry and motion primitives
_parent: **Let a Frontier Planner Compose Code, Learned Tools and Frozen VLAs** ([`planner_composes_code_and_policies`](../main/planner_composes_code_and_policies.md)) · status: candidate_pattern · source card: `K105-code-cells-over-primitives.md` (frozen domain `embodied-agent-harness/v1`)_

## Operation
let the frozen frontier model write and run code that composes primitives, computes geometry, branches and retries locally, and returns only requested observations

- Information access: Frozen planner in a coding runtime (Codex CLI, Claude Code); helper functions persist across cells; 2610.01939#s1 can read the benchmark success flag and world coordinates; 2610.01939#s2 gets only the evaluation client's RGB and joint state (no depth, no success signal); 2609.39207#s1 gets full robot sensors plus MCAP replay and a safety validation layer; No student in these signatures (student RL on this interface is K704).
- Contrasts: Contrasts with K104 (fixed vocabulary) and K101 (primitive batches).
- Transfer: Needs primitives whose outcomes can be checked in code; contact-rich steps without feedback stay hard.
- Status: candidate_pattern (2 full-text paper(s))

## When it works
- High-effort frontier model with context compaction and call budgets (2610.01939#s1)
- A minimal geometric library with known calibration can suffice for many tasks (2610.01939#s2)
- Generated motion validated in MuJoCo/kinematic checks before execution, with replay-based repair (2609.39207#s1)

## When it fails
- Composition, persistent state and selective feedback are not isolated; many code-only successes are tool-calling budget exhaustion (2610.01939#s1)
- Contact without feedback (button presses) and tight fits remain unsolved where pretrained policies reach 83-96% (2610.01939#s2)
- Real humanoid tasks take 10-20 min and are qualitative (2609.39207#s1)

## Counterexamples
- Including failures, cost on RC365 atomic is about equal to tool calling; removing guides raised tool-calling success on RoboTwin without VLA (42.8 -> 60.4) (2610.01939#s1)
