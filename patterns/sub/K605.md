# K605 — On-policy distillation from a white-box teacher's token logits at student-visited states
_parent: **Distil On-Policy with Logit, Privileged-Self, Agreement or Harness-Contrast Signals** ([`on_policy_distillation_objectives`](../main/on_policy_distillation_objectives.md)) · status: case · source card: `K605-whitebox-logit-opd.md` (frozen domain `embodied-agent-harness/v1`)_

## Operation
roll out the student, reward each sampled action token by the negative student-teacher log-ratio, and update by policy gradient, using reverse KL rather than forward KL or argmax relabels

- Information access: Frozen teacher VLA sees the same observation; white-box logits required, shared action tokenization; teacher actions not executed.
- Contrasts: Same verb as K609 with different access (logits vs sampled actions).
- Transfer: Does not apply to an API frontier teacher; applies only once a white-box intermediate teacher exists.
- Status: case (1 full-text paper(s))

## When it works
- Strong teacher with accessible logits and shared tokenization; resettable sim (2603.26666#s1)
- Teacher uncertain on student OOD states favours reverse KL (2603.26666#s2)

## When it fails
- Student ceiling is the teacher; not applicable to black-box API teachers; cross-interface untested (2603.26666#s1)
- Objective ablation on one task, curves only; hard-CE (black-box-style relabel) weakest (2603.26666#s2)
