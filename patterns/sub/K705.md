# K705 — Fork the simulator at each decision step, score completions with a privileged dense reward, continue from the best
_parent: **Make Sparse-Success Embodied RL Learnable** ([`teacher_seeded_sparse_rl`](../main/teacher_seeded_sparse_rl.md)) · status: case · source card: `K705-forked-branch-stepwise-grpo.md` (frozen domain `embodied-agent-harness/v1`)_

## Operation
sample a group of completions per decision step, roll each in a forked simulator branch, score with a dense privileged reward plus brevity term, update with GRPO and continue from the best branch

- Information access: Reward uses privileged distance-to-goal and SG discovery; student is the SFT VLM piloting the same harness.
- Contrasts: Same commit-best-candidate move as 2610.19820#s2 (K609) with environment reward instead of teacher agreement.
- Transfer: Requires cloneable simulator state, costly for a rendering-heavy simulator.
- Status: case (1 full-text paper(s))

## When it works
- Simulator state cloneable per step; dense privileged reward; SFT warm start (2606.27871#s3)

## When it fails
- Per-step bandit-like RL, not full-episode credit; requires forking; text/table SR mismatch (2606.27871#s3)

## Counterexamples
- none found in the readings
