# K611 — Start student RL from states produced by teacher-student interaction
_parent: **Correct, Review or Relabel at Learner-Induced States** ([`learner_state_teacher_correction`](../main/learner_state_teacher_correction.md)) · status: candidate_pattern · source card: `K611-rl-from-correction-derived-start-states.md` (frozen domain `embodied-agent-harness/v1`)_

## Operation
start the student's sparse-reward RL rollouts from intermediate states derived from teacher-student interaction instead of the task start

- Information access: 2509.14257#s2: verified student prefix before the first error, replayed; key-step bonus for matching the teacher correction; no teacher queries during RL; 2505.09546#s2: reset to states the privileged teacher reaches when rolled out from student-visited states; teacher actions not imitated.
- Transfer: Needs arbitrary-state resets in the embodied simulator.
- Status: candidate_pattern (2 full-text paper(s))

## When it works
- State restorable by textual replay; short horizons (2509.14257#s2)
- Resettable simulator; sparse success reward; tolerates a suboptimal teacher (2505.09546#s2)

## When it fails
- Not reported for long-horizon or non-replayable environments; reward scale tuned on a small search (2509.14257#s2)
- Longer training; struggles in large exploration spaces; not tested with visual policies (2505.09546#s2)

## Counterexamples
- none found in the readings
