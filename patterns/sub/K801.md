# K801 — Cross frozen models with harnesses on fixed tasks and report harness variance with paired statistics
_parent: **Separate the Harness Effect from the Model Effect** ([`harness_effect_evaluation`](../main/harness_effect_evaluation.md)) · status: candidate_pattern · source card: `K801-coding-harness-factorial.md` (frozen domain `embodied-agent-harness/v1`)_

## Operation
run a model-by-harness grid with everything else fixed and report harness variance, model variance, ranking reversals, paired bootstrap CIs and tokens per solved task

- Information access: Frozen API models; identical tasks, sandbox, verifier and budgets; harnesses vary as deployed products.
- Contrasts: Contrasts with K802 (component toggles inside one harness) and K803 (embodied swaps).
- Transfer: Embodied evaluations rarely afford enough tasks or repeats for such paired CIs.
- Status: candidate_pattern (3 full-text paper(s))

## When it works
- Long-horizon tasks, frontier models of comparable capability (2605.23950#s1)
- Deterministic test verifiers; model held fixed per comparison (2607.22585#s1)
- Contamination-controlled private tasks with model identity verified (2609.11987#s1)

## When it fails
- 7.80x ratio not universal; harnesses cumulative, per-layer contributions not isolated (2605.23950#s1)
- 50 tasks, most differences within noise; turn-budget asymmetry (2607.22585#s1)
- Intervals 11-17 pp wide; post-hoc workload split; coding only (2609.11987#s1)

## Counterexamples
- none found in the readings
