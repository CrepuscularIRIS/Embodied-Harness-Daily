# K201 — Treat each model proposal as a request and gate it with an external checker before execution
_parent: **Gate, Monitor and Diagnose Actions Outside the Model** ([`external_verification_control`](../main/external_verification_control.md)) · status: candidate_pattern · source card: `K201-pre-execution-proposal-gate.md` (frozen domain `embodied-agent-harness/v1`)_

## Operation
check each proposed edit, navigation target, STOP or route outside the model with a cheap checker and either dispatch it or reject it with structured feedback

- Information access: Checker sits outside the LLM and does not use the evaluation oracle (no unit tests, no geodesic success criterion); Checkers: syntax linter (2405.15793#s2); argument validity, evidence provenance/recency, reachability, subgoal consistency (2609.15195#s1); identity + fresh-depth + completion checks on STOP (2609.15195#s3); obstacle-box clearance of a waypoint polyline (2609.20822#s1); Frozen planner; no training.
- Contrasts: Same verb as K202 (control-flow on executor output) but K201 acts before execution on model proposals.
- Transfer: A gate is only as good as its proxy for success; a distance-based stop gate needs a distance estimate the deployed sensors can provide.
- Status: candidate_pattern (3 full-text paper(s))

## When it works
- A cheap automatic checker of action validity exists (2405.15793#s2)
- Usable depth at the grounded region and reliable target detection for stop checks (2609.15195#s3)
- A single known obstacle grounded by segmentation, phases cut at contact events (2609.20822#s1)

## When it fails
- Catches only syntax-level errors: 52% of unresolved instances are wrong implementations the linter misses (2405.15793#s2)
- Stop gate passes outside the success region (fresh depth 1.20 m vs goal distance 2.15 m) and near wrong endpoints; OSR-SR gap 19.0 on HM3D-OVON (2609.15195#s3)
- Contribution of proposal validation alone is not ablated (2609.15195#s1)
- Box-only verifier on an approximately measured scene misses unmodeled constraints; small gain for GPT-5.5 on Level II (2609.20822#s1)
