# Sample Candidate Actions and Let a Verifier Choose
_id: `sample_verify_select` · sub-patterns: R06 · 1 candidate_pattern · 0 case · domain: `board-induced` (2026-10-21, from wave-1 weak fits) · outcome labels: none in this build_

**Definition.** Spend test-time compute on the action choice: sample several candidate actions from the policy at each decision step (perturbed VLA actions, chain-of-thought action candidates, reflected plans), score them with a verifier — a learned VLM reward model, repeated true/false and masked-entity checks by the same model, or a reflector/critic — and execute the best, optionally updating policy and critic at test time from hindsight reflection (R06).

**Operational signature.** observation + instruction → policy samples N candidates (optionally perturbed around a fitted Gaussian) → verifier scores each (learned reward model / same-model verification prompts / reflector) → execute argmax → (optional) hindsight reflection on the outcome → test-time update of policy and critic

**When to apply.** When sampling is cheap relative to one action, a verifier ranks closer to task success than the policy's own likelihood, and the control rate tolerates N forward passes plus verification per step.

## Success conditions
_Derived from the member cards' When-it-works lines and the readings' reported effects; each is phrased as a property checkable in a paper's text._
- **Verified policy compared with the same policy unverified, in closed loop.** +9 points on a simulated benchmark, 60% vs 35% on real out-of-distribution tasks, 56.5 vs 49.8 on a long-horizon suite, with the verifier's data scaled (37.5 -> 46.3) (2506.17811#board).
- **Sampling separated from verification.** No sampling SR 39, sampling with a vote 40, full verification 52 on the same subset; gains flatten beyond 4 candidates (2601.18492#board).
- **Each reflection channel removed.** 33.65% with both reflection channels vs 10.40% with both removed and 11.20% for a self-refinement baseline (2602.21198#board).

## Failure modes
_Derived from the member cards' When-it-fails lines; each names a design or evidence property whose presence signals the failure._
- **Verifier trained or argued on a proxy.** The reward model ranks by distance to the demonstration action, and the scaling argument assumes an oracle verifier (2506.17811#board).
- **Per-step latency of N candidates.** 16 candidates take 650 ms and the robot runs at about 1.5 Hz; the K x P verification cost is not timed (2506.17811#board, 2601.18492#board).
- **Small ablation sets and trial counts.** A 90-pair subset from 8 scans without variance; 10 real trials per task (2601.18492#board, 2506.17811#board).
- **Privileged frontier supervision.** Task specifications are generated by a frontier model and SFT data are privileged, on the authors' own benchmarks (2602.21198#board).
- **Far below trained specialists.** SR 52 vs 81 for a fully supervised navigator; +0.41 SR on a second benchmark (2601.18492#board).

## Cognitive barriers
- "Any verifier helps." A different published verifier paired with the same VLA scores below the VLA alone, and some tasks show no gain (2506.17811#board).
- "Combining verification signals is additive." Each reflection channel alone can score below using neither (2602.21198#board).
