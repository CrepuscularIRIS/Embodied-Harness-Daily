### 2510.03342 v3 — Gemini Robotics 1.5 (GR 1.5 + GR-ER 1.5)
- **OPERATION**: a thinking VLM orchestrator decomposes the task, calls tools (e.g. web search), detects success and sends language instructions to a thinking VLA exposed as a tool (§2.1).
- **INFO ACCESS**: both models trained (GR-ER 1.5 for embodied reasoning; GR 1.5 on multi-embodiment data with Motion Transfer). Orchestrator sees user input and feedback; VLA sees images and instruction.
- **CLUSTER**: (b).
- **WORKS**: the available text gives no numbers. It says GR 1.5 beats GR and GRoD across all four generalization axes (Fig. 3, §3.1) and that MT amplifies the gain from multi-embodiment data (Fig. 4). The benchmark has 230 tasks and reports progress score.
- **FAILS**: fulltext truncated (§3.2–6 missing), so thinking/agentic claims are unverifiable. GRoD comparison "not apples-to-apples" (§3.1). Over 90% of development episodes in simulation (§2.3).
- **COUNTER**: none in the available text.

### 2510.25548 v3 — VIZ-COAST (VLM-inferred SMT constraints for TAMP)
- **OPERATION**: before planning, have a VLM predict refinement failures from a scene image and write Z3 constraints for an SMT task planner; revise them when:
  - over-restriction: no task plan is found;
  - code errors in the constraints;
  - after K cached refinement failures, each temporarily blocked (§Methodology).
- **INFO ACCESS**: frozen VLM (Gemini Flash) sees PDDL, image, geometry text and grasp spec. Planner and streams are classical.
- **CLUSTER**: (a), with failure-feedback repair.
- **WORKS**:
  - Shelf: zero refinement failures over 30 problems from a single VRM call.
  - Cooking: the only method at 100% success.
  - Packing: lowest planning time at 5–6 items.
  - Table 1: 8 of 9 VLM configurations reach 100% over 20 trials.
- **FAILS**: planning time excludes VRM prompting. K picked per domain by fewest failures (test-set tuning, inferred). 30 problems per domain, simulation only.
- **COUNTER**: VLM-only reaches 100% success on Packing. No-feedback fails Cooking at ≥3 ingredients, so a-priori constraints alone are not enough. Flash-Lite has 7.05±8.87 failures, and Qwen3.5-Flash reaches 73%.

### 2511.01594 v2 — MARS (multi-agent MLLM assistive planning)
- **OPERATION**: chain four agents: perception (CLIP + segmentation → scene text), risk ranking with a rule table (Table 1), planner over a base action library, and an evaluator that scores four dimensions and loops until the mean passes a threshold (Alg. 1).
- **INFO ACCESS**: one static RGB image. Frozen MLLMs (GPT-4o), no training.
- **CLUSTER**: (c), role-split variant. No embodiment, so probably tier C.
- **WORKS**: in Table 4 the full system ranks 1.73 (GPT-5 judge) and 1.53 (experts), versus 4.40–6.97 for single-branch ablations. Generalization scores are 4.75–5.53 on a 1–7 scale (Table 5).
- **FAILS**:
  - Nothing is executed. Outputs are ranked by GPT-5 plus two experts.
  - Table 2 labels the best row "Ours 1800B" while §4.2 credits GPT-4o with the same numbers.
  - Expert L2 score: 1.20 in text, 1.5 in table.
  - No variance is reported, and the threshold loop is never isolated.
- **COUNTER**: none.

### 2511.22354 v2 — CoMuRoS (event-driven multi-robot replanning)
- **OPERATION**:
  - A Task Manager LLM classifies tasks (independent, sequential, coordinated or infeasible) and allocates them using a static rules prompt plus dynamic status and events.
  - Per-robot LLMs compose Python from skill functions.
  - Onboard perception plus an LLM label events as relevant or irrelevant, and relevant events trigger replanning over non-COMPLETED tasks (§III).
- **INFO ACCESS**: frozen LLMs (GPT-4o, Grok 3). The scenario config gives capabilities and rules. Events come from OwlViT plus GPT-4.1 VQA.
- **CLUSTER**: (c), with a K202-like monitor-triggered replan.
- **WORKS**: on hardware, 9/10 recovery, 8/8 coordinated transport and 5/5 human-assisted runs (§IV-A). On the text benchmark with Grok 3, correctness is 0.91 and TA/TC/IoU/Exec are 0.96/0.96/0.97/0.98. The replanning set reaches 1.0 (§V).
- **FAILS**: correctness is judged by an expert on text plans. No baseline numbers are reported. Replanning is scored only when the initial plan was correct. There is no ablation of event filtering or status monitoring.
- **COUNTER**: the one hardware failure in 10 came from an incorrect replanning sequence.

### 2512.10394 v2 — RoboNeuron (MCP↔ROS2 middleware)

It offers a direct path or a perception→inference→control process graph that the agent starts and stops. VLA backends, runtimes and pruning presets are swapped behind a fixed I/O contract (§III).
- **INFO ACCESS**: an external LLM agent (unspecified) sees the tool schemas. The VLAs are pretrained (OpenVLA, OFT, π0).

### 2512.14442 v1 — A4-Agent (training-free affordance pipeline)
- **OPERATION**: run three stages.
  - Dreamer: an image editor renders the imagined interaction.
  - Thinker: GPT-4o reads the original and imagined images and outputs JSON naming the object part.
  - Spotter: Rex-Omni boxes and points, then SAM2 refines them into a mask.
- **INFO ACCESS**: all components frozen. Single image plus instruction. Static prediction with no control loop.
- **CLUSTER**: other (static perception; nearest K109). It could seed a cluster "imagine-then-ground", but it is a singleton.
- **WORKS**:
  - ReasonAff gIoU 70.52 vs 67.41 for Affordance-R1 (Table 1).
  - 3DOI 63.9 vs 39.6 (Table 2).
  - UMD 65.38 vs 49.85 (Table 3).
  - Dreamer adds +4.54 gIoU with Qwen (Table 4). Spotter alone scores 45.91 (Table 6).
- **FAILS**: the text claims 71.83 gIoU against 70.52 in Table 1. P50-95 ties at 55.22. No robot execution and no variance.
- **COUNTER**: GPT-4o without the Dreamer already reaches 62.30, against 63.94 with it (Table 4). Most of the gain comes from decoupling reasoning and grounding, not from imagination.

### 2601.11063 v2 — EmboTeam (LLM→PDDL→behaviour trees, multi-robot)
- **OPERATION**: LLM decomposes and allocates the task into per-subtask PDDL problems; an LLM simplifies them, FastDownward solves each, a few-shot LLM merges sub-plans with sync nodes; the plan compiles into parallel behaviour trees with fallback/retry and a shared blackboard (§3).
- **INFO ACCESS**: frozen LLMs (GPT-4o, Claude-3.5, Llama-3.1). Abstracted symbolic state, with ground-truth PDDL domain given.
- **CLUSTER**: (a), plus (c).
- **WORKS**: Table 2, GPT-4o: parallel-independent SR 0.71 / GCR 0.88 vs LaMMA-P 0.14/0.40; temporal-dependent 0.38/0.62 vs 0.10/0.26. Aggregate SR 12% → 55%.
- **FAILS**:
  - The "No BTC" ablation row equals the LaMMA-P row on all six numbers (Tables 2 and 3), which is suspicious.
  - The evaluation uses abstracted states (§5) on the authors' own 42-task benchmark, with no variance reported.
  - Exec is 0.76 vs 0.81 for the baseline.
- **COUNTER**: without PFG+HP, PI SR is still 0.43, the same as without HP. On PI tasks the LLM→PDDL+planner stages add nothing over the BT layer alone.

### 2601.14681 v1 — FARE (fast-slow LLM + RL exploration)
- **OPERATION**: prune the belief graph to top-k modularity communities; a frozen LLM (Qwen3-14B) maps a human-written environment description to a strategy schema and outputs a global waypoint path; an RL policy trained with a waypoint-adherence reward executes it (§IV).
- **INFO ACCESS**: the LLM sees text only (description, graph and memory). The RL policy sees the local graph with utilities plus the global path.
- **CLUSTER**: proposed new (i): frozen-LLM sparse global guidance plus an adherence-trained RL follower. Nearest: (b) (but planner trained there) and (h).
- **WORKS**: Table I numbers absent from fulltext. Text: on par indoors, shorter distance/makespan in forest, best in warehouse (§V-A, 10 runs per environment). Hardware: whole 200 m × 130 m building explored without intervention.
- **FAILS**: no recoverable numbers. Description human-supplied per environment (privileged). No LLM-vs-heuristic or adherence-reward ablation; one hardware run.
- **COUNTER**: indoor parity, so there is no gain without global structure.

### 2601.18492 v1 — DV-VLN (generate-then-verify VLN)
- **OPERATION**: sample K chain-of-thought candidate actions (Prediction / View-match / Action). Verify each P times with the same model, using a True-False prompt and a masked-entity recovery prompt, and pick the candidate with the most verification successes (§IV-E).
- **INFO ACCESS**: BLIP captions plus direction text. LLaMA-2-7B is bias-tuned (1.6M parameters) on CoT labels built from ground-truth paths and CLIP. The verifier is the same model.
- **CLUSTER**: (f).
- **WORKS**:
  - R2R val-unseen SR 52 / SPL 45, vs 46/40 for MSNav (§V-B).
  - On the subset (Table II): no sampling 39, sampling with vote 40, full system 52.
  - REVERIE SR 29.8 vs 19.2 for NavGPT (Table IV).
  - Gains flatten past K=4 (K=8 reaches SR 54).
- **FAILS**: ablations use a 90-pair subset from 8 scans, with no variance. The K×P overhead is not timed. Results remain far below ScaleVLN (81 SR). On RxR the gain is only +0.41 SR over NavGPT-2 (Table III).
- **COUNTER**: TFV alone adds only +2 SR over voting (40→42, Table II).

### 2601.19510 v2 — ALRM (CaP vs TaP agentic manipulation)
- **OPERATION**: a ReAct planner emits templated subtasks. An executor LLM realises each one either as one-shot Python over 8 API functions (CaP) or as iterative tool calls (TaP). Execution summaries come back to the planner as observations (§III).
- **INFO ACCESS**: frozen LLMs. Perception returns simulator object names and poses. The fast evaluation environment returns placeholder poses (§V-C).
- **CLUSTER**: fits K803, moderately (swaps 10 models under a fixed harness and 2 executor modes per model). The executor itself is K105.
- **WORKS** (Table III): Claude-4.1-Opus reaches 93.5 with TaP and 92.6 with CaP. Falcon-H1-7B reaches 84.3 with CaP at 24.89 s. Gemini goes from 73.1 with CaP to 87.0 with TaP.
- **FAILS**: success is scored by three LLM judges against ground-truth sequences, not by execution, and placeholder poses hide physical failures. The text says both 56 and 54 tasks. Single run, fixed prompts.
- **COUNTER**: executor mode reverses by model. GPT-5 scores 90.7 with CaP vs 85.2 with TaP. Small models collapse under TaP: Falcon goes from 84.3 to 14.8 and Granite scores 0.0.
